# AKRONIKL IT NEXUS v0.1.4-alpha.2 — инструкция загрузки

## База
Патч накладывается **только поверх рабочего `v0.1.4-alpha.1`**.

## Что исправляет
- Nexus Sandbox больше не смешивает статическую проверку, условия задания и фактический Runtime.
- Ошибка лёгкого Browser Runtime на расширенном ООП маркируется как возможное **ограничение среды**, а не автоматически как ошибка ученика.
- «Проверить среду» отдельно тестирует базовый console/stdout и OOP capability.
- Добавлен безопасный временный retry для `override`; исходный код ученика не изменяется.
- Добавлена RU/EN документация модели runtime capabilities.

## Загрузка
1. Сделайте резервную точку текущего рабочего `v0.1.4-alpha.1`.
2. Распакуйте `AKRONIKL_IT_NEXUS_v0.1.4-alpha.2_OOP_RUNTIME_COMPATIBILITY_PATCH_FROM_v0.1.4-alpha.1.zip`.
3. Загрузите **всё содержимое архива** в корень `akronikl-it-nexus` с сохранением структуры папок и заменой одноимённых файлов.
4. Сам ZIP в репозиторий не загружайте.
5. Дождитесь зелёного GitHub Pages deployment и обновления CDN.
6. Откройте страницу с `?v=0.1.4-alpha.2`.

## Smoke-test
Откройте тему 37 «ООП: инкапсуляция, наследование и полиморфизм».

Проверьте:
- пример `Wallet`/базовый class code;
- «Проверить среду» — base console должен пройти; OOP probe может быть PASS либо `best-effort`, но не должен объявлять платформу сломанной;
- код с `virtual`/`override`: если Browser Runtime не умеет конструкцию, должно появиться **«Ограничение Browser Runtime»**, а не ложное утверждение «ваш код неверен»;
- технический вывод раскрывается отдельно;
- исходный код в редакторе после compatibility retry остаётся неизменным;
- Benchmark 01 и 02, меню, Glass Dropdown, particles и RU/EN продолжают работать.

## Коммит
**Название:**
`fix: разделена диагностика кода и ограничений Runtime v0.1.4-alpha.2`

**Описание:**
`Nexus Sandbox теперь отдельно показывает статический анализ, требования задания и фактический Runtime. Добавлены capability-aware diagnostics, OOP self-test и безопасный временный compatibility retry для override без изменения исходника ученика.`

## Важно
Это не подмена полноценного C++ compiler. Browser Runtime остаётся быстрым учебным provider. Полный modern C++, multi-file builds и Project Studio будут обслуживаться расширенным WASM / Secure Build provider через тот же интерфейс Nexus Sandbox.
