# Legal Model Research — 2026-09-17

## Summary

Keeping the repository without a root `LICENSE` during the initial rights audit is safer than prematurely granting broad public permissions. GitHub states that default copyright applies when no license is chosen, while public-repository viewing/forking remains governed by GitHub's Terms.

The target post-audit model is layered: PolyForm Noncommercial 1.0.0 candidate for software; CC BY-NC-SA 4.0 candidate for original learning content/docs; separate reserved brand/mascot/logo policy; third-party materials under their own licenses; secrets never published.

MIT/Apache-style open-source licensing does not fit the stated anti-commercial-repackaging goal because open source permits commercial use. Creative Commons should not be used for software, but can be suitable for educational content. Copyright protects expression rather than the underlying platform idea, so direct copying can be restricted while independent implementation of similar concepts cannot be completely prevented by copyright alone.

Russian law protects computer programs as copyright works, allows optional state registration of software/databases, recognizes open-license structures, and provides exclusive rights for registered trademarks. Trademark protection is territorial; WIPO's Madrid System can later extend protection internationally from an eligible basic mark.
