# Product Scope

Includes IT course library; deep lessons/labs/tests/projects; local progress and optional future sync; contextual text/voice Akronikl; code runners; Skill Graph and prerequisites; practices and portfolio; PWA/offline shell; multilingual-by-design architecture with RU/EN first and arbitrary future locales; a free core learning path; rights/provenance metadata; and documented product/architecture/content/QA/legal/release processes.

Foundation v0.3 excludes mass generation of every discipline, mandatory tuition subscription, client-side secrets, unsandboxed arbitrary server execution, marketplace/payment systems, and activation of a final public license before the rights audit.

The first major stage is to make C++ the reference implementation, complete dependency/provenance review, and finish three benchmark lessons before scaling.
