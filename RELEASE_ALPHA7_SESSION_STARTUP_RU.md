# Nexus Alpha7 — запуск интерфейса и сессия

Исправлена остановка bootstrap до первого запроса аккаунта: браузерные таймеры вызывались как методы служебного объекта и получали неподходящий Window receiver. Теперь вызов сохраняет правильный контекст. Проверка сессии и блокировка локального хранилища не ослаблены.

Gateway и BFF поддерживают V2 передачи всей строки Cookie. Обнаруженные расхождения отдельных cookie-параметров воспроизводились синтетическими запросами. V2 строго сравнивает контекст с настоящим Cookie с обеих сторон, запрещает неоднозначность и дубликаты защищённых имён. Сессионная cookie по-прежнему проверяется сервером; отдельный frontend токен не вводится. Подробности: `server-access/COOKIE_HEADER_V2_RU.md`.

При первой попытке внешнего входа существующий аккаунт по-прежнему требует явной привязки из свежей Passkey-сессии. Браузер получает понятную страницу с объяснением и ссылками на ключи/безопасность, а API сохраняет JSON и прежний статус ошибки. Адреса почты и данные OAuth в ошибку не выводятся.

Worker, D1-миграции, Passkey, модераторские права и проекты не меняются. Выпускается новое поколение ресурсов; прежние поколения, manifest identity и Service Worker сохранены. Локальные/синтетические проверки не заменяют реальный вход владельца и не закрывают формальный PWA/Release Gate 05. Для отката сохранены предыдущие container revision, Gateway spec и исходные SHA256; пользовательские данные не очищаются.
