Прежний голос «Уют-7» — пробный локальный модуль Windows

Для компьютера, где уже установлены Qwen3 TTS 1.7B Base и среда Kitsune-Qwen-Voice. Также нужен Node.js 22 или новее. Модели и библиотеки автоматически не скачиваются. Для обычного веб-доступа выбирайте быстрый Piper в Nexus: ему этот модуль не нужен.

Распакуйте архив в отдельную папку и запустите START.cmd. Откроется окно локального модуля с восьмизначным кодом. В Nexus войдите в свой аккаунт, откройте помощник → Настройки → Голос → Прежний «Уют-7» и введите код. После подключения выберите прежний голос в общем списке.

Ключ облачного ИИ модулю не нужен. Текст для озвучки обрабатывается на вашем компьютере. Подключение действует в текущем запуске Nexus; закрытие чата его сохраняет, выход из аккаунта его отзывает. На другом устройстве модуль нужно подключить отдельно. Если браузер запросит доступ к локальной сети, разрешите его для Nexus при подключении модуля.

Код меняется после успешного подключения. Другой аккаунт не получает предыдущий код подключения, историю или звуковой кэш. Для двух аккаунтов используются отдельные подключения.

В этой тестовой версии ускорена уже установленная Qwen с сохранением голоса. Дождитесь надписи «Голос готов»: модель предварительно загружается и прогревается. Обновлённая страница Nexus начинает воспроизведение по мере подготовки речи. Старые страницы получают фразу целиком. Если ускорение недоступно на вашей видеокарте или в установленной среде, остаётся обычная озвучка Qwen.

Если на компьютере есть проверенная русская модель из Kitsune, модуль выбирает её первой. Другие устройства не используют видеокарту этого компьютера: этот модуль предназначен для локальной озвучки на ПК.

Обновление от 30 октября 2026 года: скачайте новый архив с платформы и распакуйте в отдельную папку. Если прежний модуль уже работает в фоне, его нужно завершить перед запуском нового. При необходимости перезагрузите Windows и запустите START.cmd из нового архива. Код подключения появится заново.

При нестандартной установке параметры Python и ModelDirectory можно передать в Start.ps1. Это пути к установленной модели; API-ключей в конфигурации нет.
