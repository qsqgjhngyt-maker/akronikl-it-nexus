Голос «Уют-7» · локальный Qwen TTS для Windows

Если Qwen TTS ещё нет: в настройках голоса Nexus нажмите «Установить Qwen TTS · Windows» и запустите Akronikl-Qwen-TTS-Setup.exe. Установщик проверит компьютер, покажет объём, затем загрузит модель, Python, Node и библиотеки. Отдельно искать и устанавливать их не нужно. Облачный API-ключ не требуется.

Эта поставка предназначена для Windows x64 с NVIDIA, поддержкой BF16, номинальными 8 ГБ видеопамяти и подходящим драйвером 572.61 или новее. Проверенная конфигурация: RTX 5050, 8151 МиБ. CPU, AMD и телефоны этим пакетом не поддерживаются; для них в Nexus доступен Piper. CUDA Toolkit, Flash Attention и среда Kitsune не требуются.

Загрузка около 8 ГБ; после установки около 10 ГБ. Для загрузки и распаковки временно нужно больше места; установщик рассчитывает его до начала. Успешно распакованные архивы удаляются из его кэша. Прерванная загрузка сохраняется и продолжается при повторном запуске. Все архивы проверяются по размеру и SHA256. Установщик тестовый, цифровой подписи пока нет.

После установки откроется локальное окно. Дождитесь «Голос готов», возьмите восьмизначный код. В Nexus войдите в свой аккаунт: помощник → настройки → голос → прежний «Уют-7» → введите код → подключите и выберите голос. Позже модуль запускается через меню «Пуск» → Akronikl → «Голос Уют-7 Qwen TTS».

Если используете дополнительный ZIP «Только модуль подключения», распакуйте его полностью и запустите START.cmd. Этот облегчённый ZIP предназначен для уже установленной Qwen/Kitsune; он не заменяет полный установщик. Не запускайте START внутри ZIP.

Модель предварительно загружается и прогревается. Речь начинает проигрываться по мере подготовки. Тексты не отправляются в облако; сеть модели выключена. При неподдерживаемом ускорении сохраняется обычный локальный синтез. Микрофон не используется.

Сопряжение сохраняется при закрытии чата; выход из аккаунта отзывает его. На другом устройстве нужно отдельное подключение. Если браузер запросит доступ к локальной сети, разрешите его для Nexus. Код меняется после подключения. У разных аккаунтов отдельные токены и доступ к звуку. API-ключей в пакете нет.

Если запущена прежняя версия модуля, сначала завершите её или перезагрузите Windows; новый запуск не должен молча подключаться к старому процессу.

Удаление: параметры Windows → приложения → «Голос Уют-7 · Qwen TTS для Nexus». Удаляются только локальный модуль, модель и кэш этого приложения; история, проекты и настройки аккаунта Nexus сохраняются.
