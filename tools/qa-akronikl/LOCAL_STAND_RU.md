# Локальный стенд без облачного ИИ

Это тестовая среда feature-ветки. Публикация, production, main и официальный Release не изменяются.

Используется полный интерфейс Nexus из feature-исходников. Вход проверяется существующим кодом BFF/Worker/WebAuthn, но база аккаунтов отдельная, а ключи доступа виртуальные тестовые. Настоящие аккаунты production, Windows Hello и обычный профиль Chrome не используются. Адрес штатного Gateway работает здесь только в отдельном Chrome, где все имена направлены на loopback; открывать его в обычном браузере для проверки нельзя. Рабочее окно открывается через локальную страницу управления стендом.

Включено сохранение настроек и дерева сообщений. Облачная генерация выключена отдельно: connect/generate/chat отклоняются до чтения ключа или создания провайдера. Для этой среды не нужны API-ключи. Настройки и история сохраняются на компьютере стенда в зашифрованном файле; тестовые passkey-ключи и ключ шифрования защищены Windows DPAPI CurrentUser. Эти приватные файлы и профиль браузера не входят в архив доказательств.

Локальная очередь изменений принадлежит подтверждённому аккаунту Nexus. Пока вход подтверждён, временный сбой хранилища позволяет продолжить работу с локальной копией. После восстановления можно нажать «Повторить синхронизацию»; конфликт версий требует выбора пользователя. При переполнении локального хранилища интерфейс предупреждает о невозможности сохранения. Другая вкладка не может перезаписать очередь первой вкладки.

При полном разрыве связи публичная справка использует ранее загруженные материалы с проверенными хешами. Когда сервер не может подтвердить вход, личный интерфейс скрывается; локальный accountId не заменяет авторизацию. Холодный вход без сервера и офлайн-доступ к чужим данным не разрешаются. Этот стенд доступен без внешнего интернета, пока локальный сервер работает.

Озвучка предлагает установленные локальные голоса устройства и рассказчика «Уют-7». Рассказчик использует уже установленную модель из отдельного проекта Kitsune-Qwen-Voice `siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf`, snapshot `c16b3af3db3095120efc1ebb73f6522442bcb3b1`. Эталон голоса взят из существующего проекта «Уют-7», сведения сохранены рядом с WAV. Веса повторно не загружаются. Python работает с отключённой сетью, HF offline и локальным путём к весам. Это акустическая модель на компьютере стенда; она не устанавливается на телефон. Облачный учебный Qwen по-прежнему выключен.

Первая фраза требует загрузки модели в видеопамять. Текст передаётся в UTF-8 с проверкой SHA-256. Модель прогревается в фоне при запуске стенда и остаётся готовой после отмены. Отмена останавливает генерацию на ближайшем шаге; при зависании применяется принудительное завершение процесса. Закрытие стенда освобождает модель. Автоозвучка требует включения пользователем и читает только новые ответы после действия. История при восстановлении не проигрывается. Микрофон в этом этапе не подключается.

Проверка WAV, событий браузерного воспроизведения и фактического синтеза не является оценкой дикции человеком. Для окончательной оценки голоса нужно прослушать сохранённый пример. Работа с физического телефона и публикация в интернете этим стендом не проверяются. Остальные облачные провайдеры и Qwen с исчерпанной квотой отложены.

Ускоренный режим использует speaker embedding рассказчика без длинного ICL-эталона и детерминированные дополнительные акустические коды. Вариант принят пользователем после прослушивания. Повторно озвученная фраза хранится только в памяти экземпляра чата (до 8 записей / 8 МБ), не записывается в browser storage и очищается при закрытии/смене аккаунта. Проверка текущей личности действует также при чтении из этой памяти. Первая часть ответа ограничена 60 символами, последующие — 100; текст сохраняется полностью.
