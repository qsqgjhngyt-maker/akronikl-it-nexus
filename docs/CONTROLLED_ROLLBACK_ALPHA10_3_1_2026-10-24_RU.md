## Объём изменения

Пять корневых runtime-файлов (`index.html`, `nexus-shell.html`, `offline.html`, `version.json`, `service-worker.js`) возвращаются побайтово из официального commit 10.3.1. `BUILD_MANIFEST.json` берётся из официального пакета: в самом историческом теге этот корневой manifest ошибочно описывает Alpha9. Реконструкция исходников, повторная сборка и изменение immutable поколений не выполняются.

Все 1112 файлов официального frontend 10.3.1 совпали по размеру и SHA256 с точным снимком GitHub. Проверены также 74 записи manifest внешнего пакета. Все существующие `releases/` и `entry-assets/`, включая 10.4.2, сохраняются. Корневые исходники и `release-candidate.json` остаются кандидатом 10.4.2; активную публикацию определяют точные корневые runtime-файлы и официальный manifest 10.3.1. Нельзя пересобирать текущие исходники под immutable именем 10.3.1.

Yandex BFF, Cloudflare Worker/D1, Identity, grants, секреты, БД и инфраструктурные конфигурации не меняются. Очистка данных сайта, удаление IndexedDB, localStorage, CacheStorage, переустановка PWA и автоматический Cloud Sync не выполняются.

## Ограничения и неудачные попытки

Первый запуск локального браузера был заблокирован сетевой изоляцией (`ERR_NETWORK_ACCESS_DENIED` даже для loopback). Повтор с разрешённым локальным доступом прошёл; исходный результат сохранён.

Первый навигационный прогон прошёл шесть групп и остановился на ошибочном ожидании теста: прямой вход в Блог/Code Studio не обязан загружать C++ данные. Исправлено только это ожидание теста, код frontend не менялся; повтор прошёл все семь групп. Исходный результат сохранён.

Синтетические проверки не доказывают сохранность каждого реального пользовательского профиля, вход с реальным аккаунтом, физические iPhone/Android или исчезновение сетевых задержек backend. LIVE gate должен подтвердить новую публикацию на обоих origin, точные публичные bytes и отсутствие ослабления анонимных API guards. FULL LIVE PASS без приёмки владельца не объявляется.

На Yandex `/` и `/index.html` для анонимного пользователя выдаются существующим BFF, а `/nexus-shell.html` остаётся закрытой с 401. Поэтому публичная landing BFF не является побайтовой копией GitHub `index.html`; она сохраняется с предпубликационным SHA256 `c0ec6c135d98142e67147273ba09686d3d44afcce7e6311a60eff9f0880c50dd` (7019 байт). Предпубликационная проверка 16/16 прошла с учётом этого штатного контракта. Исходная проверка с ошибочным ожиданием одинаковых landing сохранена отдельно. Без реального аккаунта содержимое закрытой оболочки на Yandex напрямую не доказывается.

## Восстановление 10.4.2 при необходимости

Использовать защитную ветку и прежний официальный manifest: вернуть пять корневых runtime-файлов и manifest из `cf4ae9ded9b17db4911c78196bf6bc56df7d8a67` новым коммитом, пройти тот же gate и штатную публикацию. Историю main не переписывать, хранилища пользователей не очищать.
