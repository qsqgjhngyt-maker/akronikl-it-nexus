# AI Reproducibility Standard

Record:
- experiment id/date;
- code commit;
- dataset/task ids;
- provider/model/config;
- prompt/policy version;
- Context Engine version;
- Learner Model version;
- Skill Graph version;
- RAG index version;
- evaluator/rubric;
- seed where available;
- exclusions;
- outputs/results.

Hosted-model mutability must be disclosed.
