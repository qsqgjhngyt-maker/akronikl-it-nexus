# AI Evaluation Metrics — Summary

Learning:
- next-task success;
- correction success;
- time-to-solution;
- hint count;
- repeated-error rate;
- retention where appropriate.

Quality:
- correctness;
- pedagogy;
- personalization;
- code/course grounding;
- unsupported claims.

Systems:
- latency;
- context size;
- provider failures/fallback;
- cost where measured.

Learner model:
- predictive loss;
- calibration;
- uncertainty.
