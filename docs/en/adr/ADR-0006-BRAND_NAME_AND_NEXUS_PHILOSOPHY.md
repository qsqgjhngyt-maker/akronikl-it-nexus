# ADR-0006 — Akronikl IT Nexus name and Nexus philosophy

**Status:** accepted  
**Date:** 2026-09-17

## Context

The original project started as a standalone C++ course. After the concept expanded into a platform spanning programming, systems, data, AI/ML, security, cloud technologies and practical work, the working name `Akronikl Academy` became too generic and did not clearly express the interdisciplinary architecture.

## Decision

Official product name:

**AKRONIKL IT NEXUS**

Repository:

`akronikl-it-nexus`

Primary namespace:

`akronikl:it-nexus:*`

Canonical philosophy:

> **Nexus is the node of connections, the center where disciplines converge.**

Brand metaphor:

> **Nexus is our event horizon.**

In official documentation, “event horizon” is used as a metaphor for the transition from isolated knowledge to an integrated engineering system, not as a literal definition of the word Nexus.

Main brand line:

> **Nexus — the node of connections. The horizon beyond which knowledge becomes a system.**

## Consequences

- All new documents and identifiers use `Akronikl IT Nexus`.
- `Akronikl Academy` is treated as the historical working name of Foundation v0.1 and is not used for new artifacts.
- Akronikl remains the name of the character and AI mentor.
- Product architecture must implement real interdisciplinary connection through prerequisites, Skill Graph, cross-links, projects and practices.
