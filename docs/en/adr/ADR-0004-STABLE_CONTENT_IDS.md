# ADR-0004-STABLE_CONTENT_IDS — Stable content identifiers

**Status:** Accepted

## Decision
Progress, cross-links and references use stable content IDs rather than array indexes or visible ordering numbers.

## Rationale
Topic order will change as Akronikl IT Nexus expands, while user progress and links must remain valid.

## Consequences
This decision is part of the Foundation architecture contract. Changes require a new ADR rather than a silent rewrite of history.
