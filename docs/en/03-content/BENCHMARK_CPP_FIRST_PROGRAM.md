# Benchmark 01 — Your First C++ Program

ID: `cpp.first-cpp-program`

Status: **Benchmark Standard 1.0 / RU+EN complete**

## What this benchmark validates

The lesson must prove that Nexus can be more than a collection of short cards: it should form a complete knowledge-assimilation path from first understanding to internal model and independent transfer.

## Required characteristics

- the learner understands both syntax and the path source → preprocess → compile → link → runtime → main;
- historical `stdafx.h`, Borland/C++ Builder and similar details are separated from the modern baseline;
- the reference example is modern and portable;
- errors are treated as diagnostic problems, not only wrong answers;
- theory is connected to practice, lab work, and the Skill Graph;
- RU and EN share one stable lesson ID and one progress record.

## Acceptance criterion

After the lesson, a learner should be able to explain the role of `#include`, `std::cout`, `main`, `;`, and `return 0` in their own words, and classify compile/link/runtime failures.
