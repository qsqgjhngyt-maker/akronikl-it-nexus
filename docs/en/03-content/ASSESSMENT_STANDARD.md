# Assessment Standard

Assessment combines quick checks, result prediction, bug finding, explanation in the learner’s own words, code modification, code-from-scratch tasks, labs and projects. Skill mastery uses multiple evidence sources with provenance; one lucky answer must not mark a skill as mastered.
