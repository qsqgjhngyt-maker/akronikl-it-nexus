# Full Theory Standard

The full-theory block must be readable as a self-contained textbook section. It needs precise definitions, motivation, causal explanation, an internal execution/data model, multiple distinct examples, edge cases, common errors, modern practice, separately labeled historical context when needed, and a conclusion/self-check. There is no artificial length target: simple topics may be 3–5k characters, complex ones 8–15k+ if justified. Template text and unmarked obsolete practice are prohibited.
