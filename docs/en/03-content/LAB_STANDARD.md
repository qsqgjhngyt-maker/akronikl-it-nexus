# Lab Standard

A lab includes goals, prerequisites, problem statement, inputs/constraints, milestones, acceptance criteria, checks, tiered hints, expected artifacts, reflection and Skill Graph mapping. Akronikl uses progressive assistance: diagnosis → guiding question → partial hint → full walkthrough only when explicitly requested.
