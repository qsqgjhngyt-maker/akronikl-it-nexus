# Code Example Standard

A meaningful example includes the task, assumptions, code, expected result, explanation, key state/invariants, safe variations and common failure modes. Where a toolchain exists, examples should be compiled/executed automatically; otherwise the limitation is recorded. Unsafe/undefined-behavior code is allowed only as an explicitly labeled negative example.
