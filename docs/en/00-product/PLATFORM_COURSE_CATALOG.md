# Akronikl IT Nexus Course Catalog

The platform is planned as a multi-discipline IT curriculum. The primary Russian catalog is normative and contains the complete approved list plus proposed extensions. English course names will be localized as each course package is implemented.

Major tracks: Programming Foundations, Systems, Software Engineering, Data, AI/ML, Infrastructure/Cloud, Security, Applied Technologies, Mathematics for IT/AI, and Practice/Portfolio.

A course is not considered ready merely because a catalog card exists. It requires goals, prerequisites, skill outcomes, curriculum map, sources, labs and final-project criteria.
