# Competitive Research Summary

**Snapshot date:** 2026-09-26

Reviewed official public materials from:
Coddy, Hyperskill, Codecademy, Replit, freeCodeCamp, Sololearn, Scrimba and DataCamp.

Main conclusion:
interactive coding, projects, roadmaps, AI code help and AI-assisted building are already established product patterns.

Nexus should not claim uniqueness from any of those features alone.

The stronger differentiation hypothesis is the integration of:
- learning state;
- real engineering project history;
- cross-device project lifecycle;
- skill/prerequisite graph;
- versioned learner model;
- purpose-bound AI context;
- experimental evaluation against Generic LLM and ablations.
