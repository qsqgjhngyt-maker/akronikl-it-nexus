# Feature Comparison — Summary

Public evidence confirms strong existing coverage of:
- interactive browser learning;
- structured paths;
- projects;
- AI code assistance;
- AI app builders;
- mobile learning;
- cloud collaboration/building.

Public evidence in this review did not establish that competitors expose the exact Nexus combination of:
- learner-facing revision/conflict/audit workflow;
- longitudinal mastery/confidence model tied to project evidence;
- controlled Generic-LLM/ablation research layer.

This is a differentiation hypothesis, not a universal absence claim.
