# API Security

Provider secrets never reach the public client. Use HTTPS, trusted secret storage, rate limits, abuse protection, minimal request context, intentionally scoped CORS, secret-free logging, isolated code-runner infrastructure, input/output limits, and provider abstraction so course content does not depend on one AI backend.
