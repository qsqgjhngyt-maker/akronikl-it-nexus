# Current vs Target Architecture

| Area | Current | Target |
|---|---|---|
| Identity | local identity + Nexus token | federated identity, passkeys, MFA, revocable sessions |
| Progress | local | cloud-linked profile + offline cache |
| Sync | manual PUSH/PULL | queued/background UX after correctness |
| Cloud storage | D1-only snapshots | keep until measured scaling need changes |
| Team | ACL/schema foundation | invitation/member UX |
| Admin/CMS | none | Control Center + publishing |
| AI | Context v1 only | Learner Model + Skill Graph + RAG + Project grounding + secure gateway |
