# Course Package Architecture

Each course package contains a manifest, curriculum, RU/EN locales, lessons, labs, assessments, projects, skill map and sources. Manifests declare stable IDs, version, prerequisites, languages, skills, entry route, offline policy and platform compatibility. Progress must be keyed by stable lesson IDs rather than array positions.
