# Requirements Baseline — v0.1.7-alpha.2.3

**Normative source:** Russian. This English document is a synchronized mirror.  
**Runtime baseline:** `v0.1.7-alpha.2.2.1`.  
**Status:** WORK02 COMPLETE.

This baseline introduces stable requirement namespaces and lifecycle statuses for current implementation, planned product features, and AI research. IDs are immutable after publication. Major features require an ID, acceptance criteria, verification method, security/privacy assessment, and—when applicable—an ADR. AI requirements additionally require a baseline and evaluation plan.

Statuses: `IMPLEMENTED`, `FOUNDATION`, `PLANNED`, `RESEARCH`, `DEPRECATED`. Priorities: `P0`, `P1`, `P2`.
