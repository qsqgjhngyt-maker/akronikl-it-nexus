# RU/EN Localization Policy

Russian documentation and content are the primary source of truth for the first stage. English is a required secondary mirror. `docs/ru` is primary and `docs/en` mirrors it. Identifiers, schemas and code keywords are not translated. Public stable releases should not leave critical English documents in a translation-pending state. Technical terminology should be adapted idiomatically, not literally.
