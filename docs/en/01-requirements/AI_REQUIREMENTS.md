# Akronikl AI Requirements

Akronikl receives only the necessary context: course, lesson, section, task, code, stdout/stderr, requested hint level and bounded attempt history. It should coach before revealing final answers, classify compiler/runtime/logical/design errors, reference the current theory and prerequisites, never pretend code was executed when it was not, and retain a useful offline fallback. Do not transmit unrelated content or user secrets.
