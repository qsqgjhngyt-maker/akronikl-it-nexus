# Versioning

Use a SemVer-like scheme `MAJOR.MINOR.PATCH-pre.N`: foundation for documented architecture, alpha for active contract changes, beta for stabilized architecture and broad QA, rc for release candidates, stable after release gates. Platform and course-package versions will be separated.
