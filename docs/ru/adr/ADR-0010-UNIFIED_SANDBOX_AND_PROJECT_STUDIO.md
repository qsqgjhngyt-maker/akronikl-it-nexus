# ADR-0010 — Единый Nexus Sandbox и Project Studio

**Статус:** Accepted

## Решение
Все программные курсы используют единый пользовательский интерфейс Nexus Sandbox. Исполняющая часть реализуется через взаимозаменяемые providers: Browser Runtime, WASM Runtime и Secure Cloud/Build Runner. Поверх той же модели в будущем строится Nexus Project Studio с файлами, тестами, сборкой, памятью версий, Akronikl Project Mentor и Portfolio Release.

## Причины
- курс должен полноценно проходиться на ПК, планшете и телефоне;
- внешний VS Code/IDE не может быть обязательной частью учебного сценария;
- базовые и сложные проекты требуют разных вычислительных возможностей, но не разных UX;
- итоговый проект должен быть реальным доказательством навыков, а не только сертификатом.

## Следствие
Новые программные курсы не должны напрямую связывать UI с конкретным runtime. Любой runner подключается через provider contract.
