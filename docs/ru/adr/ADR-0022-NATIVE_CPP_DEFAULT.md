# ADR-0022 — закреплённый Clang/WASI для стандартного C++

Дата: 24.10.2026. Статус: IMPLEMENTED в feature/academy-gold-standard-cpp-module-2; автоматический допуск подтверждается отдельным evidence. Main/production не изменяются. Источник запроса: владелец поручил закрыть M2-RUNTIME-001…003 и повторить M2-0/Module 1.

## Причина

M2-0 на 4d6efc6: g++ C++20/UBSan и закреплённый Clang/WASI проходят 35 программ/56 сценариев. Автоматический router выбирает JSCPP для части обычного C++ с assessment guaranteed и даёт 13 расхождений: 8 отказов на корректном коде, 3 неверных результата без ошибки, 2 принятия ошибочного C++. Исходные probes, stdout/diagnostics и CI40101221596 сохранены. Поломка затрагивает /, signed/unsigned, sizeof и const; это базовая семантика, а не только новые ключевые слова.

## Решение и границы

Для любого C++ запроса Browser Runtime объявляется unsupported и unavailable. ID browser-jscpp и публичный export сохранены как DEPRECATED facade для старых импортов. Прямые run/load всегда возвращают typed provider limit; JSCPP script, normalize-адаптации и override retry не запускаются. normalize возвращает исходник без изменений для совместимости наблюдающих вызовов.

Существующий router выбирает имеющийся Clang/WASI. При отсутствии Worker/совместимого provider C++ route выдаёт WASM_ENVIRONMENT_UNAVAILABLE с anxProviderLimit и без строки ошибки ученика. Во время загрузки/компиляции штатные timeout, sysroot limits и diagnostics сохраняются. Отказ загрузки не даёт права перейти к интерпретатору. Planned Secure Build Runner не объявляется доступным. Другие языки и настоящий C provider не меняются.

Ограничения закреплённого компилятора сохраняются: например, C++ exceptions не поддержаны его sysroot и дают ограничение среды. Выбор настоящего компилятора не означает поддержку любой стандартной библиотеки или всех особенностей C++20.

## Альтернативы

1. Новые regex для 13 известных строк. Отклонено: не доказывает арифметическую семантику, const и поведение произвольных корректных/ошибочных программ.
2. Узкий fast path с доказанной грамматикой и типовой/семантической моделью. Отложено: такой recognizer не реализован и не проверен, обучающий риск нельзя закрыть маркетинговым guaranteed.
3. Закреплённый Clang/WASI по умолчанию. Принято: компилирует неизменённый исходник и даёт настоящую диагностику; текущие ресурсы, версии и ABI уже используются принятой test.2.
4. Исправлять код урока под JSCPP или принудительно добавлять constexpr/убирать return. Отклонено: скрывает дефект выбора runtime и учит обходам среды.

## Последствия и security

Первый запуск даже простой программы требует on-demand compiler bundle 105558342 bytes (~106 MB); до этого фиксированный вывод мог использовать JSCPP ~620 KB. Это осознанная цена корректности. Home сохраняет lazy imports и не запускает компилятор. Холодный native offline работает после штатной подготовки пакета и сохранения public cache; первый запуск без заранее загруженного пакета остаётся ограничением среды.

Production, опубликованные immutable bytes, service worker source/manifest, compiler versions/hashes, sandbox Worker, лимиты CPU/memory/output, Identity/Cloud/Project Studio/storage и stable IDs не меняются. Runtime patch ограничен sandbox/providers/browser-runtime.js и sandbox/runtime-router.js. Сеть и реальные credentials в QA не используются; compiler bytes подаются локально с проверкой SHA256. Обновление production потребует отдельного разрешения владельца и публикационного gate.

## Доказательства и повторная приёмка

Исходный M2-0 evidence остаётся неизменным FAIL. Повтор: прежние 35 программ/56 сценариев плюс 8 вариантов правил; независимые host g++20/UBSan, настоящий router/Clang/WASI и 6 UI Run на desktop/mobile viewport с восстановлением после compile error. Отрицательные контроли должны завершаться именно compile phase; network/provider errors не считаются успешной диагностикой исходника. Дополнительно запрет fallback при недоступном compiler, запрет прямого JSCPP и 0 JSCPP network requests.

Module 1: CP-1.1/CQG, 34 regression groups, integration, C++20/UBSan, все 173 уникальных source+stdin, реальные кнопки Run, холодный native offline, словарь/accessibility, Home/Account/media и PWA upgrade/rollback на изолированных синтетических работах. Полная личная LIVE-приёмка владельца и физические устройства не заявляются.

Есть ли здесь материал для диплома? Да: до/после provider policy, 13 конкретных расхождений, отрицательные контроли, стоимость холодного компилятора, сохранение startup бюджета и ограничения target/sysroot. Результаты отражают инженерную корректность проверенных программ; учебная эффективность и mastery не измерялись.
