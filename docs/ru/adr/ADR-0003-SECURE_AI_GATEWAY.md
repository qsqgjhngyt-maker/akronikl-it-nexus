# ADR-0003-SECURE_AI_GATEWAY — AI только через доверенный gateway

**Статус:** Принято

## Решение
API secrets хранятся только на server/Worker стороне.

## Обоснование
Публичная PWA не может безопасно хранить provider key.

## Последствия
Решение считается частью архитектурного контракта Foundation v0.1. Изменение оформляется новым ADR, а не тихой правкой истории.
