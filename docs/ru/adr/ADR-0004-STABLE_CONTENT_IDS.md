# ADR-0004-STABLE_CONTENT_IDS — Стабильные идентификаторы контента

**Статус:** Принято

## Решение
Прогресс и ссылки используют stable IDs, а не индексы массивов.

## Обоснование
Порядок тем будет меняться при расширении академии.

## Последствия
Решение считается частью архитектурного контракта Foundation v0.1. Изменение оформляется новым ADR, а не тихой правкой истории.
