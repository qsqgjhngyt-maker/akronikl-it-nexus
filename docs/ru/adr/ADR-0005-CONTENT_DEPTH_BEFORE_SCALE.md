# ADR-0005-CONTENT_DEPTH_BEFORE_SCALE — Сначала эталон качества, затем масштабирование

**Статус:** Принято

## Решение
Перед массовым наполнением создаются и утверждаются три эталонных C++ урока.

## Обоснование
Это снижает риск получить десятки дисциплин с шаблонной поверхностной теорией.

## Последствия
Решение считается частью архитектурного контракта Foundation v0.1. Изменение оформляется новым ADR, а не тихой правкой истории.
