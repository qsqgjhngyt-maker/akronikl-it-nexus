# Competitor Profile — Sololearn

## Publicly confirmed

Sololearn publicly offers:
- web/mobile learning;
- free course content;
- certificates;
- practice/quizzes;
- Code Playground;
- paid AI assistance.

Its MAX plan describes Kodie as an AI tutor that reads user code and includes:
- Explain My Answer;
- Find My Mistake;
- AI Prompting Playground.

Source: `S-SOLO-01`.

## Product lesson for Nexus

AI code explanation and mistake detection are already common product functions.

Nexus therefore should not treat:
- “AI reads code”;
- “AI explains mistakes”;
as core novelty.

## Nexus differentiation hypothesis

Potential distinction comes from longitudinal evidence:
- repeated error patterns;
- project history;
- skill graph;
- mastery confidence;
- next-step recommendation;
- experiments measuring whether AI assistance improves learning.
