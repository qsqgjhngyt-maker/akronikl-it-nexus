# Competitor Profile — Replit

## Publicly confirmed

Replit is a cloud software-building environment with a strong AI-agent direction.

Agent 4 public materials describe:
- parallel agent tasks;
- review before merge;
- conflict-handling assistance;
- live team collaboration;
- building multiple artifact types in a shared project/context.

Source: `S-REPLIT-01`.

Replit Learn is a free educational platform focused on:
- building apps with AI;
- video lessons;
- interactive exercises;
- hands-on examples;
- outcome-first learning rather than syntax-first.

Source: `S-REPLIT-02`.

## Product lesson for Nexus

Replit is the strongest adjacent benchmark for:
- cloud workspace;
- AI-assisted software creation;
- collaboration;
- project execution/deployment.

Nexus should not position “cloud IDE + AI” as unique.

## Nexus differentiation hypothesis

Nexus can occupy a different center of gravity:
- educational skill model is first-class;
- AI must optimize learning outcome, not only software output;
- code/project actions become pedagogical evidence;
- user can progress through a structured curriculum and engineering project lifecycle;
- AI assistance can be experimentally constrained to avoid over-helping.

In short:
Replit is primarily “build with AI”; Nexus target is “learn engineering by building, with AI that models learning”.
