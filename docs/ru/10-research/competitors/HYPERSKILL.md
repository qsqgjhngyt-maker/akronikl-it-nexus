# Competitor Profile — Hyperskill

## Publicly confirmed

Hyperskill emphasizes:
- project-based learning;
- 300+ hands-on projects;
- 80% practice / 20% theory positioning;
- 60+ structured courses;
- Java, Python, Kotlin, Spring Boot, Django, AI and other areas;
- integration with professional JetBrains IDEs;
- portfolio-oriented project work.

Source: `S-HYPER-01`.

Its public AI/engineering offerings include courses and projects around:
- AI agents;
- AI applications;
- software-development fundamentals;
- Git/remotes/tags;
- production-oriented engineering concepts.

## Product lesson for Nexus

Hyperskill is especially relevant because it already treats a project as a primary learning unit rather than a final bonus.

Nexus therefore cannot differentiate merely through:
- project-based learning;
- use of professional engineering concepts;
- AI-engineering curriculum.

## Nexus differentiation hypothesis

Potential Nexus distinction:
- browser/PWA engineering environment integrated directly with the learning state;
- continuous Project Studio state across devices;
- explicit cloud revision/conflict/audit model;
- skill graph + learner model linked to project telemetry;
- one integrated path from course concept → project evidence → mastery model → AI intervention.

This remains a product hypothesis to validate.
