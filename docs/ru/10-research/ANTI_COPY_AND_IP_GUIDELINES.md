# Anti-Copy & IP Guidelines

Competitive research is for understanding user needs and product patterns, not copying protected expression.

## Allowed inspiration
- general product category;
- user problem;
- abstract workflow;
- public standard patterns;
- technical concepts.

## Do not copy
- visual identity;
- proprietary illustrations/mascots;
- exact copywriting;
- course text;
- screenshots/art assets;
- distinctive UI composition;
- proprietary source code;
- hidden/private API behavior.

## Nexus rule
When adopting an idea, restate:
1. what user problem it solves;
2. Nexus-specific design;
3. independent implementation;
4. evidence/requirement that justifies it.
