# Product Differentiation — Nexus

## Не является дифференциатором само по себе

Следующие признаки уже широко представлены:
- код в браузере;
- интерактивные уроки;
- проекты;
- roadmaps/career paths;
- сертификаты;
- AI hints;
- AI that reads code;
- prompt-driven app building;
- gamification;
- mobile learning.

## Дифференциация должна строиться комбинацией

### 1. Learning state ↔ Engineering state
Учебный прогресс связан с реальным проектом пользователя.

### 2. Engineering evidence
Навык подтверждается не только quiz/result, но:
- успешной сборкой;
- исправлением diagnostic;
- checkpoint;
- project milestone;
- конфликтом/merge-like ситуацией;
- тестами.

### 3. Longitudinal Learner Model
AI получает не просто текущий код, а версионируемую оценку навыков и confidence.

### 4. Skill Graph
Следующий шаг объясняется prerequisites, а не только линейным curriculum.

### 5. Cross-device engineering continuity
Один проект и прогресс продолжаются на другом устройстве с revision/conflict semantics.

### 6. AI as measured tutor
AI должен быть экспериментально сравним с Generic LLM и ablations.

### 7. Full SDLC learning
Цель — учить не только синтаксису, а инженерному циклу:
requirements → design → code → tests → versioning → release → operations.

## Positioning hypothesis

> **AKRONIKL IT NEXUS — интеллектуальная инженерно-образовательная среда, где обучение, разработка реальных проектов и персонализированный AI-наставник работают на единой модели навыков и инженерных доказательств.**
