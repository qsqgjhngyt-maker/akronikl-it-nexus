# Nexus AI — Competitive Position

## Already common in market
- ask AI;
- explain code;
- find mistakes;
- contextual course feedback;
- generated projects;
- personalized learning path generation;
- AI-guided content discovery.

## Nexus research position

The intended distinction is a structured longitudinal AI context:

```text
Current task
+ current code/diagnostic
+ project history
+ Learner Model
+ Skill Graph
+ approved RAG evidence
+ privacy/context policy
= Nexus AI Context
```

## Research claim we may eventually test

> A structured longitudinal context improves learning outcomes compared with Generic LLM and simpler contextual variants.

This is not yet a proven product claim.

## Defensible novelty direction

The defensible academic contribution is more likely to come from:
- architecture;
- learner modeling;
- graph/evidence integration;
- context selection;
- evaluation;
than from model API integration itself.
