# Nexus Positioning Draft

## Short

**Учись как инженер. Строй реальные проекты. Получай AI-помощь, которая понимает твой путь.**

## Technical

AKRONIKL IT NEXUS объединяет:
- structured learning;
- Project Studio;
- browser/runtime execution;
- cross-device cloud project state;
- checkpoints/revisions/audit;
- skill graph;
- learner model;
- research-backed AI tutor.

## What Nexus is not
- ещё один каталог видео;
- только browser playground;
- только AI app builder;
- чат поверх курса;
- копия Coddy/Codecademy/Replit.

## Core product object
Не «урок» и не «чат».

Core object — **путь пользователя от компетенции к доказанному инженерному результату**.
