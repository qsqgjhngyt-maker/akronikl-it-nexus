# Roadmap Implications — WORK07

## Keep

Nexus should continue investing in:
- Project Studio;
- cloud revision/conflict correctness;
- cross-device continuity;
- Identity v2;
- Skill Graph;
- Learner Model;
- Context Engine;
- evaluation/reproducibility.

## Increase priority

### Learning Map / Skill Map
Coddy, Codecademy, DataCamp and others validate the value of visible learning paths.

Nexus version should be deeper:
- graph-based prerequisites;
- mastery/confidence;
- evidence links;
- explainable next-step recommendation.

### Account/Profile visibility
Cross-device products make identity continuity expected. Global account state should become a visible first-class UI element.

### Real projects
Hyperskill, Replit, Codecademy and Scrimba reinforce that users expect portfolio/project work, not exercises only.

### Mobile continuity
Coddy/DataCamp/Sololearn publicly support mobile learning. Nexus PWA should preserve continuity even where full editing UX differs by device.

## Do not over-prioritize as differentiation
- streaks;
- XP;
- generic certificates;
- AI chat button;
- simple code playground;
- prompt-to-app generation.

These may still be useful product features, but they are not strong uniqueness claims.

## Research priority
The strongest thesis/product leverage remains:
`learner state + skill graph + engineering evidence + bounded AI context + controlled evaluation`.
