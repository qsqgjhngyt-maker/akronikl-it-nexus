# Competitive Research Baseline Closure

WORK07 establishes a dated product-market snapshot across:
Coddy, Hyperskill, Codecademy, Replit, freeCodeCamp, Sololearn, Scrimba and DataCamp.

## Confirmed market patterns
- interactive coding;
- projects;
- roadmaps/tracks;
- AI code help;
- AI-assisted building;
- mobile/cloud workflows.

## Nexus implication
Uniqueness cannot be claimed from those features individually.

The working differentiation hypothesis is the integrated:
learning state + engineering project state + cross-device lifecycle + Skill Graph + Learner Model + purpose-bound AI context + experimental evaluation.

This remains a hypothesis requiring future validation.
