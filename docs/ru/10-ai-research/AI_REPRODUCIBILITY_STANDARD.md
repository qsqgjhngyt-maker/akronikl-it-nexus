# AI Reproducibility Standard

Every experiment records:
- experiment id/date;
- research question/condition;
- code commit;
- dataset version;
- task ids;
- model/provider/version;
- generation parameters;
- prompt/policy version;
- Context Engine version;
- Learner Model version;
- Skill Graph version;
- RAG index version;
- evaluator/rubric version;
- seed where supported;
- environment;
- exclusions;
- outputs/metrics;
- known incidents.

For mutable hosted models record exact run date and reproducibility limits.
