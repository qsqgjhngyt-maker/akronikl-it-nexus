# Skill Graph Quality Metrics

Structural:
- strict prerequisite cycles;
- orphan skills;
- content coverage;
- prerequisite depth.

Educational:
- prerequisite violation rate;
- expert agreement;
- success difference when prerequisites are met/not met;
- recommendation success.

Stability:
- edge changes between versions;
- recommendation churn.

Больше узлов/рёбер не означает лучший граф.
