# Pilot Study Plan

Purpose: проверить процедуру, метрики и технические логи, а не «доказать диплом».

Candidate crossover:
- часть участников начинает с baseline;
- часть с Nexus condition;
- matched task sets.

Collect:
- task outcome;
- time;
- hints;
- compiler/test transitions;
- short rating;
- blinded rubric.

Pilot outputs:
- event completeness;
- metric variance;
- task imbalance;
- technical failures;
- effect/variance estimate for sample planning.
