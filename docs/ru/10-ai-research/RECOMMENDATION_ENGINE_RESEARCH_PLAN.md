# Recommendation Engine Research Plan

Baselines:
- REC-B0: static curriculum order;
- REC-B1: prerequisite-ready next unit;
- REC-B2: learner-state-aware weak-but-ready skill;
- REC-B3: learned/adaptive policy only when data supports it.

Optimize learning progress, not engagement alone.

Metrics:
- prerequisite violation;
- completion;
- activity success;
- path efficiency;
- skip/override;
- learner satisfaction.

Recommendation is explainable and overridable.
