# Code Intelligence Research Plan

Signals:
- active file/selection;
- compiler/runtime/test diagnostics;
- file tree;
- relevant files by path/symbol;
- recent diff;
- checkpoint diff;
- build manifest;
- runtime capabilities.

Levels:
- CI-0: snippet only
- CI-1: snippet + diagnostic
- CI-2: relevant-file retrieval
- CI-3: AST/symbol/static facts
- CI-4: edit/checkpoint history

Research:
- minimum useful code context;
- symbol-aware vs whole-file;
- normalized error signatures;
- privacy/latency trade-offs.

Project execution remains controlled by runtime security, not by AI advice.
