# Dataset Strategy

- **DS-0 Synthetic:** deterministic fixtures/security/regression.
- **DS-1 Developer-owned:** longitudinal pipeline validation, not population claims.
- **DS-2 Curated benchmark:** skills, prerequisites, expected diagnostics, evidence, difficulty.
- **DS-3 Pilot participants:** consenting pilot.
- **DS-4 Thesis dataset:** frozen inclusion/anonymization/version.

If learned components are trained, separate train/development/final evaluation roles.

Do not tune on final evaluation examples.
