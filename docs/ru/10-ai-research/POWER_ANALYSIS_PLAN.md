# Sample Size / Power Analysis Plan

WORK06 не придумывает фиксированное число участников.

Перед final study:
1. выбрать primary outcome;
2. получить variance/effect estimate из pilot/literature;
3. выбрать statistical design;
4. определить alpha/power target по академическому протоколу;
5. учесть repeated measures/dropout;
6. сохранить calculation record.
