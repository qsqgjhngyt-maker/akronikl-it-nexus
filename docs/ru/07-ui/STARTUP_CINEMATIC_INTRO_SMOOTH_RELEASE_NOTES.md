# Изменения стартовой заставки

- Непрерывное воспроизведение вместо переключения частей каждые две секунды.
- Временная остановка скрытых декоративных анимаций во время заставки.
- Мобильный логотип плавно появляется в последние две секунды полного ролика.
- FullHD и полная длительность10/8секунд сохранены; MP4 стали меньше.
- Пропуск, настройки для всех, отсутствие вспышки интерфейса и offline fallback сохранены.

Кандидат для проверки. На рабочем адресе пока не опубликован.
