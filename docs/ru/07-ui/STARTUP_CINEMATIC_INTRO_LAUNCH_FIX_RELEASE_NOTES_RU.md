# Исправление стартовой заставки — кандидат

- Заставка появляется при открытии приложения или ссылки в браузере, до входа в аккаунт.
- При переходе через вход второй ролик не запускается; новое открытие приложения снова показывает заставку.
- Видео больше не закрывается из-за фонового обновления интерфейса, смены фокуса или поворота экрана.
- Настройки заставки доступны всем в меню режимов и оформления, а также до входа.
- Сохранены полупрозрачная кнопка «Пропустить», выключение заставки и упрощённый запуск.
- Desktop использует новый widescreen владельца: полные 10 секунд; Mobile сохраняет прежние файлы и полные 8,033 секунды.
- Оба видео медленно проявляются; после последнего кадра встроенный логотип остаётся видимым, затем сцена плавно затухает и открывает интерфейс. Второй логотип поверх не добавляется.
- Новый Desktop уменьшен с 61,35 МБ до 2,30 МБ MP4 / 2,12 МБ WebM, без сокращения 300 кадров. Видео не добавлены в обязательную офлайн-установку.
- Проекты, прогресс, локальная копия и настройки входа сохранены.

Статус: подготовленный кандидат; доставку на рабочий адрес подтверждать по итоговому отчёту, а не по этому описанию.
