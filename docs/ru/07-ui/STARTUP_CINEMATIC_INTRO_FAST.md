Desktop-сценарий, Account/bootstrap, OAuth, Cloud, Code Studio, PWA client, public entry.js и compiled entry.js побайтно прежние. Для runtime меняется только entry.html: добавляется ранний мобильный CSS без inline JavaScript и без дополнительной сетевой картинки. Backend и CSP не меняются.
