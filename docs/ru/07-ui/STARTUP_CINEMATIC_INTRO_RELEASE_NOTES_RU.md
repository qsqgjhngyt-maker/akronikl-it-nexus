# Примечания к кандидату «Кинематографичный запуск Nexus»

Статус: IMPLEMENTED / локальный AUTOMATED PASS. Ошибка первоначального допуска M5 разобрана: добавлен отдельный контракт Intro, историческая публикация проверяется своим неизменённым валидатором на точной базе. Итог текущего CI относится к SHA в Checks PR №47. Это не опубликованный релиз; физический LIVE и разрешение владельца на публикацию остаются отдельными условиями.

Добавлены два исходных ролика владельца в web-форматах, адаптивный внутренний Intro Layer и полупрозрачная кнопка «Пропустить». Заставка показывается один раз для версии ролика; в Account доступны отключение, упрощённый запуск и явный просмотр.

Account и рабочие экраны запускаются независимо от видео. При отсутствии сети, экономии трафика, reduced motion, ошибке или задержке видео используется короткий статичный fallback. Ролики без звука, не входят в обязательную установку PWA.

Локальные браузерные проверки, офлайн-компиляция, Cloud regression и точный rollback пройдены. Production, main и GitHub Releases не изменены. Физические устройства и разрешение владельца на публикацию остаются отдельными gate.
