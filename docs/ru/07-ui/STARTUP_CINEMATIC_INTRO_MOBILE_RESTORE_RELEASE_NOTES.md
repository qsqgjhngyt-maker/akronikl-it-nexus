# Восстановление мобильной заставки

Кандидат возвращает прежний мобильный способ воспроизведения Full HD без повторного сжатия. Логотип плавно появляется в финале. Настольная версия и вход сохраняются. Откат подготовлен; публикация требует отдельного разрешения владельца. Проверка физического телефона ещё не выполнена.
