## Откат

В отдельной чистой ветке от опубликованного коммита выполнить `node tools/prepare-startup-intro-delivery.mjs --rollback`, затем `node tools/check-startup-intro-delivery.mjs`. Проверить diff: только шесть корневых файлов и режим `production-test-rollback` в `startup-intro-publication.json`. Зафиксировать русским коммитом и опубликовать через main/GitHub Pages. Ни одного immutable файла не удалять. Новые файлы заставки сохраняются для уже открытых вкладок.

Возврат восстанавливает точные bytes main `d76d1613…` для index, nexus-shell, offline, version, SW и BUILD_MANIFEST. Проверка отклоняет откат, если исходная доставка повреждена. После доставки подтвердить прежнее поколение `ui1a-cpp-gold-module5-test2-header-20261027` на GitHub Pages и рабочем Yandex-адресе. Восстановление не требует очистки CacheStorage/IndexedDB, токенов, проектов или прогресса. Время возврата зависит от очереди Pages и обновления вкладки/SW; мгновенное принудительное обновление всех открытых устройств не обещается.
