> **Основной язык документации: русский.** Русская версия является нормативной. Английская версия поддерживается как вторичное зеркало для международных пользователей.

# Нефункциональные требования

- **NFR-001 Производительность:** старт без загрузки тяжёлых AI-моделей.
- **NFR-002 Mobile-first:** контроль памяти и отсутствие обязательных desktop-only функций.
- **NFR-003 Доступность:** клавиатурная навигация, контраст, фокус, aria для ключевых элементов.
- **NFR-004 Надёжность:** неудачное обновление не должно уничтожать рабочую PWA-оболочку.
- **NFR-005 Безопасность:** секреты только на доверенной стороне; sandbox для выполнения кода.
- **NFR-006 Сопровождаемость:** платформенное ядро и course packages разделены.
- **NFR-007 Наблюдаемость:** ошибки критических модулей диагностируются без раскрытия персональных данных.
- **NFR-008 Документируемость:** каждая архитектурно значимая перемена имеет ADR/changelog/regression evidence.
- **NFR-009 Международность:** русская ветка первична, английская обновляется синхронно в рамках релизного gate.
