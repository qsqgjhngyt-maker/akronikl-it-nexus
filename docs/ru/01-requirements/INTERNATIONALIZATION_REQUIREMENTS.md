> **Основной язык документации: русский.** Русская версия является нормативной. Английская версия поддерживается как вторичное зеркало для международных пользователей.

# Политика локализации RU/EN

## Нормативность
Русская документация и русское содержание — основной источник истины первого этапа. Английская ветка — обязательное вторичное зеркало.

## Структура
- `docs/ru/...` — primary;
- `docs/en/...` — secondary mirror;
- course content в будущем хранится через locale-aware поля/пакеты;
- код, идентификаторы и схемы не переводятся.

## Release gate
Если изменён документ в `docs/ru`, релиз отмечает английскую копию как `current` или `translation-pending`. Для публичного стабильного релиза критические документы не должны оставаться `translation-pending`.

## Контент
Перевод должен адаптировать терминологию, а не буквально переводить русские формулировки. C++ keywords и API names остаются оригинальными.
