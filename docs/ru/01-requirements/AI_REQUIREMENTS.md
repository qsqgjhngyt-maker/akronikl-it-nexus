# Требования к AI-наставнику Akronikl

## Контекст
Akronikl должен получать минимально необходимый контекст: `courseId`, `lessonId`, текущую секцию, условие задачи, код, stdout/stderr, выбранную подсказку и ограниченную историю попыток.

## Поведение
- сначала помогать понять, а не выдавать финальное решение;
- при запросе полного разбора — уметь дать полный разбор;
- отделять компиляторную ошибку, runtime error, логическую ошибку и проблему проектирования;
- ссылаться на текущую теорию и prerequisites;
- не выдумывать успешный запуск кода, если runner не запускался;
- offline fallback остаётся доступным для базовых объяснений.

## Приватность
Не отправлять лишние данные, токены доступа, содержимое других курсов или пользовательские секреты.
