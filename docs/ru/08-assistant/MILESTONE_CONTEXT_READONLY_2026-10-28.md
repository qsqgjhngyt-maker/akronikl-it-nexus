## IMPLEMENTED / CONTEXT & CODE ASSISTANCE

Вопрос «Что мы сейчас изучаем?» сопоставляется с настоящим уроком из проверенного индекса: совпадают courseId, lessonId и язык. Название, версия и происхождение берутся из материала, а не придумываются по URL. При отсутствии привязки помощник сообщает ограничение. Вопрос о текущем задании получает явное сообщение об отсутствии подключённого task-контекста. История прогресса также не имитируется.

Просмотр разрешённого контекста показывает активный файл, язык и ревизию. Код по-прежнему доступен только в явно выбранном диапазоне.

Добавлен небольшой модуль `sandbox/runtime-evidence.js`: штатный Sandbox run связывает результат с конкретным Studio/workspace, ревизией и фактически отправленными файлами. Во время запуска проверяется соответствие уже сформированного compiler request рабочей области; полный исходник и stdin/stdout в записи evidence не сохраняются. Одноразовый ticket не позволяет предыдущему запуску заменить более новый результат. Self-test не выдаётся за проверку проекта пользователя.

В приватности добавлено отдельное выключенное согласие на сообщение компилятора. Оно доступно только вместе с согласием на выделенный код и проверяется не только DOM-элементом, но и sessionHost. Помощник получает одну первичную диагностическую строку текущего файла и текущей ревизии. Полный журнал, соседние строки исходников и диагностика других файлов не передаются. Неизвестный файл, provider-limit, несовпадение координат и слишком длинная строка отклоняются.

На вопрос об ошибке сначала выводится факт с отметкой «Диагностика компилятора». При подключённой модели последующее объяснение использует прежний Tutor-контракт и отмечается отдельно как сгенерированное. Без модели причина ошибки не выдумывается. Реальное качество объяснения диагностики в этом этапе не измерено.

Новый запуск, завершение запуска, правка, смена файла или workspace делают прежний контекст недействительным. Отзыв согласия, блокировка и смена Account очищают историю и подавляют поздние ответы. Изменения проекта, запуск компиляции командой AI и Code Fix не добавлялись.
