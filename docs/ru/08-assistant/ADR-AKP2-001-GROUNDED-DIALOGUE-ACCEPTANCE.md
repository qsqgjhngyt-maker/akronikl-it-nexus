# ADR-AKP2-001 — полный смысл контекста и границы приёмки учебного диалога

Дата:27.10.2026. Ветка08. Статус: принято в экспериментальной feature-ветке; не разрешение на публикацию.

## Контекст

Реальная Qwen3-0.6B Q8_0 прошла технический smoke на1046574, но ответ «Объясни проще» ошибочно говорил об освобождении ресурса при инициализации. Исходный курс говорит о получении при инициализации и освобождении в деструкторе.

История передавала только120символов: «освобождение при деструкторе» обрывалось до «освобождение при д». Выдержка курса также обрывалась внутри слова. Оба обрыва воспроизведены тестами. Нельзя утверждать, что они были единственной причиной ошибки модели.

Источник: `courses/cpp/gold/structured/lifetime-ownership.ru.json`, sourceId `nexus:cpp:cpp.lifetime-ownership:theory-3:ru`, content SHA256 `cb0135f11e02ee056917451809abf0dd6bff8407bf1b16e548c2e6b97d1cdd39`.

## Решение

Передавать короткий предыдущий обмен целиком. Слишком длинный пропускать целиком вместо обрезания посередине слова. История живёт только в текущем окне и очищается при смене разрешений/контекста.

Сокращать исходный текст по границе завершённого абзаца/предложения, сохраняя происхождение. При отсутствии завершённого фрагмента не создавать обрывок. UI обозначает неполноту выдержки. Завершённая фраза не равна полному источнику: оставшиеся условия и оговорки могут не войти в бюджет.

Просить модель сохранять время, отрицания и причинный порядок; материал курса приоритетнее предыдущего сгенерированного ответа. Для упрощения отдельно требовать обычные слова, а не повторение английской расшифровки аббревиатуры.

Разделять техническую, смысловую и продуктовую приёмку. Правильный JSON, source-метки и появление текста не доказывают правильность преподавания. Узкий экран RAII находится в QA и не выдаётся за универсальный runtime-фильтр истины.

## Альтернативы

Увеличение таймаута не исправляет смысловую ошибку;120с сохранены. Подмена ответа заготовкой отвергнута: проверяется настоящая генерация. Отключение отрицательных тестов и маскировка ошибки ссылкой на источник отвергнуты. Большая модель/аппаратное ускорение остаются возможными следующими экспериментами, не реализованными данным решением.

## Доказательства

Новые тесты против старого session.js:8PASS/2FAIL; после исправления:10PASS. Известный неверный ответ сохраняется и отклоняется новым узким экраном. Первый парный опыт40478979776 сохранил порядок получения/освобождения, но упрощение оставалось слишком техническим, поэтому критерий дополнен.

Итоговый source `81c4e5442db0925b95c328273fa9b1effad84350`, CI40480218928:229Core/UI и указанная адресная регрессия PASS; реальная генерация с продолжением без сети —10/10технических групп. Тексты прочитаны реализующим ассистентом, не независимым экспертом.

В двух новых ответах известная ошибка не повторилась. Но «инициализация», «деструктор» и «область» остались без пояснений. Упрощение для начинающего — PARTIAL, репрезентативная педагогическая приёмка не выполнена.

## Измерения и последствия

На одном runner старый source дал86,739/92,817с, текущий —77,709/97,428с для первого ответа/продолжения. Один парный прогон не доказывает ускорения; скорость не принята. Нельзя сужать приёмку до одного RAII-вопроса ради зелёного статуса. Следующий этап — пригодный способ вычисления и более разнообразная оценка.

Полный предыдущий ответ увеличивает контекст по сравнению с обрывком; это осознанный компромисс в пользу смысла, не обещание ускорения. Длинный пропущенный обмен ограничивает продолжение разговора. Source-метки подтверждают наличие предоставленных материалов, не истинность выводов модели.

## Security / ограничения

Account/ACL, backend, production, веса модели, COOP/COEP не меняются. Нет инструментальных действий и исполнения generated text. Prompt cache для приватных данных не включён. Контекст/согласие/отмена остаются обязательными.

Генеративный probe — синтетический host, публичный учебный вопрос, native ESM и CPU/WASM. Авторизованный E2E отдельно использует виртуальный CTAP2 и тестовую базу. Продолжение без сети в том же окне не означает холодную повторную подготовку модели. Runtime и модель пока требуют отдельной подготовки.

Физические устройства, независимый review, разнообразный корпус и настоящая диагностика в пользовательском UI не приняты. Регулярные выражения могут не заметить другую ошибку, поэтому qualityAcceptance:false сохраняется.

## ВКР

Отрицательный эксперимент: технически успешная генерация → содержательная ошибка → проверка входного контекста → устранение обрыва → усиление критериев → реальные ответы и ограничения. Это инженерный результат, не доказанная педагогическая эффективность.
