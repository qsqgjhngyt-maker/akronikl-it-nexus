# ADR-AKP1-001 — общеплатформенные команды Akronikl

Дата: 27.10.2026. Ветка 08. Статус: IMPLEMENTED, кандидат без публикации.

## Решение

Один детерминированный интерфейс `request/confirm` для текстового ввода и кнопок.
Будущий голос использует этот же интерфейс; сейчас распознавание речи и LLM не подключены.
Каталог отделяет существующие экраны от PLANNED и неподключённых действий.
Навигация требует явного подтверждения одноразового предложения. Hash берётся только
из каталога; входная строка не является URL, селектором или JavaScript.

Граница host наследует проверенный контекст: текущий аккаунт/локальную сессию, маршрут,
готовность экрана, язык, экземпляры редактора и workspace. Перед подтверждением
повторно проверяются граница и режим. Ввод нового текста, новый запрос, блокировка
или закрытие окна отменяют старое предложение. Публичный offline не открывает личные
проекты; local unlock не становится server proof. Административная навигация
не подключена: отсутствие проверенных capabilities обозначается как неизвестная
доступность, а не как утверждение, что владелец лишён прав.

Справка — восемь подготовленных тем с привязкой к файлам существующего Nexus.
Причина недоступности произвольной кнопки без её диагностики не угадывается.
Сохранение, запуск кода, удаление, публикация, logout и изменения настроек не выполняются.

## Интеграция

Основа — main d76d1613a1fbf6726d453e40366c306ea502d4c7 (M5 Test.2).
Core/UI из fd72c1372ff4f67e927bae570fc20358d8f2e72d перенесены изолированно:
новая версия платформы и исправления M5 не заменены старым runtime.
Актуальный C++ индекс содержит 56 ID, 55 Gold-уроков каждого языка; EN-заголовок
cpp.visual-event-model не объявляется полным новым шестым разделом.
Это адаптация к M5, не доказанная автоматическая поддержка будущего M6/всех курсов.

Каталог и окно загружаются только при открытии помощника. Не добавляются startup fetch,
сбор содержимого всех проектов, telemetry, аудио или передача пользовательского кода.
Изменение frontend bootstrap — ранее проверенное одностороннее уведомление очистки;
оно не разрешает маршрут и не заменяет серверную проверку. Review перед выпуском остаётся.

## Доступность и ограничения

Нативный dialog, label для текстового поля, Enter для запроса, Escape для закрытия,
возврат фокуса и live-region для ответа. Базовые ориентиры — W3C APG Modal Dialog:
https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/dialog/
Это не сертификация WCAG и не физическая проверка VoiceOver/TalkBack/NVDA.
Обычная ограниченная грамматика не равна свободному пониманию естественного языка.
Независимый review, реальный LIVE и физические устройства не заявляются.

## Альтернативы

Автоклики по тексту/координатам отклонены: ненадёжно и неоднозначно.
Выполнение URL из ответа модели отклонено: внешний текст не источник полномочий.
Отдельный движок голосовых действий отклонён: дублирует права и логику.
Слияние старого snapshot поверх main отклонено: потеря M5 и исправлений входа недопустима.

## Материал для ВКР

Контракт команд, минимизация контекста, одноразовые предложения, отказ на неизвестных
правах, сохранение runtime текущей платформы и исполняемые отрицательные тесты.
Педагогическая эффективность и доступность на физических устройствах ещё не измерены.
