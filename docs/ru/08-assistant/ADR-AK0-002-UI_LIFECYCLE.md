# ADR-AK0-002 — ленивый UI и границы контекста

Статус: реализовано в feature-кандидате; production approval отсутствует.

## Контекст и выбор

Большой индекс и UI не должны попасть в стартовый граф Nexus. Bootstrap удерживает hashchange до проверки сессии: обычный listener помощника может не получить исходное событие. Во время асинхронного render старый редактор ещё существует в DOM.

Выбраны ленивый import через существующий akronikl/context.js, закрытие окна на границе контекста, host.readReady и односторонняя invalidation до session recheck. readReady относится к согласованности UI, не к авторизации. Источники identity/ACL остаются прежними. Готовность выставляет только владелец render; помощник не восстанавливает её после ошибки сам.

## Альтернативы

Статический импорт bridge увеличивал критический граф до 76 модулей и нарушал существующий gate. Повышение лимита отклонено; импорт переведён на существующую точку входа, граф остался 75.

Ожидание окончания навигации для очистки окна оставляло устаревший контекст на экране. Один hash-listener недостаточен из-за session guard. Независимая копия авторизации в помощнике отклонена: она создала бы второй источник полномочий.

## Последствия и безопасность

Незавершённый import/поиск отменяется логически и через AbortSignal. Новый запрос не может наследовать старые данные. Закрытие локальной копии снимает доступ помощника до await сохранения; сама очередь сохранения не меняется. Смена Studio/workspace с одинаковыми файлами и ревизией всё равно меняет границу.

Цена: при смене раздела окно закрывается, история диалога не сохраняется. Скрытие вкладки не снимает render-ready навсегда. Model/BYOK и постоянная память не добавлены.

## Дефекты и эксперименты

| Проблема | Результат и решение | Регрессия |
|---|---|---|
| Новый статический модуль нарушил бюджет | FAIL startup; ленивый импорт без повышения лимита | 17 startup tests |
| Старый CSS-класс сжал окно | Снимок дефекта; уникальный класс akronikl-core-dialog | Геометрия 320–1366 px |
| Session guard удерживает hashchange | Очистка до recheck через событие без данных | UI/bootstrap test |
| Повторное открытие во время render | readReady до/после импорта и в host | Readiness suite |
| Асинхронный offline render сменил hash | Сверка sequence и исходного hash | Точный render-wrapper test |
| Закрытие копии ждёт сохранения | Готовность снимается до первого await | Lock-wrapper test |
| Повторный bind Studio | Сравниваются экземпляры Studio/workspace | 4 lifecycle tests |

## Rollback и приёмка

Main, backend и опубликованные поколения не менялись. До approval откат не требует переключения production: кандидат остаётся изолированным. Любой будущий merge должен пройти полную браузерную/PWA-приёмку и review additive-события bootstrap через MASTER 00.

Evidence и команды: MILESTONE_AKRONIKL_0_2_2026-10-26.md и review-комплект текущего этапа.
