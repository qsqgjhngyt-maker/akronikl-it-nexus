Только доверенное состояние `routine` допускает ненулевой юмор. Экзамен, безопасность, потеря данных, отказ доступа, неизвестное состояние и ошибка callback дают effectiveHumor=0. Ограниченное RU/EN-правило по тексту может только усилить осторожность.

**В штатном Nexus адаптер нового состояния ещё не подключён; по умолчанию используется unknown, то есть инструкция без юмора.** Routine/exam в браузерной проверке задавались синтетическим host. Это не доказательство распознавания реального экзамена и не обещание, что Qwen выполнит все ограничения. UI сохраняет выбранное значение, но неизвестная ситуация ограничивает его действие.
