## WHAT WAS PROVED

`readReady` запрещает открытие до завершения render и повторно проверяется после импорта. Отмена по границе контекста подавляет поздние ответы. Готовность страницы связана с её маршрутом и последовательностью render; прежний DOM не становится готовым для нового hash. Блокировка локальной копии снимает готовность до ожидания сохранения.

Контекст привязан к identity, маршруту, языкам, DOM-редактору, экземпляру Studio, объекту workspace, ревизии и активному файлу. Параллельная защита повторного bind редактора сохранена. Смена языка вне корня offlineApp также закрывает окно. Скрытие вкладки очищает окно, но не уничтожает принадлежащую приложению отметку готовности.

Bootstrap посылает одностороннее событие `nexus:context-invalidated` до удерживаемого hashchange и при lock. Событие только отзывает отображаемый контекст; оно не подтверждает сессию, не меняет ACL и не выпускает маршрут. Перед merge необходим review этой additive-точки интеграции через MASTER 00.

## SECURITY

Помощник не выполняет запись в progress/VFS/Cloud, код, административные или разрушительные действия. Внешние AI-провайдеры и model.generate в UI-адаптере запрещены. Для индекса используются фиксированные публичные URL, GET, credentials:omit, redirect:error и ограничение размера потока; запрос пользователя не становится URL или телом сетевой отправки. Ответы источников выводятся textContent.

Backend, OAuth, IAM, D1, cookie policy, server Account/ACL, service worker и release metadata этим кандидатом не изменены. Готовность DOM не является отдельным доказательством авторизации: проверяется актуальная identity приложения. Offline public mode не даёт доступа к закрытой личной копии.
