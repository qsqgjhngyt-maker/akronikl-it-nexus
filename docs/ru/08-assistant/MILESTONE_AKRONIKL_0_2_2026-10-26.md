## SECURITY

Панель не получает session credentials, не меняет Account/ACL и не читает все browser storage. Выбор кода ограничен текущим файлом и явно выделенным диапазоном. Данные не отправляются внешним моделям. Текст источников не интерпретируется как HTML или инструментальная команда. В тестах использованы только синтетические данные.

Изменение ссылки на Studio/workspace теперь немедленно делает host недействительным. При наблюдаемой DOM-мутации и при обращении к host старое состояние отклоняется. Произвольная замена JavaScript-свойства без события или DOM-мутации не является поддерживаемым способом интеграции: host уже недействителен, но визуальное закрытие требует уведомления/наблюдаемого изменения. Это остаётся явно описанной границей, а не обещанием слежения за всеми присваиваниями.

Завершённые тесты не доказывают отсутствие всех возможных ошибок безопасности. Перед real AI/BYOK нужен отдельный threat review и архитектура хранения ключей.

### Дефект AK02-LC-01

Проблема: новый Studio мог наследовать действительность host старого редактора при том же DOM-узле и совпадении ревизии/имени файла. Гипотеза: проверки объекта textarea недостаточно. Воспроизведение: три независимых теста с повторной привязкой/удалением binding — **3 FAIL до исправления**. Причина: отсутствовала проверка идентичности Studio/workspace. Решение: закрепить обе ссылки. Результат: прежние три и дополнительный четвёртый тест проходят; браузерный повторный bind также PASS. Протокол неудачного эксперимента сохранён в evidence-пакете.

### Дефект AK02-LC-02

Проблема из code review: `MutationObserver` видел только непосредственных детей root, а редактор расположен глубже. Решение: `childList + subtree` только на время открытой панели. Регрессия после исправления: браузерный тест удаления вложенной области — PASS. Отдельный браузерный baseline FAIL до изменения не получен, поэтому не заявляется.

### Ограничение среды AK02-ENV-01

Локальная среда Chromium блокировала навигацию политикой `ERR_BLOCKED_BY_ADMINISTRATOR`. Политику не обходили. Выполнен отдельный компонентный CI-тест без Account/backend. Полный E2E и холодный PWA этим тестом не заменены.
