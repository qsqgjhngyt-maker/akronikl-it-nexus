# ADR-AKP4-CONTEXT-001 — факт компилятора и контекст текущего урока

Дата: 28.10.2026. Статус: принято в изолированном implementation candidate; production не опубликован.

## Проблема

Штатный Sandbox уже получал сообщения компилятора, но UI-host Akronikl не передавал их Tutor. Чтение текста окна ошибок не давало бы надёжной связи с файлом, версией исходника и реальным пользовательским запуском. Старое сообщение нельзя использовать после правки, self-test или нового запуска.

## Решение

В момент штатного run создаётся одноразовый внутренний ticket. Он фиксирует конкретные Studio/workspace, ревизию и состав уже подготовленного runtime request. Текст отправленных файлов сравнивается с текущим workspace, но не копируется в долгоживущую запись evidence. При завершении принимается только текущий ticket с той же ревизией. Поздние результаты отклоняются.

В WeakMap сохраняется только первичная строка настоящей parsed compiler diagnostic с точными файлом, строкой и столбцом. Другие файлы, source snippets, stdin/stdout и полный журнал не сохраняются. Некорректные, неизвестные и слишком длинные сообщения отклоняются без усечения смысла. Provider-limit и self-test не считаются диагностикой проекта.

Каждый запуск/завершение/очистка меняет opaque boundary. Host проверяет его вместе с identity, маршрутом и экземпляром редактора. До передачи требуется отдельное разрешение на сообщение компилятора плюс существующее разрешение на выделенный код. Изменения согласия стирают историю и отменяют ответ. Модель получает только разрешённый selection и диагностическую строку; автоматически запускать компилятор она не может.

UI выводит факт отдельно от модельной гипотезы. Без модели факт остаётся доступным, но объяснение причины не выдумывается. Работоспособность generative adapter не заменяет оценку правильности разбора ошибки.

Текущий урок подтверждается точным совпадением courseId/lessonId/locale в подготовленном индексе. Task, прогресс и достижения не выводятся из маршрута. Файл/язык/ревизия показываются отдельно без перечисления проекта целиком.

## Альтернативы

- Читать HTML/текст панели ошибок: отклонено, нет доказательства происхождения и актуальности.
- Хранить весь compiler log: отклонено, он может содержать другие файлы и строки исходников.
- Доверять только номеру ревизии: недостаточно при повторном bind или нескольких run одной ревизии.
- Считать выбор кода согласием на весь compiler output: отклонено; вводится отдельный разрешённый объём.
- Давать без модели универсальный диагноз по ключевому слову: отклонено, сообщение компилятора и предполагаемая причина различаются.

## Границы доверия и ограничения

Ticket и WeakMap — механизм согласованности доверенных модулей приложения, не изоляция от вредоносного same-origin JavaScript. Новый модуль не меняет Account/ACL. Lifecycle очищает доступ и ссылки, но отдельного heap-snapshot доказательства полного GC нет.

Поддерживается одна первичная ошибка компилятора; warnings успешной сборки, runtime exceptions, весь multi-file анализ и автоматическая правка не добавлены. Отдельная проверка реального browser Clang/WASM и устройства необходима. В текущем browser-сценарии настоящий native g++ stderr доставляется fixture-провайдером в реальный Sandbox coordinator.

## Проверки и последствия

27 новых unit-сценариев охватывают повторное/устаревшее завершение, правку, self-test, другой workspace/файл, provider-limit, неизвестные пути и согласие. Четыре сообщения получены настоящим native g++. 9 новых browser-групп проверяют UI-путь без модели, отзыв разрешения, сохранность workspace и подтверждение урока. Прежние UX/Account/offline проверки повторно пройдены.

Отдельный старый multi-file-check падает и на baseline из-за неподдерживаемого в Node22 native WASM EH; результат сохранён, не засчитан PASS. Полная приёмка всех возможностей Nexus этим ADR не закрывается.

## Rollback / выпуск

Candidate остаётся в feature-ветке. Пока merge/deployment отсутствуют, рабочий сайт не затронут. Будущий release-пакет и точный rollback проверяются отдельно; этот ADR не разрешает откат пользовательских данных или очистку хранилищ.
