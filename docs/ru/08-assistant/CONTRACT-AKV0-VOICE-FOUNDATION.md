# AK-V0 — независимые TTS/STT и жизненный цикл голоса

Дата: 27.10.2026. Контракт подготовлен; адаптер и пользовательская озвучка PLANNED. Микрофон не нужен для режима «текст → голос». Ни AI/Voice-веса, ни внешние API не подключены.

## UX и согласие

По умолчанию текст → текст, звук выключен. Если реальный TTS-адаптер готов, у ответа появляется «Озвучить». Пока готового адаптера нет, рабочая кнопка не рисуется. Автоозвучка только по явному включению. Голос, язык, скорость и чтение кода/журналов — отдельные настройки. Микрофон включается независимо и только по пользовательскому действию. Выразительность не меняет текст фактов.

## Предлагаемые интерфейсы V1

TTS: `inspect()`, `listVoices()`, `speak({schemaVersion:1,requestId,contextRevision,text,locale,voiceId,rate},{signal,onState})`, `pause(requestId)`, `resume(requestId)`, `stop(requestId)`, `dispose()`.
STT: `inspect()`, `start({schemaVersion:1,requestId,contextRevision,locale},{signal,onTranscript,onState})`, `stop(requestId)`, `dispose()`.

Состояния: unavailable/idle/preparing/speaking/paused/listening/stopping/error. Capability descriptors явно указывают, что поддерживается; отсутствующие pause/resume не выдаются за работающие. Locality — verified-local/remote/unknown. Неизвестное местоположение обработки не маркируется офлайном. Remote STT/TTS требует отдельного согласия на внешний адрес; пока такие адаптеры не разрешены.

## Границы и отмена

Один владелец очереди на окно. Только окончательно принятый видимый текст может поступить TTS, не сырой JSON, не внутренние фрагменты генерации. Исключать секреты, свёрнутый личный код и журналы по умолчанию. Нет копирования диалога в публичный cache. Текстовый fallback сохраняется при любой ошибке.

Закрытие окна, смена аккаунта/контекста, блокировка копии, отзыв согласия и отключение TTS отменяют очередь и текущую речь. Новый requestId/contextRevision запрещает старые callbacks. Ошибка отмены не скрывается; до завершения cleanup новая речь не стартует. Конкретный адаптер должен доказать, что остановка не нарушает чужую озвучку Nexus; глобальный системный stop не считается безопасным без проверки.

STT-результат — недоверенный текст ввода, а не разрешение на действие. Распознанный текст показывается для проверки. Нет постоянного прослушивания или запуска административных операций. Озвученный помощником текст не должен сам запускать команду микрофона.

## Приёмка AK-V1

Сначала без микрофона: настоящая речь выбранного ответа, остановка/повтор, длинный ответ, код пропущен, RU/EN, отказ адаптера, late event после lock, смена аккаунта и взаимодействие с диктором ОС. Синтетические тесты lifecycle не доказывают наличие звука. Офлайн на ПК/iPhone/Samsung подтверждается физически для каждой комбинации голоса и браузера. Нельзя обещать фоновое воспроизведение после закрытия PWA или одинаковые голоса на всех устройствах.

AK-V2 (голосовой ввод) и AK-V3 (собственный голос) остаются отдельно. H1 и Personality не зависят от TTS/STT.
