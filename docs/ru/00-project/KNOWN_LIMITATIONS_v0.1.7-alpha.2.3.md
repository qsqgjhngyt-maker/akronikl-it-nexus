# Known Limitations — v0.1.7-alpha.2.3

## Identity
Current runtime still uses alpha `nexus-token` Cloud Sync auth. Identity v2 is design-only.

## Session security
Current token-in-browser storage remains accepted alpha debt and is not target public-auth architecture.

## Cloud Sync
Manual PUSH/PULL is current. Background/offline reconciliation is not complete.

## Conflict handling
Conflict detection/recovery is implemented, but automatic three-way merge is not.

## Team
ACL/schema foundation exists; full invitation/member UX is not production-complete.

## Learning state
Progress is still primarily browser-local. Account-bound cloud progress is planned.

## Skill Graph / Learner Model
Research/design only.

## AI
No production LLM gateway, RAG, Learner Model, Recommendation Engine or AI provider is introduced by this release.

## Admin / CMS / Support
Planned only.

## Competitive research
WORK07 is a dated public-source snapshot, not proof that competitors lack unconfirmed features.

## Research
No participant experiment has yet validated Nexus AI hypotheses.
