# Четвёртый модуль C17 в PR #66

Четыре урока «Массивы и базовые алгоритмы» добавлены на русском и английском. Начинающий ученик связывает индекс с длиной, передаёт массив вместе с числом занятых элементов, ищет минимум и первое совпадение, затем сортирует копию измерений. Теперь доступны 23 темы.

Задания используют фиксированные массивы вместимостью до восьми элементов. Наборы длины 0, 1 и 8, отрицательные значения и повторы разбираются на наблюдаемых примерах. Ошибки в заготовках дают неверное или неполное вычисление при допустимых обращениях к массиву. Недопустимые индексы отклоняются до чтения элемента.

Для сортировки ученик проверяет исходную строку и отсортированную копию. Контроль повторов помогает заметить случай, когда вывод упорядочен, но потеряно или заменено значение. Правила сравнения, границы и ожидаемые результаты доступны на обоих языках.

Допуск M4 фиксирует отдельный список путей поверх принятого M3 `03cb97482be373a3efb9674ac630040b0a9786ff`. CI сверяет порядок курса, прежние уроки, исходные правила R1–M3 и точный Git tree. Браузерные проверки подтверждают переход M3 → M4, сохранение работы и повторное чтение уроков без сети. Понимание материала учащимися оценивается отдельно.
