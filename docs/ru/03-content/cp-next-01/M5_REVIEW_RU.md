# Пятый модуль C17 в PR #66

Четыре урока «Строки и текст» доступны по прежним ID в программе C17 на русском и английском. Ученик собирает строку с завершающим нулём, проверяет границы строки при чтении, сравнивает ключи и реализует консольный фильтр строк.

Ручные контрольные входы выполняются в редакторе урока. Случаи с NUL, одиночным CR и CRLF подписаны по байтам и проверяются автоматической матрицей Clang/WASI. Разбор отдельно показывает EOF без завершающего перевода строки и границы UTF-8 в байтах. Тесты заготовок дают наблюдаемый результат на безопасных исходниках.

Допуск M5 фиксирует отдельный список путей поверх принятого M4 `05cb4f09c0d47dd66b91b167e288c9d001fde47c`. Правила и доказательства R1–M4 сохранены. Тесты сверяют прежний порядок, точные исходники, переход M4 → M5, восстановление черновика и чтение без сети. Изолированный PERF-01 проверяется отдельно. Понимание материала учащимися оценивается отдельно.
