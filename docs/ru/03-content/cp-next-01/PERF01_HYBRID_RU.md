# PERF-01-R3 · Гибридная загрузка Академии

MASTER выбрал вариант A для финальной технической проверки. База — R1 `ad12a8915d099df0b42f1eb79a79302125780e9b`. Состояние интеграции — HOLD. [Исходная история PERF-01](PERF01_REVIEW_RU.md)

Критическое представление Академии загружается вместе с оболочкой. Карточки, поиск и фильтры строятся из прежнего канонического каталога. Главная и Академия используют один проверенный C++ outline. Лабораторные и практики загружают свои представления по маршруту. Функция создания копии учебного проекта загружается при открытии шаблона. Перед записью действует прежняя проверка маршрута внутри штатного механизма записи проекта. Общие представления и функции возобновления используют один модуль. Автономная оболочка получает прежние экспорты discovery.

Стартовый граф 601 842 байта, 71 модуль. Запас по действующему лимиту 640 000 — 5,9622%. Бюджет и способ расчёта те же. Границы компиляторов, Qt, Code Hub, Code Studio и полных материалов курсов сохранены. Код проверки сессии, политики Service Worker и хранения данных сохранил точные байты R1.

В предварительной лабораторной сверке на 320×760 медиана готовности составила 119,65 мс у варианта A и 162,10 мс у R1. В шести сбалансированных тройках на локальном Chrome p90 совпадает с максимумом. Из расчёта исключили целиком одну тройку после ошибки `ASSET_SIZE_MISMATCH` при установке Service Worker, затем её повторили тем же порядком. Исключённые строки сохранены. Отдельная проверка на синтетическом аккаунте подтвердила поиск, фильтры, лабораторные, практики, повторное открытие шаблонного проекта и `publicReady`. Результаты лабораторные.

Проверки сохраняют неизменённую цепочку M4 → R1 и сверяют отдельный [набор точных хэшей R3](PERF01_HYBRID_BYTES.json). Изолированный браузерный сценарий проверяет один запрос критических модулей, отсутствие Labs и Practices в запросах Главной и корректный отказ от просроченного рендера Labs.

Перед приёмкой нужны полный комплект CI, 34 показателя исходного протокола, независимая регрессия 05 и анализ воспроизводимости ошибки установки SW. Интеграция с курсом C17 требует отдельного решения MASTER.
