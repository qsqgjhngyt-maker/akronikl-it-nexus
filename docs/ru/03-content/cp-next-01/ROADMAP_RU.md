## Очередь

В кандидате CP-NEXT-01 к исходному срезу добавлена отдельная карточка C. Теперь в исходном каталоге 55 записей и 49 ученических карточек, из них четыре доступны. Поле `count` приведено к размеру массива. В Code Hub по-прежнему 24 трека, пара записей `c` в каталоге и Code Hub ведёт на один маршрут `#course=c`. Доступен только первый модуль из девяти уроков. Строки ниже описывают направления на исходной точке и их дальнейшее развитие.

- **P0** — C и регрессия трёх действующих эталонов. По C этот этап охватывает первый модуль кандидата. Остальная программа остаётся запланированной. Эталонные уроки получают адресные правки по подтверждённым дефектам.
- **P1** — Python → JavaScript → базы данных и SQL → алгоритмы и структуры данных. Python даёт учебные скрипты и базу для данных. JavaScript открывает интерактивный веб. SQL нужен отчётам и аналитике. Алгоритмы после первого языкового маршрута опираются на знакомые ввод, коллекции и тесты.
- **P2** — инженерная база, типизация, автоматизация, базовые математика и анализ. Практики связываются с результатами предметных модулей.
- **P3** — прикладные и инфраструктурные направления после подтверждения нужных провайдеров и учебных стендов.
- **P4** — распределённые, мобильные, научные и продвинутые AI-треки. Для их практики нужны отдельные подтверждения среды, данных и эксплуатационных ограничений.

В таблицах `L:` обозначает трек Code Hub. Входные знания описывают уровень ученика, зависимости определяют порядок подготовки курсов или материалов. Обозначение **план** перед средой означает предложение для проверки. На исходной точке WASM-провайдер объявляет C и C++, а готовность сквозного учебного сценария C проверяется отдельно. У Secure Build Runner `available() = false`. Учебный клиент 1С остаётся самодостаточной внешней средой для действующих курсов.

Для каждой новой строки проверяем семантически согласованные RU/EN, стабильный ID, доступные маршруты, объяснение с разбором, самостоятельная задача с проверяемым результатом, подтверждённое поведение среды, диагностика ошибки и восстановление работы. Дополнительный критерий по предмету содержится в последней колонке. Состав и размер предлагаемых модулей уточняются при авторинге. Физическая мобильная проверка и учебный эффект фиксируются по собственным результатам.
