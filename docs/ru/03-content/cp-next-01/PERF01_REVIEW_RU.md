# PERF-01 · Стартовый граф, навигация и обложки блога

База сравнения — M4 `05cb4f09c0d47dd66b91b167e288c9d001fde47c`, 639 898 байт и 77 стартовых модулей. Действующий проверяющий скрипт и его пределы 640 000 байт и 80 модулей используются для обеих версий. Программа курсов и учебные материалы сравниваются с тем же исходником.

Академия, Code Hub и домашняя страница Code Studio загружают своё представление при переходе. Тяжёлые модули и курсы открываются по существующему маршруту. Запросы независимых зависимостей запускаются вместе, готовность текущего маршрута проверяется перед показом. Автономный вход использует прежнее представление Code Hub с явной передачей зависимости.

В ленте блога подсказки для выбора размера обложки соответствуют ширине карточки. Медиатеки, публичные производные изображения и права доступа сохраняются. Синтетический эксперимент каталога подставляет дополнительные записи только в процессе локального измерения.

Для воспроизведения измерений используется та же чистая локальная сборка, что в проверках браузера. Путь к ней передаётся через `NEXUS_FRONTEND_DIR`, путь к репозиторию через `NEXUS_REPO`, версия через `NEXUS_PERF_SOURCE`, путь отчёта через `NEXUS_PERF_REPORT`. Нужны те же Chrome, Playwright, сертификат из изолированной фикстуры и закреплённые ресурсы, что для CI C17. В `tools/measure-nexus-performance.mjs` фиксируются три ширины и исходные результаты повторов. `tools/check-academy-scalability-browser.mjs` измеряет разметку и вставку синтетического каталога отдельно от навигации. Эти измерения выполняются в лабораторном стенде.

Точный перечень путей, дерево и цепочка проверяемых хэшей проверяются в CI. Пакет продолжает историю R1–M4.
