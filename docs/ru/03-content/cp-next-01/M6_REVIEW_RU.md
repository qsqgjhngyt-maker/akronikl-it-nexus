# Модуль C17 «Указатели, адреса и границы памяти»

Пять уроков RU/EN открывают адрес и разыменование, указатели при обходе массива, изменение объекта через параметр, `const` и `NULL`, время жизни объектов. Договоры проверяются перед обращением к памяти. Результаты практики используют значения объектов. Конкретные машинные адреса для проверки вывода не нужны.

Пример возврата адреса локального объекта читается как диагностика компиляции. Заготовки для запуска используют живые объекты и проверенные диапазоны. Разбор показывает, где должен завершиться проход, что происходит при отсутствующем аргументе и когда результат разрешено записать.

Новый точный допуск начинается от принятого M5 `842bdcc291bd7c0313b33849223c5fd4ba38c3c3`. Матрица браузерного Clang/WASI делится на две части с одинаковым исходником и пакетом. Каждая часть выполняет ровно половину заявленных запусков по индексу запроса. Вместе они покрывают все 290 уникальных запросов и 580 ожидаемых результатов. Проверка native, UI и автономного режима проводится в первом задании.

PERF-01 ведётся отдельным черновиком. Понимание материала реальными учащимися остаётся отдельной проверкой.
