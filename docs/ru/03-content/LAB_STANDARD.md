# Стандарт лабораторной работы

Лабораторная содержит: цель, prerequisites, постановку, исходные данные/ограничения, этапы, критерии готовности, набор проверок, подсказки уровнями, ожидаемые артефакты, рефлексию и связь с Skill Graph.

Akronikl не должен сразу выдавать готовую лабораторную. Режим помощи: диагностика → наводящий вопрос → частичная подсказка → полный разбор по явному запросу.
