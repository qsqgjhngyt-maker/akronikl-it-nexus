Причина ограничения самого порта не исследовалась и не выдаётся за установленную причину Windows.

3. Проверка окна подготовки: тест считал ссылки сразу после запуска асинхронной загрузки JSON и получил ложный отказ. Добавлено ожидание видимого диалога; содержимое и все загрузки затем проверены отдельно по HTTP и браузером. Семантические assertions и защиты не ослаблены.

Частные platform logs, пути учебной базы, профили и содержимое лицензионной диагностики в общий пакет не включены. Результаты относятся только к собственным синтетическим данным.

Список изменённых файлов переведён на NUL-разделение (`--name-only -z`), которое сохраняет точные имена. Разрешённая область не расширена за review/cpp-clarity-r3, защита всех 1С-деревьев и остальных областей сохранена. Ранний PASS до staging не выдаётся за проверку полного пакета.

11. Клавиатурная проверка списка файла открывала его Enter после выбора Home и сразу ожидала Tab в редакторе. Первый Tab закрывал системный список. ### Уточнение общей CI-регрессии

На implementation SHA f3ccc20 общая 1С CI обнаружила также устаревший производный индекс C++ и проверку, которая искала перенесённые обработчики редактора в app.js. Индекс RU/EN и manifest детерминированно пересобраны существующим генератором без изменения формата, API и правил поиска. Проверка Code Studio теперь проверяет фактические shared views и lazy session; требования к редактору сохранены. Обе проверки включены в обязательный CPP-CLARITY gate: 116 unit PASS, 11/11 групп PASS. Ранее сохранённые 97-тестовые отчёты являются историческими поднаборами.

Оставшиеся отрицательные проверки общей 1С CI имеют отдельный смысл: ONEC_HISTORICAL_ROUTE_UNIT и ONEC_STUDIO_UNIT отклоняют неутверждённые новые bootstrap bytes; ONEC PRESERVATION не допускает ветку CPP-CLARITY в прежнюю область чисто 1С-публикации. Ни эти допуски, ни публикационный маршрут не расширялись. Старые Gold jobs также не заменяются целевым CPP-CLARITY gate. Статус всего PR нельзя обозначать SUCCESS по одному целевому workflow.
