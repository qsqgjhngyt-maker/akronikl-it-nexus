# 1С P1 — кандидат на содержательную проверку

STATUS: IMPLEMENTED / локальные AUTOMATED PASS. Содержательная приёмка MASTER и понимание учащимся отдельно. Точный SHA, CI и адрес просмотра фиксируются в передаче после коммита; этот документ не предсказывает их результат.

Четыре темы `onec.p1.architecture`, `onec.p1.infobase`, `onec.p1.lifecycle`, `onec.p1.tools` теперь последовательно связывают объяснение, пример, собственный прогноз, трассировку, изменённое условие, самопроверку и новое действие ученика. Новая подача хранится в восьми отдельных авторских JSON; сборщик проверяет SHA256 исходного урока. Все прежние исходники обоих курсов 1С, 67 тем C++ и три R3 сохранены побайтно относительно c72e65a.

Самостоятельная работа жизненного цикла показывает два новых сообщения в одном обработчике, затем меняет второе и повторяет запуск. В инструментах разобраны 30+45=75 и отдельное реальное наблюдение 20+35=55; новая задача исправляет 18−27 на 18+27=45 и переносит правило на 40+25=65. Заготовка, эталон и текущий код различаются. Открытие примера, эталона, подсказки или рабочего окна не подменяет редактор. В ручных заданиях эталон объясняет решение без фиктивного программного файла. Четыре choice-вопроса имеют тот же порядок в selfcheck и assessment; старые попытки сохраняются, открытие урока не создаёт завершение.

Наглядность: четыре локальные SVG-схемы RU/EN, текстовые альтернативы, проверенные исходные снимки создания/режимов/выгрузки и новые подлинные снимки собственного Конфигуратора. Настоящий отладчик показал 20,35,55; затем настоящий клиент показал сообщение 55. Пропущенная кавычка проверена отдельной командой «Проверка модуля»; рабочий текст восстановлен. F7 обновляет конфигурацию базы данных; это не команда синтаксической проверки. Фото не синтезированы и не изменены; увеличенная область и указатели формируются отдельно. На 320px сохраняется исходный масштаб полезной области с горизонтальной прокруткой и ссылкой на оригинал.

В R65_VISUAL_EDU_MATRIX.json есть отдельная строка каждого из 151 ID. Для P1 зафиксированы необходимые материалы и техническая проверка. Для прежних C++ сохранён CONTENT ACCEPT, но новая визуальная приёмка не приписывается автоматически. Дальнейшие блоки обоих курсов проходят этот критерий до сдачи.

Общий экран и существующий Account/Studio adapter сохранены. Для двух программных тем доступно «Задание и Code Studio» после явного создания своего черновика; настоящий BSL запускается в установленной 1С. Browser Studio не синхронизирует код с Конфигуратором. Самоотчёт о внешнем запуске не является измерением платформой. Новый writer/runtime не создавался. Локальная offline-оболочка теперь открывает публичные темы обоих курсов 1С без авторизации и без доступа к C++ vault; личные элементы там отключены.

Проверки: общий технический gate; отдельные тесты P1; восемь редакций × три этапа × 1366/390/320; реальные изображения и подписи; размер и границы SVG-текста; семантические подсказки с возвратом выделения; отдельный редактор, эталоны и сохранение RU→EN; попытка 4/4 без автоматического завершения; новое окно браузера при отключённой сети; регрессия прежних R3, аккаунтов, конфликтов и повреждённых данных. Предварительные неудачные проверки сохранены отдельно.

Границы: тестовые аккаунты синтетические; серверный вход, пользовательские базы, физические устройства, полный screen reader и понимание реального учащегося не измерялись. Нативные наблюдения 55 и диагностика относятся к точному учебному экземпляру, не доказывают выполнение всех новых самостоятельных работ.
