Объяснения организованы по смыслу каждой темы. Ученик прогнозирует результат до раскрытия разбора. Код, фактический ввод и ожидаемый вывод находятся рядом. ## Конечные материалы и сохранность

Уточнение владельца: далее единица работы — целый учебный блок программы, без добора до условных десяти тем. Следующим идёт «Алгоритмизация»: восемь тем от cpp.programming-process до cpp.languages-compilation-debugging, по порядку и с сохранением принятого входного образца. B01 завершён по границе модуля «Основы C++»: от cpp.first-cpp-program до cpp.standard-io, все 12 тем по порядку. Две оставшиеся темы добавлены после явного подтверждения владельца; прежние десять редакций RU/EN сохранены относительно d551c75047c0e21a16d0fba49e4c8fd340975e7b.

- Авторские источники — courses/cpp/gold/basics/*.ru.json и *.en.json, поле teachingEdition.
- Генератор переносит полные sections, selfcheck, practice и reading только для явного списка этого блока. Новые темы за пределами списка не включаются автоматически.
- Новый материал имеет revision b1-author-v1. Старые predict/explain ID сохраняются; старые ответы остаются читаемыми, но не считаются проверенными по новому условию.
- Открытие примера или recall не создаёт новую работу поверх существующей. Возвращаются тот же редактор, выделение, фокус и введённые данные.
- При проверке новой локальной копии выявлено повторное монтирование одной темы после разблокировки: отменённый экран оставлял обработчики на общем контейнере и выдавал R3_CONTEXT_CHANGED при переключении этапов. Теперь отменённое монтирование освобождает обработчики и observer; поздний результат не заменяет текущий controller в обычной и offline-оболочке. Формат хранения и session/Account/vault contracts не изменены. Адресный браузерный тест воспроизводит три ошибки до исправления и проверяет отсутствие ошибок после него; общая регрессия сохранения остаётся обязательной.
- Подсказка ведёт к соответствующему правилу или другому разобранному примеру. Код эталона самостоятельной задачи находится в авторском источнике для проверки, не в пользовательской заготовке.
- За пределами одиннадцати переработанных тем сохранены 280 из 302 конечных редакций, включая принятые «Типы данных» и три R3-образца. Сравнение выполняется с предыдущим кандидатом, а не с production.
- Сохраняются 67 C++ ID и 40 legacy ID, остальные курсы, маршруты, проекты, runtime, ограничения размеров и производительности. Личные данные не используются.
- Индекс локального помощника пересобирается с SHA256 pin манифеста. Проверка целостности не ослабляется.

## Проверки: что считается доказательством

tests/cpp-clarity-b1-content.test.mjs проверяет источники, языки, цели, ревизии, границы блока и неизменность принятых материалов. Пересборка сравнивает все 302 ресурса; вне блока не допускаются изменения.

tests/cpp-clarity-b1-browser.mjs проверяет обычный маршрут локальной Академии. Для каждого разбираемого кода он извлекает фактический source/stdin/expected из DOM и сравнивает с источником. Затем исполняет эти программы настоящим Clang/WASI. Отдельно исполняются код вопроса-прогноза и привязанные эталоны/граничные случаи. Ожидаемые отказы компиляции не выдаются за успешное выполнение. Намеренно переставленный expected должен быть отвергнут.

В браузерный проход входят RU/EN, 1366/390/320, неверный ответ и повторная попытка, собственное объяснение, возврат из recall, тот же редактор и курсор, переходы, принятый образец и сосед вне блока, полный перезапуск без сети, разблокировка, сохранённые код/stdin и реальный запуск. До/после снимаются в одной оболочке на тех же размерах. Эмуляция размера не является испытанием физического телефона.

tools/check-cpp-clarity-b1-host.mjs независимо запускает конечные записи в host C++20 с UBSan. Старые тесты runtime, Account adapter, vault branching/quota, исторических попыток и всех 302 редакций остаются в workflow; отсутствующий или неудачный тест не объявляется PASS.

Точный SHA, фактические результаты и архив evidence фиксируются в описании PR и отчёте конкретной сборки после коммита. Предварительный проход рабочей копии отделяется от прогона точного SHA.

## Preview и границы допуска

Просмотр — отдельная синтетическая локальная копия в отдельном Chrome. Физические Android/iPhone, настоящий Account и OAuth, Qt, реальная учебная 1С, измерение понимания — NOT RUN в этом блоке. Не объявлять общий FULL LIVE PASS.

Изоляция выпуска относительно реально развёрнутой версии и цикл обновление → изменение работы → rollback → чтение → повторное обновление ещё не доказаны. Сборка остаётся preview. Текущий PR содержит накопленные прежние изменения; его нельзя назвать изолированным производственным выпуском только этих двенадцати тем.
