# Как посмотреть R3 на этом ПК

В PowerShell выполните одну команду:

```powershell
& 'C:\Users\User\.codex\visualizations\2026\11\04\01a1a774-f585-7bb1-ab20-238357b7c5b7\cpp-clarity-r3\START_CPP_CLARITY_R3.cmd'
```

Откроется обычный Chrome с отдельным профилем. Проверенный адрес: http://127.0.0.1:47653/ . Вверху выберите один из трёх образцов и RU/EN. «Объяснение», «Самопроверка», «Практика» доступны свободно. В подготовке BSL находятся полные файлы и последовательность действий в 1С.

Команда обращается к `tools/START_CPP_CLARITY_R3.cmd` существующего checkout PR #65; самостоятельный запуск из корня checkout: `tools\START_CPP_CLARITY_R3.cmd`. Нужны уже установленные на этом ПК Node.js и Chrome. Сервер слушает только 127.0.0.1, проверяет совпадение отпечатка ресурсов; чужой процесс на занятом порту не останавливает. Проверен холодный запуск и повторное открытие. Закрытие браузера не останавливает собственный фоновый сервер.

Это экран для review трёх новых уроков. Он не опубликован. Аккаунт и рабочие данные не подключены. Внутри открытого окна сохраняются код, ответы, файл, stdin, результат и позиция при переходах. Обновление/закрытие окна теряет демонстрационные черновики: перед выходом скачайте свой файл. Запуск кода здесь пока не подключён; BSL выполняется отдельно в установленной 1С, результаты в экране вводятся как самоотчёт. Учебная сборка 1508 и физические телефоны не проверены.

Соседи вне трёх образцов показывают границу review. Ссылки на прежнюю тему/главную/Studio ведут на отдельный R2-стенд 63368, который запускается прежним комплектом R2. Он не нужен для просмотра трёх образцов R3. Полная штатная навигация, Account, private persistence и runtime R3 относятся к следующему согласованному пилоту. Нельзя считать техническую проверку методической приёмкой.

После принятия этапа A используйте текущий manifest schemaVersion2: sha256-json-path-sha256-utf8-order-v1, digest ddbdb20194911fb5999fd6aa307c95314c5751a314d937324b171eb78c3c97b1. Принятые18 ресурсов те же; устранена зависимость порядка путей от языка ОС. Для явной регенерации manifest из корня checkout: node tools/build-cpp-clarity-r3-manifest.mjs --write; обычный запуск без --write только сверяет его.
