Они сохранены для аудита, НЕ являются самостоятельной инструкцией повторного запуска. Не запускайте их поверх доказанного стенда: в них зафиксированы исходные абсолютные пути. Их первоначальные промежуточные состояния не заменяют канонический финальный source fixture.
