Текущие исходные уроки уже содержат сильные тексты, два разобранных примера, официальные маршруты и реальные изображения. Их нужно связать с прогнозом, изменённым условием, трассой и новой самостоятельной задачей без инженерных журналов внутри объяснения. Исходные файлы, nativeGuide, nativeCaseIds, nativeEvidence, изображения и источники сохраняются побайтно. Новая редакция хранится отдельно в courses/clarity/authoring; общий сборщик применяет её только к согласованным четырём Topic ID. Это сохраняет прежний упакованный комплект 1С без роста его JSON и не добавляет авторский исходник в старые native-контракты.

Сохранность защищается точным набором восьми новых авторских файлов и восьмью производными уроками, неизменностью всех старых исходников 1С и принятых C++/R3. Авторская редакция фиксирует путь и SHA256 первоначального урока. Стабильные вопрос/ответ сохраняются; новый прогноз имеет отдельный ID и contentRevision. Переход «Вспомнить правило» связан с конкретным объяснением.

Оценочная матрица assessment.quiz должна содержать те же четыре choice-вопроса в том же порядке, что новая selfcheck; оставлять прежнюю тройку при добавлении прогноза нельзя. Существующий store принимает отдельную ревизию и сохраняет старые попытки/историю прохождения. Новый контракт записи для этого не нужен.

Учебный экран использует тот же контекст «курс / тема / этап». BSL выполняется в официальной установленной 1С, браузерный Studio — необязательный исходник; автооценка внешнего запуска не заявляется. Эталон для ручного задания — ход рассуждения и ожидаемые наблюдения, для кода — отдельный исходник. Просмотр эталона/примера не подменяет работу. Рабочее окно с Studio добавляется там, где есть необязательный черновик; без кода не создаётся фиктивный запускаемый файл.

Риски/ограничения: nativeEvidence первой версии не переносится на новое задание автоматически. Исторический startup-фрагмент 8.3.27.1508 имел completion observer, но видимое сообщение в гостевой среде не наблюдалось независимо. В официальном 8.3.27.2214 есть снимки интерфейса; они исторические, не новые измерения. Новая внешняя проверка должна указывать реальную среду и границу доказательства. Рабочие базы владельца не подключаются.

Проверки: источник/производный текст RU/EN, 8 учебных редакций × 3 этапа, прогноз/подсказки/фокус, подписи примера/ожидания, 1366/390/320px, native-рисунки и подготовка, необязательный черновик/самоотчёт и холодный offline, сохранность старых попыток/проектов. Проверка содержания MASTER и понимание учащегося отдельны.

Есть материал для диплома: смешанный курс с настоящей внешней средой, недоказанность runtime по одной подсветке, сохранение истории и границ старого evidence. Merge, deployment и Release не разрешены.
