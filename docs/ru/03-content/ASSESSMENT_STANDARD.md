# Стандарт оценки

Оценка понимания не должна сводиться к одному тесту с вариантами ответа.

Используются: quick checks, предсказание результата, поиск ошибки, объяснение своими словами, изменение кода, написание фрагмента с нуля, лабораторная и проект.

Skill mastery рассчитывается по нескольким сигналам и хранит происхождение оценки. Один случайный правильный ответ не должен делать навык «освоенным».
