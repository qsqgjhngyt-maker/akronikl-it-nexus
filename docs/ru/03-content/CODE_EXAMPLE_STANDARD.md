# Стандарт примеров кода

Каждый значимый пример содержит: задачу, предположения, код, ожидаемый результат, объяснение, ключевые состояния/инварианты, варианты изменения и типичные поломки.

Пример не считается проверенным, если его только «визуально прочитали». Для доступных toolchain примеры должны компилироваться/выполняться автоматизированно либо иметь явно указанную причину, почему это невозможно в текущем стенде.

Небезопасный/UB-код допускается только как отрицательный пример с явной маркировкой.
