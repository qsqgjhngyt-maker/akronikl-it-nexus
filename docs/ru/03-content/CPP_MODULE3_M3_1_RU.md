## Неудачные эксперименты и исправления

1. В первой редакции общее имя apply конфликтовало со std::apply через ADL: 31 из 206 старых проб не собрался. Имена заменены на executeStock/applyCommand. В финале оба настоящих компилятора прошли 223/223 актуальных случая. Ожидания не подгонялись.
2. Промежуточный прогон прошёл 223 C++ случая, но тест UI заполнил stdin прежнего экрана до завершения перехода в Project Studio. Тест теперь ждёт уникальный элемент проекта и проверяет исходник/ввод до запуска. Аналогично исправлено чтение VFS после ленивого перехода к Gold-уроку: требуется точный data-gold-lesson ID; старый прогон сравнил файл предыдущего проекта 7 с ожидаемым файлом урока 6. Полный финальный CI подтвердил каждый маршрут и проектный roundtrip. Production эта ошибка теста не затрагивала.

3. Рекомендация без bookmark использовала физический массив, поэтому после старых 23 тем пропускала functions-contracts. Порядок выбора и видимых номеров переведён на section.lessonIds без изменения legacyIndex/order. Полный 45-шаговый unit-контроль и actual online/cold Offline кнопка подтвердили исправление.
