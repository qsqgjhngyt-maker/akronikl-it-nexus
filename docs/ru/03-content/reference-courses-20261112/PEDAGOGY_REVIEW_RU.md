# Редакторский review двадцати редакций

Статус: внутренний редакторский review, не приёмка методиста и не эксперимент с независимыми начинающими.

Рубрика для каждой пары RU/EN: понятная цель; все обязательные prerequisites введены в маршруте; определение до применения; пример и результат рядом; прогноз/объяснение; одно контролируемое изменение; типичная ошибка и восстановление; новая самостоятельная задача; проверяемый результат; честная граница feedback. Наличие текста и зелёный CI сами по себе не означают понятность.

| Урок | Проверенный разрыв и принятое исправление |
|---|---|
| Входной C++ | Зачем писать программу и почему компьютер не угадывает; наблюдаемый текст → исходник → компиляция → запуск. История опирается на автора языка. |
| Первая программа | Заголовок, библиотека, main, скобки, cout, перевод строки, return вводятся до изменения сообщения. Самостоятельные строки другие. |
| Типы | Объявление вводится перед его использованием. 37/2 и37/2.0 объясняют исчезновение половины минуты; самостоятельные18+23 дают20.5. |
| Переменные | Начальное значение120, затем новое70; создание отличается от изменения. Допустимые имена и область действия разобраны явно. Новая задача: четыре набора по25, один отменён. |
| Устройство1С | Платформа/конфигурация/база/два режима/Nexus не смешиваются. Подготовка новой пустой базы включена, скрытого требования infobase нет. |
| Первое сообщение1С | Указан модуль управляемого приложения, событие и фактический порядок F7/F5. Сообщить не считается выполненным за запись заметки Nexus. |
| Первый расчёт1С | Число и строка, присваивание и вывод вводятся локально. Самостоятельный расчёт12+18 отличается от30+45. |
| Учебная служба | Объяснено, куда загружается CF и как проверить новую отдельную папку. Рабочая база не нужна. |
| Клиент | Имя, код и идентичность различаются через переименование той же записи; новая карточка не равна переименованию. |
| Заявка | Клиент и услуга выбираются из списков, поля записываются и открываются заново; отказ без клиента не выдан за успешную запись. |

RU/EN сохраняют одинаковые действия, числа, вопросы, ID, примеры и критерии. Английская редакция объясняет русские имена BSL и подписи учебной конфигурации; не обещает англоязычную установку1С.

Повторная проверка выявила и устранила пропущенное соседнее наблюдение у блока режимов1С, метаданные entryFile у C++ примеров и неясное продолжение маршрута. Развёрнутые словари дополняют первое объяснение в уроке; не заменяют его.
