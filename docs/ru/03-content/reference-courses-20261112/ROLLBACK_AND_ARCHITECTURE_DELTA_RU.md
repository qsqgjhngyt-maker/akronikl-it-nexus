# Архитектура, совместимость и откат

До: три этапа с разными legacy адаптерами справки; broad pre CSS; контекстная навигация в скрытом меню; неясная граница запуска и проверки. После: общий текстовый адаптер справки, lazy карточки, ограниченная CSS область, план маршрута на прежних ID, явные основные действия и оценка текущего снимка.

План маршрута — только presentation: `learningRoute=reference-start` выбирает4/3/3 эталона; отсутствие параметра выбирает действующую программу. ID, глобальный порядок, проекты и Learning Events не меняются. Переход проходит прежнюю prepareNavigation/flush-очередь. Валидация цели и результата не превращается в Mastery.

Новая разрешённая редакция десяти тем получает новую contentRevision. История и работа сохраняются; прежний ответ/самоотчёт не становится новым зачётом. Формат draft/session/account/runtime не расширен.

Исторические guards и receipts S1/P4-Q не переписываются. Исторические assertions проверяются на собственном сохранённом коммите; текущий непубликованный scope проверяется по `9a01de88dac94729b0bb232fb18bd6de49e7507d`, точным old/new SHA и отрицательным контролям. Это не новый допуск выпуска. FULL classifier и private-deny сохраняются. Pin Ubuntu24.04 исправляет только совместимость QA с закреплённым браузером.

Откат локального кандидата: закрыть только его сервер и запустить прежнюю собранную директорию; текущие данные не удалять. Откат исходников — отдельные обратные коммиты выбранных изменений после фиксации diff, без force/reset. Production сейчас не переключается; прежний composite/rollback и книга/блог/логотипы сохранены.

Есть ли материал для диплома? Да: пользовательская диагностика, причина CSS-регрессии, адаптация строковых/объектных терминов, граница технической и педагогической оценки, безопасная миграция редакций и измерения до/после. Эффект на независимых учащихся пока не измерен.
