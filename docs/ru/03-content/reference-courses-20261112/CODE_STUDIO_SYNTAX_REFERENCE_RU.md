# Справочник C++ во время работы над проектом

Прямое поручение владельца 13.11.2026: справочником должно быть удобно пользоваться во время написания проекта. MASTER принял опубликованное исправление загрузки Code Studio (C7) отдельно и разрешил подготовить это дополнение в существующем PR #65.

## Поведение

- По уточнению владельца кнопка «Синтаксис» / «Syntax» находится в правом нижнем углу, как справка в уроках C++. Используется прежнее оформление `lesson-floating` / `quick-action`; кнопка поднята над помощником и имеет читаемую подпись на телефоне. При открытой панели её заменяет доступное закрытие в заголовке, чтобы плавающая кнопка не закрывала карточки.
- На широком экране открывается правая колонка. Редактор остаётся доступным: можно читать карточку и печатать одновременно. Затемнения, модального окна и блокировки проекта нет.
- На узком экране справочник размещён над редактором, занимает не более 55% высоты окна и прокручивается внутри. Заголовок и закрытие доступны; панель не накладывается на код.
- Поиск учитывает название, синонимы, объяснение и форму записи. Выделенный в редакторе короткий фрагмент становится первоначальным запросом.
- Используются прежние 36 C++ карточек RU/EN из `courses/reference/cards.*.json`: форма записи, пример, разбор, наблюдение, типичная ошибка и первоисточник. Это справочник основ, а не полное описание стандарта C++.
- «Копировать пример» использует буфер обмена. Пример не вставляется в проект автоматически.
- Закрытие справочника и Escape внутри него возвращают фокус и сохранённое выделение. Код, файлы, ошибка сохранения и несохранённый черновик остаются в редакторе.
- При ошибке загрузки есть явная повторная попытка. Открытие справочника не вызывает сохранение, проверку или запуск проекта.

## Область изменений

Новый `core/studio-syntax-reference.mjs` загружается динамически из общего адаптера `core/nexus-studio-ui.js`, используемого обычным и локальным клиентами. Загрузка ограничена открытым C++ редактором проекта; на стартовой странице модуль не входит в начальный граф зависимостей. При неудаче загрузки модуля доступна повторная попытка. Домашняя страница Code Studio и отдельные уроки не получают вторую панель.

Данные справочника повторно используются без изменений. Project Store, writer, аккаунты, API, runtime, файлы проектов, попытки, прогресс, маршруты и материалы всех 151 тем не менялись. Прежняя правая справка уроков сохранена. Два UI файла зарегистрированы точными SHA в существующем реестре сохранности.

## Проверка и границы результата

Адресные браузерные сценарии проверяют RU/EN, 1440/390/320 px, поиск, выделение, печать рядом со справкой, копирование, отказ хранилища, сохранение, выход и возврат в проект, reload, первое открытие справочника без сети через установленный service worker и повтор после ошибки загрузки. Используются только синтетический аккаунт и проект на loopback; реальные аккаунты и рабочие данные владельца не подключаются.

Локальный evidence: `outputs/studio-syntax-reference-20261113/`. Окончательные SHA, результаты и статус CI фиксируются в едином отчёте этого каталога после сборки кандидата. Новый CI не подменяется успешным FULL #230, который относится к прежнему source100db28e.

Новое дополнение готовится к отдельному review. Публикация, merge, tag и Release этим документом не разрешаются. Пользовательская оценка удобства и проверки на физических Android/iPhone остаются отдельными от автоматических проверок.
