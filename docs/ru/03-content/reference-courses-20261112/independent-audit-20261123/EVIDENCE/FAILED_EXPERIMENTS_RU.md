# Неудачные прогоны проверки P0

| Наблюдение | Причина | Исправление и повтор |
|---|---|---|
| Публичный блок отчётов не проявился в первом изолированном браузерном запуске | В приложении серверный feedback включается по origin. Первый стенд имел origin localhost | Для браузера скопирована штатная форма адреса. Все запросы перехватываются и обслуживаются локальным стендом. Сетевого обмена с рабочими аккаунтами нет. До и после воспроизведены со схемой публичной сводки |
| Частичный профиль 1С прервал запуск с `PRIVATE_STORAGE_KEY_REJECTED` | Заготовка теста попыталась написать ключ обучения 1С через адаптер C++ | Фикстура использует существующий `createOnecAccountStorage`. Проверка доступа в продукте сохранилась |
| После смены маршрута тест слишком рано прочитал 2/67 вместо результата 1С | Предыдущая шкала ещё находилась в DOM | Ждать шкалу с размером текущего курса, затем сверять числитель и повторять после reload |
| На раннем варианте отдельного раскрытия тест не подтвердил возврат фокуса в прикладной 1С | Общий диалог возвращал фокус по текущему активному элементу. Пробное ожидание не дало устойчивого доказательства | Закрытие нового диалога явно возвращает фокус на открывшую его кнопку. После исправления проверены Enter, Escape и возврат на нескольких ширинах |
| При последовательной подаче 1 и 2 оценок прочиталась прежняя строка | Тест сохранял прежний DOM при переходе на тот же URL | Принудительная перезагрузка и ожидание текущей строки после нового ответа |
| Имитированный отказ IndexedDB не привёл к ошибке в сценарии C++ внутри сетевой оболочки | В этой ветке `createCppAccountAdapter` пишет результат в namespaced localStorage. IndexedDB относится к другому локальному контуру | Отказ вызван у действительного writer на синтетическом ключе состояния. Отдельно проверен холодный запуск PWA после остановки сервера |
| Сопутствующий CI 1С на `a0cdfc59afbe154580fa0e9d32851f45057a3842` впервые остановился на `SHARED_PRESENTATION_CURRENT` | Сравнение Академии со снимком 2026-10-21 требовало прежние декоративные номера. Остальные элементы разметки не расходятся | Проверка требует удаления номеров и побайтного равенства остальной разметки в RU и EN. Исходный снимок и сравнение оболочки, уроков и Code Hub сохранены. [Запуск с отказом](https://github.com/qsqgjhngyt-maker/akronikl-it-nexus/actions/runs/45064040289) |
