# Контракт справочника

110 стабильных ID в каждой локали. Индекс содержит id/term/aliases/context/category/level и загружается отдельно. Полные карточки подгружаются при открытии, без eager-загрузки всей справки в Home. Поля: простое и точное определение, назначение, форма, пример, разбор, наблюдение, ошибка, связанные существующие уроки, источник и дата проверки.

C++ и BSL разделены контекстом. Прикладная1С получает понятия объектов и действий. Строковые IDs1С адаптируются отдельно от объектов терминов C++; явно назначенные теме IDs не теряются при фильтрации. Уровень «Позже» не становится prerequisite начального маршрута.

Покрытие C++: код/компиляция/запуск, include/заголовок/библиотека, основные типы, имя/значение/инициализация/присваивание, арифметика/сравнение, разделители и разные роли скобок, функции/параметры/main/return, ввод/вывод/перевод строки, комментарии/условия/циклы/область. Одинаковый символ не сводится к одному ложному правилу.

BSL: модуль/контекст, сообщения, примитивные значения, переменные/присваивание/сравнение, разделители, условия/циклы, процедуры/функции/параметры, клиент/сервер, Новый. Регистры, запросы, СКД, форматы и инструменты имеют предметные категории. Базовый справочник не объявлен полным описанием платформы или стандарта.

Карточка функции показывает полный пример, параметр и аргумент, возврат и наблюдаемый результат. Повторно использованный нативный исходник связан с прежним исполнением по точным байтам; совпадение названия карточки доказательством не является. Контекст формы/сервера и непроверенные внешние варианты указываются отдельно.

Разметка создаёт button через DOM text nodes; данные экранируются. Исключены code/pre, редактор, поля, ссылки, кнопки, заголовки и другие интерактивные области. Аннотация идемпотентна; число выделений ограничено, полная карточка остаётся доступной через поиск. Обработчики освобождаются при смене темы. Пример и буфер редактора не меняются при открытии справки.
