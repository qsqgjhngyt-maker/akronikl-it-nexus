# Восстановление контекстной помощи

Первопричина: старые селекторы/адаптеры относились к другому renderer; новый авторский текст и строковые IDs1С не проходили через прежнюю C++-обработку. Общий mount теперь работает на текущей `.r3-lesson[data-r3-topic]` и фактически показанном тексте.

Структурная проверка всех302 редакций подтверждает разрешение всех строковых терминов, формат объектов C++, существование связанных уроков и уникальность словарных ID. Браузерно проверены20 эталонных редакций, а также for-loop, контексты1С и отчёты прикладной1С вне эталонов.

Проверки: повторная аннотация не добавляет кнопки; source статического примера не меняется; поле редактора и selection сохраняются; Escape закрывает поиск с первого нажатия и возвращает фокус, включая ShadowRoot; touch не требует hover. Полная кнопка справки видима. Холодное чтение использует реальные публичные PWA-ресурсы, отдельный процесс и недоступный сервер.

Сохранены отрицательные опыты повторной аннотации и Escape. Ошибка ожидания document.activeElement вместо ShadowRoot.activeElement отделена от дефекта продукта. Состояние reviewer не пишется в ученический прогресс.
