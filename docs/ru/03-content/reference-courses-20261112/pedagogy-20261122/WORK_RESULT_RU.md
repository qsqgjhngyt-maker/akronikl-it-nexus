# Содержательная редакция курсов C++ и 1С

Редакция охватывает 141 урок, 282 версии на русском и английском, 26 модулей. В курсе C++ переработаны 63 темы, в программировании 1С (BSL) — 49, в прикладном курсе 1С — 29. Десять принятых уроков сохранены с прежними контрольными суммами.

В каждой теме объяснение связывает понятие с задачей, два шага разбора помогают проследить конкретное поведение примера, открытый вопрос даёт обратную связь по рассуждению. В практику добавлена самостоятельная проверка с новыми условиями и ожидаемым результатом. Вопросы 1С указывают, какие записи, поля и наблюдения сравнить. Основные лабораторные, заготовки, эталонные решения, оцениваемые вопросы и проверяемые сценарии сохранены.

- В алгоритмизации ученик проверяет деление 23 и 24 деталей по коробкам на 12 и объясняет, почему остаток обнуляется.
- В программировании 1С ученик связывает вычисление с выводом программы и формулирует наблюдение, которое отличает значения от их представления в сообщении.
- В прикладном курсе ученик сравнивает отчёт по отдельному клиенту и по всем заявкам. Для четырёх записей на 160 минут итог «Восток» составляет три записи на 115 минут, итог «Запад» — одну на 45 минут.

Реестр тем, маршруты, версии проверки заданий, попытки и механизм хранения работы сохраняют прежний договор. Матрица фиксирует точные файлы, точки разбора и контрольные суммы правок по каждой теме и локали.

Технические проверки подтверждают состав материалов, открытие уроков и сохранность контрактов. Новые прогнозы для практики 1С остаются ожидаемыми результатами для проверки учеником. Новый полный цикл выполнения заданий в клиенте 1С и независимая проверка понимания учащимися здесь не заявляются.
