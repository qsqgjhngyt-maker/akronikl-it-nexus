# Источники и границы проверки

Дата:12.11.2026. Собственный текст не копирует книги/статьи. Первичные материалы используются для технической проверки и редакторского пересказа; число ссылок не доказывает обучение.

| Материал | Раздел | Зачем |
|---|---|---|
| [Programming: Principles and Practice Using C++, 3rd edition](https://www.stroustrup.com/PPP3.html) | 2024; publisher description and author guidance | Beginner audience and foundational approach |
| [C++ working draft](https://eel.is/c++draft/) | [intro.execution], [basic.start.main], [dcl.init], [expr.mul] | Technical rules; the draft is not a beginner lesson |
| [Frequently asked questions](https://www.stroustrup.com/bs_faq.html) | History of C++; What is C++? | Origin, goals and milestones |
| [Practical Developer Guide](https://1c-dn.com/library/tutorials/practical_developer_guide_creating_an_infobase/) | Creating an infobase; Module types | Preparation of a separate infobase |
| [Синтакс-помощник](https://v8.1c.ru/platforma/sintaks-pomoshchnik/) | Контекст, методы и встроенный язык | Native context and syntax help |

История C++ проверялась по FAQ автора: начало C with Classes1979, имя C++1983, коммерческий выпуск1985, первый ISO1998. Устаревшее упоминание текущего стандарта на странице FAQ не использовано. Страница PPP3 подтверждает третье издание2024 и начальную аудиторию; полного прочтения книги/PDF и review всех глав не заявлено. Уроки используют собственное объяснение.

Точность инициализации/присваивания, целочисленного деления, имени, области и базовых типов сверялась с соответствующими разделами C++ working draft на eel.is. Это живой draft; урок не выдаёт его за фиксированный ISO C++20. Фактические примеры собраны штатным C++ runtime. Разные роли скобок, заголовок и библиотека не смешиваются.

Для1С использованы официальные разделы создания базы, типов модулей, объектов конфигурации и синтакс-помощник. Конкретные новые учебные вычисления и действия дополнительно проверены установленной1С8.3.27.2214 в отдельных базах. Общее описание инструмента синтакс-помощника не объявляется прочтением всех API. Старые словарные карточки получили предметные категории; инструменты EDT/OneScript/BSL LS и XML/JSON/HTTP ссылаются на их первичные проекты/стандарты и помечены дополнительными.

Синтаксические примеры, native-инструментирование и самостоятельное выполнение в GUI — разные виды evidence. Источник утверждения и исполняемый исходник проверяются отдельно. Подробный список URL/дат находится в самих карточках; непрочитанные полные книги не включены как доказательство.

Новых сторонних изображений нет. Учебные схемы и текст собственные; native снимки сделаны в отдельной синтетической среде. Программные файлы1С, лицензии и рабочие базы в review-пакет не копируются.
