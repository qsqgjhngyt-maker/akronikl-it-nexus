# Редактор: первопричина и доказательства

Общий стиль `.r3-lesson pre` менял line-height слоя подсветки, а textarea сохраняла метрики редактора. Исправлено ограничением `pre:not(.editor-highlight)`. Компенсационного смещения caret нет. Активная строка обозначается в существующем gutter.

| Среда | textarea до | pre до | textarea/pre после |
|---|---|---|---|
| Desktop | 13px /20.15px | 13px /22.1px | 13px /20.15px |
| Mobile CSS | 16px /24.8px | 16px /27.2px | 16px /24.8px |

Фактические исходные метрики: `before-browser/EDITOR_BEFORE.json`. После:36 сочетаний1366/390/320 × масштаб1/1.25/1.5/2 × строки1/10/30, длинная и пустая строки, табуляция, scrollTop/scrollLeft, selection, реальный ввод/undo/redo. Эти масштабы обозначены как CSS zoom; они не выдаются за команды Chrome.

Дополнительно выполнен настоящий масштаб Chrome через команды окна:100/110/125/150/175/200%. В `native-browser-zoom/NATIVE_ZOOM.json` DPR и viewport меняются, CSS zoom остаётся1; textarea и pre сохраняют одинаковые font/line-height/padding/tab-size/white-space/letter-spacing. Сохранены фактические снимки окна с125/150/200%. Это desktop Chrome, не физические телефоны и не независимый тест доступности.

Изменения подсказок, эталона и этапа не заменяют редактор и не теряют выделение. Отдельно отмечен непроверенный CDP-ввод в холодном Windows browser: даже контрольное поле не приняло символы. Проверка данных/ресурсов через правильную синтетическую фразу и штатный обработчик формы не объявлена реальным клавиатурным прохождением.
