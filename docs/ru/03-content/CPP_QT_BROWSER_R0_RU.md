## Что реализовано

Student C++ собирается в отдельном браузерном worker существующим закреплённым YoWASP Clang22, с Qt6.8.3/Emscripten3.1.56 headers, в динамический WASM side module. Универсальный QtCore/Gui/Widgets runtime заранее собирается локально из SDK; пользовательские исходники на сервер для Run не отправляются. Платный сервис сборки не требуется.

Preview открывается на другом site в opaque iframe с sandbox allow-scripts. Source/window/origin/nonce/profile/snapshotHash проверяются в протоколе сообщений; родителю разрешён возврат только объявленных data/*.txt/json или taskflow.txt с ограничениями размера. Исходники защищены существующим applyRuntimeFiles с проверкой исходной версии. Stop удаляет iframe и прекращает worker; память компилятора освобождается до запуска Qt. Перед тяжёлой операцией проект должен успешно сохраниться.

Новый target gui задаётся явно; старый TaskFlow адаптируется в памяти, без переписывания сохранённой работы. Собственные тесты модели выполняются существующим WASI target; их успешность не объявляется независимой экспертной оценкой. Переносимый CMake/ZIP сохраняется. Новые GUI-шаблоны содержат COPYING.txt и уведомление GPLv3; прежним работам лицензия автоматически не назначается.

Параллельно исправлен прежний необязательный серверный прототип: bytes артефакта проверяются до HTTP headers, ограничены загрузки/память/backpressure, добавлены очередь2runner и лимиты, durable запись, постраничная история; удаляется только одноразовый compiled cache, не snapshots/сдачи. Эти изменения проверены локально, сервер не развёрнут и не является выбранным обязательным runtime.
