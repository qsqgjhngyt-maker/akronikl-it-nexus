## Учебно-методический стандарт

Занятие содержит цели и prerequisites, определения, причинные объяснения, минимум два разобранных примера, управляемые эксперименты, диагностику ошибок, три уровня практики, лабораторную с заготовкой и критериями, исходник эталона по раскрытию, воспроизводимые stdin/stdout, контроль понимания с объяснением, рефлексию и переход дальше. RU и EN — отдельные полные объекты одного состава.

Глубину оценивают по раскрытию конкретной темы и проверяемости результата. Количество полей, слов и зелёный CI сами по себе не доказывают образовательное качество. Интерактивная трасса JavaScript помогает рассуждать; выполнение C++ проверяется отдельно настоящим компилятором. Автоматическая оценка работы ученика не реализована: ученик сравнивает вывод с таблицей случаев и сохраняет артефакт по критериям.

Content Quality Gate включает структурную проверку, согласованность RU/EN, содержательную ревизию, реальные компиляции/запуски, свойства моделей, browser online/offline, узкий экран, неизменность ID и learner state, regression контрактов. Независимая методическая экспертиза и учебный эксперимент с учащимися остаются отдельными этапами.

## Архитектурное решение и совместимость

До интеграции Gold объекты существовали отдельно и не загружались entry points. После интеграции точный ID и locale определяют разрешённый JSON. Он загружается при входе в урок; presentation/model и CSS также загружаются по необходимости. На Home Gold JSON, presentation/model и CSS не запрашиваются. Публичный allowlist расширен только на 16 фиксированных путей.

Состояние ученика не хранится в Gold JSON. Существующие curriculum, content-package, data, storage, migration, Identity, Cloud Sync, sandbox, Project Studio и vault contracts не переписываются. Gold проецируется поверх baseline по тому же ID; сохранённые файлы и stdin имеют приоритет. Старый quiz получил полную EN локализацию с тем же порядком ответов и семантикой индекса; новые Gold вопросы не изменяют старый прогресс. Модели получают локальную зависимость явно, без глобального реестра.

Альтернативы: загрузка всех уроков на старте отклонена из-за ненужного роста начальной загрузки; новые ID отклонены из-за риска разрыва прогресса; глобальный реестр моделей заменён передачей данных текущего урока. Production generation и закреплённые release-копии не изменяются. Build в CI — изолированный тестовый артефакт, не релиз.

Есть ли здесь материал для диплома? Да: ленивое представление двуязычного содержания при стабильной идентичности learner state, проверка инвариантов алгоритма, контракт входных данных, разделение визуальной модели и фактического исполнения. Ограничения: нет доказательств эффективности обучения на учащихся, независимой методической приёмки или физических мобильных устройств.
