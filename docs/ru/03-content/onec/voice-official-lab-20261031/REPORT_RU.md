## Безопасность и сохранность

Локальный модуль:127.0.0.1:18792, только точный разрешённый Origin/Host, без cookies/Nexus credentials. Отдельные короткоживущие токены — только память, с отзывом, лимитом частоты/сеансов. Неизвестная модель отклоняется до запроса микрофона. Браузер передаёт ограниченный PCM/WAV из памяти; контейнер получает stdin. Аудио не сохраняется на host, в чат, прогресс, outbox или evidence; в разговор может попасть только распознанный текст. Ошибка Whisper не включает облачный fallback. Отдельный сервис браузера доступен только после явного согласия.

Модель исполняется в собственном одноразовом Linux контейнере: network none,UID65532,read-only root,cap-drop ALL/no-new-privileges,2GiB памяти,4CPU,32 процесса,ограниченные tmpfs/вывод/время. Единственный read-only bind содержит два публичных файла модели; host-аудиофайлов, пользовательских каталогов,devices и портов нет. Политика inspect проверяется до запуска; отмена удаляет только свой UUID job. Браузер не получает Docker socket. Это локальный операторский кандидат, независимая security приёмка остаётся нужна.

Studio добавляет снимок всего текущего исходника для официального стенда: workId,course/topic,ревизия и отдельный manifest SHA; экспорт ничего не записывает в работу, прогресс или попытку. Builder создаёт новый каталог и отказывается перезаписывать существующий. Windows reserved/case-collision пути отклоняются. .wsb отключает сеть,vGPU,clipboard,audio/video/printers; единственный read-only input. Guest script отказывается от обычного host, проверяет исходники, подпись/версию платформы и отдельное подтверждение права guest; на каждый запуск создаётся новая база. Автоматическое извлечение результата и зачёт не реализованы, output остаётся недоверенным внутри guest.

Клиентские/серверные лицензии с этой учебной поставкой не применяются. Право общего учебного сервера и конкретного guest из этих условий автоматически не выводится. HOST_PREFLIGHT: Windows Sandbox command/package не обнаружены; текущий процесс не Windows admin. Состояние optional feature обозначено UNKNOWN_REQUIRES_WINDOWS_ADMIN, а не Disabled. ## Неудачные попытки и решения

1. Реальный браузер не видел служебный заголовок локального ASR из-за CORS. Добавлен только expose x-nexus-asr; точный Origin и авторизация сохранены. Unit и реальный браузер повторно прошли доступ к заголовку; отказы чужому origin/cookies сохранены.
2. Синтетический voice fixture сначала отправлял событие прежнему recognizer до завершения lazy start. Добавлено ожидание listening; два последовательных обмена проверены. Это исправление fixture не выдаётся за реальную речь.
3. Проба колонка→USB→Whisper не распознала фразу. Причина не доказана; возможные VAD/акустика/AEC не называются установленным диагнозом. Результат сохранён PARTIAL, естественная речь остаётся NOT RUN.
4. Host не предоставляет доступный официальный изолированный guest. Не применялись обход через host, перенос ключей, изменение ОС или ослабление release gates. Подготовка сохранена; нужен отдельный работоспособный законный guest.
