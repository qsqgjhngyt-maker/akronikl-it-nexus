## Пробелы юридического evidence

Официальная ссылка на EULA точной учебной поставки вернула HTTP 403. Локальное общее EULA подтверждает отдельные правила учебного использования и запрет распространения платформы без специального разрешения, но не подменяет неполученный договор конкретной поставки. Полное community-соглашение и EULA EDT также не объявляются проверенными. Эти пробелы не требуют раздачи дистрибутивов: кандидат распространяет только оригинальные учебные тексты, синтетическую модель и собственные метаданные/BSL.

Публичная лицензия Nexus не активируется этим изменением. OneScript/BSL LS не включаются в пакет, поэтому их лицензии зафиксированы для будущего решения о способе интеграции. Если будут распространяться их binary/components, потребуется отдельная проверка notices, исходников, зависимостей и обязанностей конкретной поставки.

## Решение о базовом прохождении

Достаточная бесплатная архитектура первого этапа: Nexus для материалов/самопроверки + официальная локальная файловая платформа для native lab. Установка остаётся действием пользователя по официальным условиям. Сервер, облачные ресурсы, платные API и покупка лицензии задачей не создавались. Телефон поддерживает материалы и модели; это не превращает его в платформу разработки 1С.

Для будущих P8/P10 нужен отдельный допустимый стенд с поддержкой соответствующих функций. До согласования нельзя включать runner в Code Studio, менять provider routing или выдавать JS за платформу.
