P4-Q: исторический publication gate относится к закреплённому выпуску C++, а обычное последовательное наполнение платформы проходит отдельный content-review. Старые security/release scope и Identity/runtime provider contracts сохраняются побайтно; точное аддитивное изменение каталога проверяется положительным ожидаемым объектом. Зелёный content-review не означает разрешение выпуска.

WHAT REMAINS / RISKS:

- Естественная речь: диктовка и минимум два цикла «сказал → ответ/озвучка → снова слушает», остановка и закрытие с реальным голосом. Доступность USB-устройства этого не доказывает.
- Реальный аккаунт: вход и candidate write/reload на законном review origin. Нужна координация01/02; новую конфигурацию OAuth/IAM/BFF/Worker/D1 в этой ветке не вводим.
- Windows ASR — доверенный личный процесс с wall/output limits, без жёсткого лимита памяти и сетевого пространства Docker. curl выключен, аргументы фиксированы, аудио идёт по stdin; системный процесс не превращается в общий сервер распознавания. Облачный провайдер не выбран.
- Native: не закрыты client-server concurrency, scheduling/background jobs, EDT и все возможные конфигурации/версии. Подготовленный фоновый модуль не является доказательством запуска. Роли/RLS доказаны в нашей учебной базе с синтетическими данными, не в Nexus IAM.
- Физические Android/iPhone владелец проверяет ПОСЛЕ публикации по прямому решению; это не причина задерживать текущую ПК-подготовку. Эмуляция и WebKit на ПК не называются физическим LIVE PASS.
- Холодный offline доказан для отдельного HTML-пакета всех168 материалов/итогов/помощника. Авторизованная общая оболочка и её новые маршруты в cold-offline пока не приняты; политика private/public cache authority не расширялась.
- Учебная лицензия не разрешает автоматически публичный многопользовательский сервер. Дистрибутив/EXE/модели не распространяются в PR или review package; используются только собственные синтетические материалы.
