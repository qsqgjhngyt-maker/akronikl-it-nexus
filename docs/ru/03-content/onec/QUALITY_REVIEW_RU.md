## Устранённые проблемы и отрицательные эксперименты

1. Проблема: первый dump нового стенда получил отказ доступа к файлу. Гипотеза: ограничения локальной среды запуска. Та же операция на том же новом стенде с разрешённым локальным доступом прошла; версия/исходная база не менялись. Решение: нативный gate выполняется в разрешённом локальном контексте. Regression: BSL, dump/restore и negative CheckConfig PASS.
2. Проблема: preservation gate неверно отклонил кириллическое имя `Русский.xml`. Причина: Git quoted-path output. Решение: NUL-delimited path list. Regression: все новые пути разрешены, existing contracts побайтно прежние.
3. Проблема: первый Chrome-test получил network access denied к loopback. Решение: изолированный разрешённый локальный запуск, без пользовательского browser profile.
4. Проблема: тестовый сервер неверно нормализовал корень с завершающим разделителем, затем пытался повторно отправить headers при отсутствующем favicon. Исправлены path resolution и порядок чтения файла/headers. Regression: все уроки/модели/копии/ошибки storage/cold offline PASS. Это ошибки тестового стенда, не доказанный дефект платформы 1С.
5. Учебный UI: длинное оглавление закрывало урок на телефоне. Сделана сворачиваемая навигация с нативными details/summary; повторены все 16 локализаций на четырёх размерах.
6. Намеренно испорченный BSL загружен только в отдельную negative-base. Нативный CheckConfig вернул 101 и синтаксическую диагностику. Принятый стенд и восстановленная копия сохранили корректное исполнение.

Неудачные исходные эксперименты сохраняются локально в каталоге работы. В GitHub переносится только безопасное описание и итоговые отчёты, без raw logs/баз/активационных сведений.
