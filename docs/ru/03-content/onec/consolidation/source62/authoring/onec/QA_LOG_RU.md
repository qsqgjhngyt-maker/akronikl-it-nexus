# 1C-0 — журнал проверок и отрицательных экспериментов

30.10.2026. Контрольные точки относятся только к редакционным кандидатам и отдельному превью. Ни один результат здесь не является LIVE PASS курса или запуском 1С.

## D-01 — не все источники отображались ссылками

Проблема: первый CI `41084270798` на `e859df73a45f1c39a897b1f5d1c47f0dc231c96f` прошёл 24 структурных теста и ограниченную существующую регрессию. Последующая проверка Chromium выявила, что у прикладного урока было 2 ссылки вместо 5, а у профессионального — 6 вместо 7.

Причина: генератор передавал в превью общий реестр, но не включал четыре дополнительных источника из `lessons.json`. Тест валидности исходных sourceRefs этого не выявлял.

Исправление: включён `lessonsSourceRows` в данные превью; источники обоих реестров объединяются при построении списка. Добавлен отдельный тест полноты источников именно в HTML-пакете, а не только в исходном JSON.

Regression gate: оба направления × RU/EN × 1440/390 px; сверить число источников, вопросы, интерактивную модель, горизонтальное переполнение и отсутствие сетевых запросов. Финальное свидетельство должно содержать SHA256 конкретного preview.html.

## D-02 — самостоятельное воспроизведение тестов пакета

Проблема: первый архив содержал тесты, но не две неизменённые зависимости `sandbox/languages.js` и `courses/catalog.json`. README предписывал запуск из полного репозитория; тестирование отдельной распакованной копии не было доказано.

Исправление: сборщик включает точные bytes этих двух исходников. Они нужны для теста registry и проверки существующей карточки. Это не изменение production и не инструкция накладывать пакет на Nexus. Тест проверяет побайтное совпадение.

Regression gate: запустить `node --test authoring/onec/foundation.test.mjs` из распакованного финального артефакта и сохранить вывод отдельно от CI.

## D-03 — будущие учебные слои в исходной roadmap

Проблема: генератор выдавал в контракте not-implemented, но неверный статус в исходной roadmap мог остаться незамеченным.

Исправление: валидатор явно проверяет исходные Skill Graph, Learning Events и Mastery; три мутации implemented должны отклоняться. Это проверка честности статусов, не реализация этих компонентов.

## Ограничение локального браузерного стенда

Установленный Chromium блокирует навигацию `file://` и тестового URL политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политика не изменялась. Для проверки разметки и событий используются точные HTML bytes через Playwright `set_content` в пустом документе при отключённой сети.

Это позволяет проверить выполнение скрипта, адаптивное отображение, переключение RU/EN, общую учебную модель и самопроверку. Это **не** проверка открытого URL Nexus, file-open на устройстве ученика, реального service worker, PWA, приватного Account storage или физических Android/iPhone. Эти приёмки остаются отдельными.

Изображения и отчёт браузерного стенда должны быть привязаны к проверенному HTML SHA256 и содержать явное описание способа доставки страницы. Из-за непрозрачного origin работоспособность настоящего storage в этом стенде не заявляется; отсутствие чтения/записи подтверждается исходным кодом превью и его структурным тестом.

## Учебное качество

Проверка схемы и число тем не являются доказательством глубины, экспертной приёмки или роста знаний. В текущем checkpoint написаны два вводных занятия с самостоятельными RU/EN телами. Остальные 93 темы программы пока только curriculum entries. Полные A1/P1, конфигурация сервисной службы, анализатор BSL и официальный запуск 1С ещё не приняты.
