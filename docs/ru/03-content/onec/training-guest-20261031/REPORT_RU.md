## Неудачные эксперименты и исправление

Первый VC++ ожидался180с; получен TIMEOUT. Попытка использовать уже установленный runtime сначала содержала ошибочно принятую минимальную версию14.27. Реальная версия подписанного пакета поставщика14.16.27033.0; нижняя граница исправлена по нему и правилу совместимости Microsoft v14. Существующая зависимость допускается только после проверки Installed x86, версий обеих DLL и подписей Microsoft. Одного registry flag недостаточно.

Следующая попытка MSI получила TIMEOUT240с. Media перенесены из readonly VSMB во внутренний guest-каталог с повторными SHA и подписями. Затем новая чистая среда снова выявила180с VC timeout. Диагностика показала: оба MSI компонента Microsoft завершились с0x0 приблизительно по121с каждый; весь dependency installer закончил позже таймаута родительского QA. Журнал1С отдельно показал около120с на штатную проверку цифровой подписи MSI, затем проверку MST. Причина задержки внутри механизма проверки подписи глубже не исследована; сетевой таймаут предполагается, а не объявляется доказанным.

Выбраны отдельные конечные600с бюджеты для VC++/MSI.90с на каждый запуск1С сохранены. Windows policy/trust checks, ExecutionPolicy/GPO, сеть и read-only не ослаблялись. Final successful job использовал уже завершившуюся и заново проверенную VC++ установку; MSI в нём завершился с0. Полная установка VC++ с новым600с бюджетом в ещё одной совершенно чистой VM отдельно не повторялась. Private логи/базы/дампы не экспортировались; публичны CLI-квитанции, hashes и точные screenshots. Raw гостевой JSON не выдаётся за автоматически извлечённый: OBSERVED_RESULT — явная сверенная транскрипция видимого ограниченного результата.

Это также выявило ограничение отмены: уничтожение непосредственно запущенного установщика не гарантирует немедленного завершения его сервисной транзакции. Нельзя начинать конкурирующие установки или считать отсутствие parent process доказательством остановки. Такой механизм недостаточен для произвольного untrusted runner. Для текущего собственного фиксированного эталона использован последовательный поток.
