STATUS: PARTIAL. Изменения — IMPLEMENTED / AUTOMATED PASS. Новая проверочная публикация и приёмка владельцем ещё не выполнены. Этот акт не объявляет LIVE PASS или официальный Release.

## Что получает ученик

В начале урока есть кнопка «Как выполнить лабораторную». Та же справка доступна в лабораторной и редакторе Studio. RU/EN инструкция объясняет восемь шагов: получить официальную учебную 1С, открыть свою рабочую копию, изменить и сохранить код, скачать ZIP, распаковать его, создать отдельную учебную базу, загрузить конфигурацию из папки src и проверить результат. У каждого шага указано, что должно появиться на экране. Отдельно разобраны первая строка кода, резервная копия .dt и частые ошибки. Шесть дополнительных шагов объясняют проверку урока и итоговую работу: варианты теста, четыре практики, выбор проекта, текстовое портфолио, сохранение версии и экспорт истории. Автоматический тест, самоотчёт и настоящая проверка 1С различаются явно.

Studio получил дополнительную кнопку «Скачать файлы ZIP». В архиве — текущие исходники в src и две текстовые инструкции. Прежний JSON-экспорт и JSON-импорт сохраняются. ZIP не содержит аккаунт, ACL, прогресс, дистрибутив платформы или ключи. Код можно выгрузить даже при ошибке сохранения на устройстве; после блокировки аккаунта выгрузка запрещается существующей проверкой владельца.

Установленная учебная 1С и изолированная проверка различаются явно. Временная Windows Sandbox проверяет снимок кода, затем удаляется и возвращает только ограниченный протокол. Код редактируют в Studio до следующего снимка. Подготовка JSON не запускает Windows. Личный комплект по-прежнему требует отдельной операторской настройки; новая кнопка автоматического запуска не заявляется. Для интерактивной работы с окнами и данными описан ручной путь через установленную учебную 1С.

Ссылки ведут на [официальную учебную 1С 8.3.27.1508](https://online.1c.ru/catalog/free/28765768/) и [инструкцию Microsoft по включению Sandbox](https://learn.microsoft.com/ru-ru/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-install). Дистрибутив получает сам ученик через форму поставщика. Новые версии платформы автоматически не подставляются вместо проверенной.

## Неуспешные проверки и исправления

1. Первая редакционная обработка добавила пробел после двоеточия в provenance. Исторические equality tests обнаружили изменение. Все 62 таких значения восстановлены точно; повторные проверки PASS.
2. Прежняя проверка запрещала любое изменение 16 A1/P1 payload. После решения владельца из двух P1 RU/EN абзацев удалены названия прикладных продуктов. Тест теперь разрешает только эти две точные замены, сравнивает всё остальное и native kit с историческим SHA. Ответы и версии не менялись.
3. Новый раздел добавил официальные ссылки в #lab. Старый browser selector стал неоднозначным. Он уточнён до прежней README-ссылки; продуктовые ограничения не ослаблялись.
4. Просмотр снимка обнаружил ещё слипшиеся слова в скопированных подписях схем. Подписи сверены с полными фразами уроков, добавлена проверка P12. Выполнен окончательный браузерный прогон.
5. В отдельном тестовом HTTP fixture лишний разделитель Windows пути привёл к 404. Исправлен только fixture; восемь проверок раскрытой справки PASS.

Учебная платформа имеет ограничения; задания с иной средой требуют указанной в уроке законной среды.
