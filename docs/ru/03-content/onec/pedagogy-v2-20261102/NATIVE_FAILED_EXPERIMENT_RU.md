# Учебная 1С 1508: отказ компиляции тестовой обвязки

STATUS: PARTIAL. Неудачный опыт сохраняется; успешный результат не объявлен до повторной проверки.

Проблема: первый объединённый прогон новых примеров в официальной учебной 1С 8.3.27.1508 завершился `COMPILE_REJECTED`. Установка официальной учебной платформы внутри временной Windows прошла; host не устанавливался и не изменялся. Очистка временной среды подтверждена. Прогресс и работы не записывались.

Привязка попытки: request `65255730-4bb1-4b27-8450-3530ed82cde6`, launch `98ace1ce-8531-47a9-a316-016b01d37850`, снимок `97c212073034cf12458057c6382a6bc7db8fec9d6fcc36982cf68ee99c0f5d96`, runner `2a6bc2955d09cba909b9b6f1b157ba16a03c0b117f85fe0745798ddd23880534`. Длительность 531051 мс, включая отдельную установку. Диагностика: `Ext/ManagedApplicationModule.bsl`, строка 38, столбец 11, проверка компиляции. Необработанные журналы не публикуются.

Гипотеза и проверка: на строке 38 обвязка обращалась к `Справочники.Клиенты.Выбрать()`. Общий runner проверяет также тонкий клиент; этот API недоступен в его контексте. В прежнем проверенном эталоне операции со справочниками уже ограничены директивой толстого управляемого клиента.

Решение: исправить только собственную обвязку, явно ограничив её `#Если ТолстыйКлиентУправляемоеПриложение Тогда`. Учебные арифметические фрагменты остаются неизменными. Исправленный снимок сначала прошёл на установленной официальной 8.3.27.2214 те же проверки целостности, тонкого/толстого клиента и сервера. Затем запущена новая отдельная попытка на официальной учебной 1508. Прежний отказ не перезаписывается.

Security gates и требования runner не ослаблены. Это ошибка контекста API в нашей тестовой обвязке; она не является отказом лицензирования и не отменяет шесть ранее реально исполненных арифметических случаев на 2214. Результат повторного запуска и его точный SHA фиксируются отдельно. Реальная тонкоклиентская демонстрация числа 75 на 2214 также остаётся отдельным узким наблюдением.

Продолжение: исправленный снимок завершился `RUN_COMPLETED` на официальной учебной 8.3.27.1508, с подтверждённой очисткой. Точный исходник обвязки сохранён в `courses/onec-education/code/pedagogy/pilot-training-check.bsl`; его хеш и привязка runner проверяются тестом. Отдельная новая попытка с заменой первого сложения на вычитание завершилась ожидаемым `LOCAL_TEST_REJECTED`, также с очисткой. Положительный и отрицательный протоколы: `PEDAGOGY_TRAINING_RESULT.json`, `PEDAGOGY_TRAINING_NEGATIVE_RESULT.json`. Это закрывает проверку исправленной обвязки в названном контексте; исходный неудачный опыт остаётся отказом.
