# Переработка 1С V2 — два образца и общий учебный маршрут

STATUS: PARTIAL. Это промежуточная инженерная фиксация, не приёмка всех курсов и не выпуск.

## Что реализовано

Исходная точка — PR63 `a104f89783edd871c4608e8b75a4ebc59cd3c110`. Идентификаторы двух курсов и всех 84 тем сохранены. Переработаны шесть тем RU/EN: четыре вводных урока прикладного направления, первая карточка клиента и первый расчёт BSL. Остальные 78 тем пока сохраняют исходное содержание; их переработка продолжается в том же потоке. Реестр `LESSON_REWORK_LEDGER.json` различает исходные и новые версии и фиксирует контрольные суммы каждого текста.

Основной маршрут — обычная установленная официальная учебная 1С. Лабораторная объясняет программу, исходное состояние, действие, причину, ожидаемый результат и исправление ошибки. Studio и Windows Sandbox остаются дополнительными инструментами. Общая инструкция доступна до первого запуска. Термины и сокращения объясняются через общий с C++ компонент справочника.

Оформление использует настоящие компоненты и стили C++ Gold. Сравнение вычисленных стилей на реальных страницах прошло для обоих курсов, RU/EN и ширин 1366/390. Снимки Конфигуратора и прикладного окна подлинные; оригинальные JPEG сохранены без редактирования, подписи и указатели наложены отдельно. Их хеши, размеры, версия платформы и границы доказательства опубликованы в манифесте. Снимки интерфейса 8.3.27.2214 не выдаются за интерфейс учебной сборки 8.3.27.1508.

Общий Akronikl получает полный проверяемый корпус и точные ссылки на шаги. Локальный режим отвечает по материалам без модели. Место занятия сохраняется отдельно для вкладки, курса и аккаунта на устройстве. Новая версия не стирает прежние попытки и работы; прежняя отметка не превращается в результат переработанного урока. Внешнее окно 1С не наблюдается автоматически.

## Что доказано

- Общая регрессия: 44/44 группы AUTOMATED PASS, включая Content Contract, сохранность, C++, PWA, Studio и NEXUS-PERF-01. Исходные результаты лежат в `evidence/regression/`.
- Общий стиль: 8 браузерных сочетаний AUTOMATED PASS; реальные компоненты, справочник, переход из шага к Akronikl и обратно, рабочая ссылка на инструкцию.
- Снимки: 16 браузерных сочетаний AUTOMATED PASS; RU/EN, ширины 1366/390/320, увеличение оригинала, холодный автономный запуск, отсутствие сетевых запросов и изменений сохранений.
- Контекст: шесть браузерных сценариев с синтетическими аккаунтами; F5, две вкладки, изоляция аккаунтов, logout, ошибка места на устройстве. Это не новая приёмка реального аккаунта.
- Настоящая учебная платформа 8.3.27.1508: положительный запуск `RUN_COMPLETED`; отдельная изменённая копия с ошибкой расчёта — `LOCAL_TEST_REJECTED`; очистка изолированной среды подтверждена в обоих случаях. Проверены шесть расчётов и операции с собственным справочником. Ложный результат не принят. Исходники и хеши связаны с протоколами.
- Авторский интерфейс 8.3.27.2214: создание, сохранение, повторное открытие, переименование без смены кода, второй клиент, перезапуск, пустой поиск и очистка. Это ограниченный операторский LIVE PASS; не исследование с новичками и не проверка интерфейса учебной сборки.

Отрицательные опыты сохранены: первый учебный запуск отвергнут компилятором из-за неверного контекста служебной проверки; исправлен только проверочный модуль. Предварительная автономная сборка с внешним скриптом отвергнута браузером file://; вместо обхода защиты используется проверяемое публичное содержимое в изолированных локальных документах. Подробности — в ADR и отчёте неудачного native-опыта.

## Границы

Приёмка первого создания/восстановления базы через интерфейс неполна. Создана отдельная пустая база, Конфигуратор открыт, но дальнейшему управлению помешало перекрытое окно и защита ввода. Чужие окна и базы не изменялись. Преподавательское оценивание, авторство, безопасность профессиональных ролей, несколько пользователей учебной версии, физические Android/iPhone и педагогическая эффективность не объявляются доказанными.

Автономный формат V2 сохраняет прежний файл входа и ключи работ, но требует распаковки всей папки с публичными частями `data/` и изображениями. Суммарный размер HTML вырос; это явно измеряется отдельно от размера каждого файла. Общий стартовый бюджет NEXUS-PERF-01 и защитные release gates не повышались.
