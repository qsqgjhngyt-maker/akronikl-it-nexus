# Публичные материалы: размер и воспроизводимость

Решение03/05→02/07/08,02.11.2026. Сохраняются NEXUS-PERF-01 и исходные security/publication gates. Ни права аккаунтов, ни runtime-provider, ни база данных не меняются.

Полный публичный корпус84тем RU/EN уже не помещался в прежние1500000 сетевых байт RU. Производный guide упакован gzip+base64 в JSON. Декодер проверяет точные поля, network budget1500000, ограниченный вывод4000000, объявленную длину и SHA до UTF8/JSON. Ответы quiz, попытки, код и приватный прогресс в индекс не входят. Исходный JSON сохранён для аудита и автономной сборки; первичная загрузка приложения не получает весь корпус.

GitHub CI head1760f1a отклонил пакет: `Пакет устарел: guide-packed.ru.json`. Архив13117501838 имеет SHA256 `d8bea27b703a1f27fe8b8685d7bef9462ae40fe2aa79f8e6c6d67c6ce45b7171`. Причина воспроизведена локально: gzip OS byte Windows=10, Linux=3, оставшиеся байты совпадают. Генератор теперь фиксирует OS=255 по RFC1952; сжатые данные и CRC не меняются. Строгое сравнение всего пакета осталось. Linux Node22.23.3 в network-disabled контейнере и Windows Node24 дали один manifest `f46025cc35a6d70d2cbc4da2be8623a4ff1101f4fdcbcd0e75b4402b7b7ebcef`; exact-head GitHub Node24 проверяется отдельно.

Накопленный PWA manifest после добавления новой генерации имел2570303 байта, превышая прежние2400000. Удаление старых immutable URL отклонено: они нужны для совместимого отката. Увеличение лимита отклонено. Применено `prefix-groups-v1`: общая часть соседних URL хранится один раз, остальные поля сохраняются. Порядок, bytes/SHA/mime/version, lazyAssets и политика остаются идентичными после раскрытия. Предпросмотр настоящей сборки esbuild:11332 assets,2148084 байта и полный deepEqual. Финальная сборка должна повторить сравнение по её точному source SHA.

Старый публичный формат читается прежним путём. Для нового формата парсер по-прежнему извлекает только JSON literal, без eval: строгие группы, ограниченные пути/числа, SHA, отсутствие дубликатов/traversal/исполняемых полей. Runtime получает тот же раскрытый объект. Исходник service-worker и release gates не ослабляются. Изменён только аддитивный reader `tools/published-worker-configuration.mjs`, закреплённый точным SHA в существующем scope; новый codec принадлежит курсу. Негативные тесты проверяют подмену/дубликаты/unknown fields.

Откат возвращает прежний frontend/worker с прежним форматом. Работы, попытки и прогресс не удаляются. Контент, индекс и инструкция публикуются одной генерацией. Межустройственная память и педагогический эффект этим решением не доказываются.
