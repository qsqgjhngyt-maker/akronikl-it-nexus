# Обычная учебная установка и оригинальная конфигурация

Повторная проверка официальных источников: 02.11.2026. Это фиксация границ личного учебного маршрута, а не разрешение на общий сервер исполнения.

Официальная учебная платформа позволяет создавать собственные решения. Её бесплатную электронную поставку ученик получает у 1С. Небольшая локальная файловая база подходит начальному обучению; клиент-серверный вариант, несколько одновременных сеансов и профессиональную аутентификацию этим маршрутом не подтверждаем. Печать в прикладном режиме также ограничена. [Описание версии правообладателем](https://v8.1c.ru/podderzhka-i-obuchenie/uchebnye-versii/1s-predpriyatie-8-3-versiya-dlya-obucheniya-programmirovaniyu/).

Правообладатель отдельно допускает разработку прикладных решений с помощью учебной версии, сохраняя ограничения её применения; реальный учёт предприятия требует соответствующей коммерческой поставки. Правила учебного класса нельзя автоматически переносить на личный бесплатный экземпляр или общий облачный сервис. [Официальные ответы по лицензированию, раздел VIII](https://v8.1c.ru/priobretenie-i-vnedrenie/otvety-na-tipovye-voprosy-po-litsenzirovaniyu-1s-predpriyatiya-8/).

Решение проекта: публикуется только собственная оригинальная конфигурация `NexusTrainingServiceDeskV2.cf` и её исходники. Платформа, установщик, ключи, сертификаты лицензий, чужие прикладные решения и записи пользователей в неё не включены. Происхождение — собственные метаданные PR63, отдельный простой обработчик запуска и прежнее правило учебного документа. Список исходных файлов и хешей — `CONFIGURATION_MANIFEST.json` рядом с файлом загрузки. Это проектная оценка состава нашего артефакта; она не расширяет лицензию платформы.

На установленной 8.3.27.2214 проверены сборка CF, загрузка в другую новую базу, проверка конфигурации и совпадение модуля после обратной выгрузки. В отдельной временной Windows официальная учебная 8.3.27.1508 загрузила тот же CF, проверила его, вернула тот же модуль и выполнила исходный стартовый фрагмент с наблюдателем завершения. Сеть и запись в папки основного компьютера отключены; собственная временная среда остановлена. Автоматический протокол не объявляется наблюдением видимого сообщения, проверкой авторства или серверной оценкой ученика.

Первый инженерный запуск этого дополнительного CF-теста не создал временную среду: неверно экранирован разделитель в новом отображаемом пути. Команда запуска отказала до исполнения 1С; последующий штатный список сред был пуст. Исправлен только путь внешнего проверочного пакета, исходный отказ сохранён отдельно. Ни runtime-политика продукта, ни правила лицензирования, ни release gates не менялись.
