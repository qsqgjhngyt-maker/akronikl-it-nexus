# Автономный корпус V2: одна точка входа и отдельные публичные данные

Статус: IMPLEMENTED; проверки Chromium file:// и отрицательных сценариев — AUTOMATED PASS. Общий допуск курса и публикация этим решением не объявляются.

## Причина

После двух глубоких эталонов, справочника, простого маршрута лабораторной и сохранения места занятия прежний единственный HTML достиг 649836 байтов при пределе 650000. Дальнейшая содержательная переработка требует места для учебного текста. Ограничение начальной загрузки платформы NEXUS-PERF-01 не повышается: проверены 80 статических модулей / 639152 исходных байта при прежних пределах 80 / 640000. Это статическая проверка, не field p95.

## Решение и границы

Ученик распаковывает весь автономный пакет и открывает прежний `onec-offline.html`. Оба Course ID, RU/EN, ключи сохранений и URL главного файла внутри выбранной папки сохраняются. Платформа 1С в пакет не включена. В `data/` находятся части только публичного корпуса; в `media/` — подлинные учебные снимки.

Главный статический скрипт остаётся под точным SHA256 в CSP. Он получает части от скрытых локальных документов с `sandbox="allow-scripts"`, без `allow-same-origin`, форм, всплывающих окон и доступа к родительскому DOM/storage. Дочернему документу передаётся только одноразовый идентификатор запроса; аккаунт, прогресс, работы, код ученика и вопрос помощнику ему не передаются. Каждый дочерний скрипт также имеет точный CSP-хеш и `connect-src 'none'`.

Родитель принимает сообщение только от конкретного `contentWindow`, с ожидаемыми типом, номером и идентификатором. Проверяются длина, формат base64, SHA каждой части и SHA объединённых сжатых данных. Данные распаковываются только как JSON; `eval`, Function, Blob-скриптов и декомпрессии исполняемого кода нет. После успеха или отказа временные документы и обработчики удаляются. При отказе курс не начинает читать или записывать личное состояние.

Действует прежний предел 650000 байтов для главного HTML; каждая часть тоже ограничена 650000. Дополнительно: максимум 8 частей, 196608 сжатых байтов на часть, 1500000 сжатых байтов всего; прежняя граница развёрнутых публичных данных 4000000 байтов сохранена. Суммарный HTML теперь измеряется отдельно. В первом прототипе нового формата он составлял 688870 байтов, включая 129344 байта главной страницы. Это увеличение совокупного размера относительно прежнего одиночного файла, а не доказательство равного трафика или ускорения. Итоговые размеры пересчитываются для каждого артефакта.

Обязательная установка ученика остаётся обычной официальной учебной 1С. Внутренняя упаковка автономной книги не добавляет ученику шагов с терминалом, Sandbox или JSON. Существующие Studio, официальный изолированный запуск и старые инженерные проверки сохраняются.

## Рассмотренные альтернативы и неудачные опыты

1. Уплотнение повторяющихся JSON-строк и минификация статического JS работали, но одиночный HTML почти исчерпал бюджет. Дополнительное извлечение строк из JS потребовало отдельного парсера; этот эксперимент не вошёл в итоговую реализацию, зависимость Acorn удалена.
2. Внешний локальный JS с SRI и точными CSP-хешами заблокирован реальным Chromium file://: проверка SRI требует CORS. Прототип сохранён вне репозитория; обход CORS и специальные ослабляющие флаги браузера не применялись.
3. Разделение на самостоятельные страницы уроков/языков меняло бы URL и поведение file://-сохранений. Выбран прежний единый адрес приложения; разделены только публичные данные.
4. Не принято выполнение декомпрессированного кода из строки и повышение бюджетов начальной загрузки Nexus.

## Проверки и ограничения

`tests/onec-offline-parts-browser.mjs` проверяет настоящий file:// без сети: правильный пакет, недоступность родительского DOM дочернему документу, подмену данных с действительным хешем самого дочернего скрипта, отсутствующую часть, traversal, удаление временных документов и неизменность сохранённой работы. Подмена отвергается по хешу данных; неизвестная/отсутствующая часть — по ограниченному ожиданию. Дополнительно проверены снимки, RU/EN, увеличение и узкие экраны в холодном автономном пакете.

Остаются полный текущий браузерный прогон 168 локализаций, WebKit, итоговый пакет после всех переработок и опубликованная сборка. Физические Android/iPhone владелец проверяет после публикации. Новая упаковка не предоставляет серверную аттестацию и не доказывает педагогическую эффективность.
