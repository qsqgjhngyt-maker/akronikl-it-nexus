# Неудачные эксперименты и исправления

История относится к новой версии, прежние акты не переписываются. Только синтетические данные; приватные process logs, backup и сами базы не публикуются.

| Проблема → гипотеза | Попытка и результат | Причина → решение → регрессия |
|---|---|---|
| Цена минуты не соблюдает дробное округление | Первый настоящий native запуск: FAIL P3.numeric-rounding-and-zero; безопасная строка ROUNDING_REJECTED.txt | Вызван старый учебный расчёт без нужного контракта. В новом полном стенде введён отдельный валидируемый расчёт с округлением. Реальная положительная проверка и компилируемая semantic mutation без округления различаются: эталон PASS, мутант отклонён. |
| Повторное проведение удваивает движения | Второй native запуск: FAIL P6.repost-no-duplicate; REPOSTING_REJECTED.txt | В повторно используемом объекте сохранялись строки набора. Обработчик нового документа очищает свой набор перед заполнением. Повтор/изменение/отмена, соседний регистратор и rollback прошли на официальной платформе. Пример урока P5 обновлён RU/EN. |
| Конструктор даты отвергает исходник | Промежуточная компиляция отвергла четырёхаргументный вызов Дата; положительный результат не заявлялся | Исправлено на допустимый полный состав параметров. Последующий CheckConfig и все 70 case IDs PASS. Приватный диагностический журнал остаётся вне Git. |
| Сохранение формы стало асинхронным после Web Lock | Браузер сначала не подтверждал прогресс/копии | preventDefault перенесён до ожидания lock; ответы, заметки и lab attestation снимаются до ожидания. Проверки ждут фактический commit. Старые attempts/provenance сохранены. |
| На мобильном экране схема визуально есть, но нажатие попадает в текст | Браузерная эмуляция P12: layout innerHeight1762 при visualHeight844, offset918; MOBILE_BEFORE.png | Длинное содержимое fieldset расширяло layout viewport. min-inline-size: 0 и перенос слов исправили геометрию: 390×844, offset0, реальное нажатие PASS. Новый assert сравнивает ширину с заданным viewport, прежний сравнивал две одновременно расширившиеся величины. Все 168RU/EN×4 размера прошли. |
| PWA установлена, но reload урока с hash без сети отклонён | Первая preview сборка: SW install PASS, offline reload FAIL | Публичная policy разрешала fragment только 3D loader. Добавлено узкое правило exact producer-hashed HTML двух курсов, с закрытыми ключами course/locale/lesson/assessment. Private/API/чужой origin/POST/query/дубли отвергаются; старые security tests сохранены. Повторная настоящая установка SW и offline reload обоих finals/P12 PASS. |
| Windows PowerShell5 отказала в выполнении нового script | Не являлось результатом 1С | Использован обычный PowerShell7 с действующей RemoteSigned. Политика ОС, admin features и настройки защиты не менялись. |

Синтаксически некорректный BSL и компилируемый семантический мутант — намеренные отрицательные контроли, их отклонение является ожидаемым результатом. Ограничение локальной сети среды исполнения инструментов устранено разрешённым запуском локального тестового сервера; оно не выдаётся за дефект платформы.
