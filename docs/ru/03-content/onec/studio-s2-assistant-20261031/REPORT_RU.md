## Что изменилось

Учебный помощник знает обе канонические траектории: `onec`52 темы/P1–P12 и `1c-enterprise`32/A1–A8. В индексе все84RU/EN теории, цели, предпосылки, пошаговые разборы, задания и инструкции лабораторных. Нет ответов quiz/final, чужих работ, личности или истории. Поиск ограничен200 знаками/6 результатами, выдаёт выдержку и точный путь/revision/SHA256 исходного урока. Без совпадения не выдумывает ответ. Программа и следующий шаг доступны без ИИ-модели, API и платных услуг.

В плеере используется его локальный самоотчёт, без переноса completion другого направления. В общем чате прогресс кандидата не подключается к Account молча: помощник сообщает об отсутствии привязки и открывает отдельный курс. Прежний строгий C++ knowledge loader,67RU/EN, его digest и schema не меняются. Новый индекс имеет свой pinned manifest и отдельный публичный cache с повторной проверкой SHA. Холодный автономный HTML восстанавливает индекс из встроенных материалов без сети и дублирования всей теории.

Разговоры и ветки выведены слева. Можно создать разговор, выбрать ветку и удалить её после подтверждения в интерфейсе. Общие сообщения остаются, пока нужны хотя бы одной ветке; недостижимые узлы и их вложения удаляются. Последняя ветка заменяется новой пустой с новым UUID. Формат сохранённых чатов и account revision/CAS не меняется. Прежнее удаление сообщения с продолжением остаётся отдельным действием. Мобильная панель открывается кнопкой; исправлены переполнение320px, размер логотипа и двойное яркое выделение ввода.

Голос: диктовка вставляет финальный текст в поле для редактирования; разговор отправляет завершённую реплику и озвучивает ответ существующим speech controller. Для следующей реплики пользователь нажимает «Говорить». Постоянное фоновое прослушивание не включается. До30 секунд/1500 знаков, остановка/отказ прав/смена контекста/скрытие вкладки/закрытие отменяют поздние результаты. Аудиозапись и API распознавания на BFF не добавлены. Локальный режим требует `processLocally`; режим сервиса браузера требует отдельного явного согласия, поскольку звук может передаваться внешнему сервису. Языковой пакет автоматически не устанавливается. Поддержка браузером и качество RU/EN микрофона пока NOT RUN физически. Источник ограничений: [Web Speech API](https://webaudio.github.io/web-speech-api/), [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).

Docker Desktop запущен владельцем; подтверждён Linux engine29.1.3/Desktop4.55.0. Посторонние контейнеры/образы не изменялись. Создан только локальный собственный образ с официальным OneScript2.2.0. [MPL2.0 точного tag](https://raw.githubusercontent.com/EvilBeaver/OneScript/v2.2.0/LICENSE) и [официальный release](https://github.com/EvilBeaver/OneScript/releases/tag/v2.2.0) проверены; SHA256 архива `3b3b0a96e141d6758b74cbf492d5e5c11823bfd92318caff1aaa19bd500f1df7`. Платформа1С и чужие конфигурации в образ не копировались. Бинарники и образ не публикуются. Для будущей передачи образа необходимо сохранить notices и доступ к соответствующим исходникам/лицензиям всех компонентов.

Реальное выполнение собственного BSL в OneScript и35 общих P2 case IDs сопоставлено с прежним принятым официальным native эталоном8.3.27.2214. Отрицательные syntax/semantic mutant отклонены. Доказана только эта область совместимости. OneScript не объявляется платформой1С и не принимает её формы/регистры/СКД автоматически.

Одноразовые контейнеры: без сети, host mounts, портов, устройств и привилегий; UID65532, read-only root, cap-drop ALL, no-new-privileges;256MiB,0.5CPU,32 процесса,256 дескрипторов,16MiB tmpfs/noexec/nosuid,1MiB файл,128KiB вывода и wall timeout. Policy проверяется inspect до исполнения. Удаляется только контейнер с UUID-label текущего job. Браузер не получает Docker socket, API bridge и host fallback. CLI доступен доверенному локальному оператору, не является общедоступным multi-tenant сервисом. Независимая security рецензия остаётся необходимой.

Studio экспортирует независимый снимок текущего `.os` до16384 UTF-8 байтов, включая несохранённую версию, с workId/ревизией/SHA256. Отдельный receipt не изменяет работу и прогресс. Вывод ученика недоверенный и не даёт автоматического зачёта: `automaticGrade=false`, `codeVerifiedServer=false`, `credentialEligible=false`.

Официальный guest полного проекта1С остаётся PLANNED/BLOCKED. Установленная Windows-платформа не исполняется Linux-контейнером. Windows Sandbox/Hyper-V management не обнаружены; чтение optional features требует Windows admin, чего текущий процесс не имеет. Компоненты ОС не включались и перезагрузка не выполнялась. Полное точное соглашение training-поставки online.1c.ru `agreement.php?ID=16463663` недоступно для проверки. Право host не приравнивается к правам guest или общего класса. [Учебные версии1С](https://v8.1c.ru/podderzhka-i-obuchenie/uchebnye-versii/) и [лицензионные разъяснения1С](https://v8.1c.ru/priobretenie-i-vnedrenie/otvety-na-tipovye-voprosy-po-litsenzirovaniyu-1s-predpriyatiya-8/) служат источниками, а не подтверждением права выбранного размещения.
