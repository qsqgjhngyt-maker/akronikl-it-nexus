# Benchmark 01 — «Первая программа C++»

ID: `cpp.first-cpp-program`

Статус: **Benchmark Standard 1.1 / RU+EN complete**

## Назначение эталона

Урок должен доказывать, что Nexus является не набором коротких карточек, а системой усвоения знаний: понятная первичная модель → фундаментальная теория → терминология → внутренняя модель выполнения → интерактивная практика → диагностика → лабораторная работа → контроль понимания → Skill Graph.

## Обязательные признаки

- ученик различает язык C++, исходный код, IDE, compiler, linker, runtime и OS;
- термины и сокращения расшифровываются при первом содержательном появлении;
- объясняется путь `source → preprocess → compile → object code → link → runtime → main → exit code`;
- пользовательский учебный текст не содержит отсылок к исходному PDF или внешней структуре источника;
- provenance хранится отдельно во внутренней документации и не смешивается с учебным интерфейсом;
- есть современный переносимый пример;
- ошибки рассматриваются как диагностические задачи: симптом → этап → причина → исправление;
- теория связана с практикой, лабораторной работой и Skill Graph;
- RU и EN используют один stable lesson ID и один прогресс;
- базовое упражнение выполняется во встроенной `Nexus Sandbox` без обязательной установки VS Code, Visual Studio или другой IDE.

## Требование к песочнице

Для эталонного урока ученик должен иметь возможность:

1. редактировать код внутри урока;
2. задавать `stdin`;
3. запускать программу;
4. видеть `stdout` и диагностику;
5. выполнить самопроверку runtime;
6. сохранить изменённый код в прогрессе урока;
7. выполнить базовый учебный сценарий на desktop и в мобильном браузере без обязательной внешней IDE.

## Критерий принятия

После урока учащийся должен уметь своими словами объяснить роль `#include`, `iostream`, `std`, `::`, `std::cout`, `<<`, `main`, `;`, `\n`, `return 0`, различать compile/link/runtime failure и выполнить базовую программу внутри Nexus Sandbox.
