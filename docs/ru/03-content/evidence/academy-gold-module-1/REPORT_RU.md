## Ошибки и исправления

| Проблема → гипотеза → попытка | Результат и причина | Решение → regression |
|---|---|---|
| Предыдущий скрипт остановился на точном текстовом фрагменте offline entry | По handoff пользователя коммитов после этой попытки не было; старая привязка не соответствовала исходнику | Интеграция по фактическому маршруту и общему lessonData; независимые browser entry points |
| Неудачное чтение и неограниченная арифметика | Код мог использовать невалидный ввод или переполнить int | Проверки извлечения, допустимые диапазоны, правило округления; g++ + UBSan, пустые и граничные случаи |
| Последовательная трасса выглядела как блок-схема ветвления | У рисунка не было обеих альтернатив | Полный граф обеих ветвей с да/нет; keyboard/viewport и снимки |
| Старый shared-presentation тест ожидал меню до Code Studio | Ошибка воспроизведена на исходном bad182c | Добавленные ранее инструменты проверяются отдельно, остальные байты продолжают сравниваться со snapshot; 31/31 PASS |
| Private response test не нашёл jpeg-js | Недостающие локальные зависимости, не продуктовый дефект | npm ci из lockfile; проверка private response PASS |
| Активный узел вне видимой части при resize | Первое позиционирование выполнялось при прежней ширине; CSS мог ещё загружаться | Ожидание stylesheet и ResizeObserver с отключением после удаления; проверка полного попадания active node в видимую область 360/390 px |

Промежуточные неуспешные browser-прогоны сохранены рядом с рабочей копией в outputs/academy-gold-evidence/. Их не объявляли PASS. Ошибки тестовых селекторов исправлены по фактическому UI; сценарий проверяет собственный снимок workspace, а не неверно предполагаемую форму runtimeFiles.
