# Backup / Restore Policy

Перед значимым релизом создаётся архив полного source snapshot опубликованной базы и записываются SHA-256.

Backup содержит: исходники, commit/reference metadata (если доступны), file inventory, restore instructions, checksums и дату.

Восстановление выполняется в новую папку/ветку. Сначала проверяются hashes и локальный smoke-test, затем только производится замена production. Browser localStorage/PWA data являются отдельным состоянием и не восстанавливаются простой заменой файлов.
