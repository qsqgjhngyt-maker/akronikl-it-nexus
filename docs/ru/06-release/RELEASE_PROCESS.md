> **Основной язык документации: русский.** Русская версия является нормативной. Английская версия поддерживается как вторичное зеркало для международных пользователей.

# Release Process

1. Зафиксировать исходный baseline/previous release.
2. Создать локальную рабочую ветку.
3. Внести изменение минимальным логическим пакетом.
4. Прогнать regression gates.
5. Собрать LOCAL/preview.
6. Провести ручной smoke-test.
7. Создать PATCH относительно точной опубликованной базы.
8. Проверить patch-application на чистой копии.
9. Сформировать changelog, manifest, SHA-256 и restore point.
10. Только после этого публиковать.
11. После публикации проверить Pages/PWA update и версию.

Названия changelog/commit в основной ветке документации — на русском; при публичной международной разработке допускается EN-дубликат описания.
