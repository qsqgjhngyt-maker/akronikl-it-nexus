> **Основной язык документации: русский.** Русская версия является нормативной. Английская версия поддерживается как вторичное зеркало для международных пользователей.

# Versioning

На этапе разработки используется SemVer-подобная схема: `MAJOR.MINOR.PATCH-pre.N`.

- `foundation` — документация/архитектура без обещания production-ready;
- `alpha` — активная разработка, возможны изменения контрактов;
- `beta` — архитектура стабилизирована, идёт содержательный/устройственный QA;
- `rc` — кандидат в релиз, только исправления и контролируемый polish;
- stable — прошёл определённые release gates.

Версия платформы и версии course packages в будущем разделяются.
