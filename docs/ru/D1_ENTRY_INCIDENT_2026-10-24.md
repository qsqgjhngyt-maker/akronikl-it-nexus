# Инцидент входа Nexus 24.10.2026

STATUS: PARTIAL. Первопричина отказа базы подтверждена, вход пока не восстановлен.

## Доказательства

Реальный запрос чтения служебной таблицы `nexus_passkey_service_nonces` через Cloudflare D1 API вернул код 7500 и сообщение `Your account has exceeded D1's free tier daily row read limit.` Запрос `SELECT 1`, который не читает строки таблицы, продолжал работать. Поэтому его прежний успех не доказывал доступность базы для входа.

Агрегаты D1 Insights за скользящие сутки: очистка `nexus_admin_nonces` выполнена 5101 раз, прочитала 6 845 374 строки, среднее 1341 строка за запрос. Это не точный счётчик текущего UTC-дня. Форма запроса совпадает с очисткой media RPC в `admin-service.mjs`: фильтр `nonce LIKE 'mp1:%'`, `expires_at<?1`, `LIMIT 128` внутри подзапроса DELETE. Таблица имеет PK по nonce; подходящего индекса по истечению срока в media namespace в исходной миграции нет.

Вход возвращал `PASSKEY_UNAVAILABLE` HTTP 503; пользователь также предоставил `ENTRY_ACCOUNT_UNAVAILABLE`. Блокировка D1 препятствует чтению аккаунта и работе Passkey. Для второго кода внутренний ответ конкретного пользовательского запроса не получен; не выдаём его за отдельную полностью трассированную проверку.

## Исправление и проверка

Миграция 0017 добавляет частичный покрывающий индекс `(expires_at, nonce) WHERE nonce LIKE 'mp1:%'`. Она не меняет runtime, строки, ключи, cookies, TTL, replay-политику, полномочия или пользовательские данные. Запрос очистки остаётся прежним.

Настоящий локальный workerd/D1, compatibility date 2026-09-23, синтетические 10 000 legacy nonce:

| Проверка | До | После |
|---|---:|---:|
| Очистка 40 истёкших media nonce: строк прочитано | 10 161 | 161 |
| 20 пустых очисток: строк прочитано | 200 040 | 40 |
| Контрольная очистка rate limits: строк прочитано | 67 | 67 |

План основной очистки изменился с полного SCAN на SEARCH по новому индексу. Применение миграции дважды успешно. Legacy и неизрасходованные nonce сохранены, повторный nonce отклонён, удаление ограничено 128 строками. Это AUTOMATED PASS локально; production-применение и LIVE вход ещё не подтверждены.

## Восстановление

Владелец выбрал остаться на бесплатном тарифе и ждать сброса лимита. Согласно документации Cloudflare, 5 млн чтений в сутки на Workers Free сбрасываются в 00:00 UTC — 07:00 по Красноярску. Смена тарифа не выполнялась.

После 07:00: проверить реальный запрос служебной таблицы; применить только 0017 к базе `akronikl-nexus-sync`; проверить существование и использование индекса через EXPLAIN QUERY PLAN; проверить публичную регистрацию Passkey; выполнить настоящий вход пользователя и возврат к курсу. Ограничить повторные проверки до нескольких запросов. Если лимит ещё действует, сохранить точную ошибку и не считать восстановление PASS. Никаких переносов данных, ослабления аутентификации, обходов квоты или выкладки C++.

Добавление индекса обратимо отдельным DROP INDEX, но автоматический откат без причины не требуется. Основной Worker и BFF остаются прежних версий; main и релизы не меняются.
