# Конкурентная концепция

## Чем продукт должен отличаться

1. **Учебник, а не краткий конспект.** Сложные темы получают объёмную самостоятельную теорию.
2. **Модель внутренних процессов.** Память, стек/куча, процессы, транзакции, индексы, сети, ML pipeline визуализируются там, где это помогает пониманию.
3. **Ошибки как часть обучения.** Akronikl разбирает конкретную ошибку в контексте кода и текущего урока.
4. **Skill Graph.** Прогресс измеряется не только процентом курса, но и компетенциями.
5. **Междисциплинарность.** Уроки ссылаются на prerequisites и связанные темы других курсов.
6. **Проектный выход.** Практики и курсы формируют портфолио.
7. **Offline-first база + online intelligence.** Базовый курс остаётся полезным без AI-сервиса.
8. **Проверяемость.** Контент и приложение имеют автоматические аудиты.

## Антипаттерны

- тысячи шаблонных уроков;
- AI-ответы без знания текущего контекста;
- API-secret во фронтенде;
- смешивание платформенного кода и содержания в одном гигантском файле;
- «100% готово» только по наличию названий тем;
- неконтролируемый server-side code execution.
