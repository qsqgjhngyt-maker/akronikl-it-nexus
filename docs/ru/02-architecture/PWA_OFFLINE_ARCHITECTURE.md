# PWA / Offline Architecture

## Цель
Учебная оболочка, уже скачанные курсы, заметки и локальный прогресс должны оставаться полезными без сети.

## Политика кэша
- shell cache версионируется отдельно от course-content cache;
- AI responses по умолчанию не считаются обязательной offline-частью;
- runner cache зависит от лицензии/технических возможностей;
- неудачная установка новой версии не должна уничтожать старую рабочую;
- cache cleanup выполняется только после успешной активации новой совместимой версии.

Текущий baseline использует `cpp-course-v7-shell-1`; это фиксируется как исходная точка, а не как целевая архитектура.
