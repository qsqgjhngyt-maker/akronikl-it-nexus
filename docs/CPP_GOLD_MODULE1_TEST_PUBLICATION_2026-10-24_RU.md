## План публикации и LIVE gate

Две воспроизводимые сборки → hash/manifest/защищённые контракты → точный CI feature → PR в main с проверкой ожидаемого SHA → штатный Pages deployment → чтение опубликованных файлов через Pages и Yandex → анонимные auth guards и готовность passkey → браузерная проверка. Backend/Worker/D1/Identity deployment не требуется и не выполняется.

Реальные аккаунт, учебный прогресс и проекты проверяются только в обычном UI владельца. Без доступа к вошедшему профилю или подтверждения владельца FULL LIVE PASS не присваивается. Автоматический Cloud PUSH/PULL, сброс прогресса, очистка данных сайта, переустановка PWA и вывод cookies/ключей не выполняются. Публичные evidence используют синтетические данные, личные screenshots в GitHub не попадают.

Проверки NEXUS-PERF-01: static startup budget, Home lazy, lifecycle и media guards. Старые измерения ускорения относятся к `9e0ab633`, новые field latency не заявляются. Реальные Android/iPhone/Safari/AT и полный WCAG остаются ручной приёмкой; предупреждения axe у Code PRE сохранены в предыдущем evidence и не переименованы в PASS.
