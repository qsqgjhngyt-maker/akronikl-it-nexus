# Как загрузить WORK07 на GitHub

Этот ZIP — **GITHUB OVERLAY**.

1. Распаковать поверх текущего репозитория.
2. Сохранить пути `docs/ru`, `docs/en`.
3. Runtime/version badge не менять.
4. Commit:

```text
docs: complete v0.1.7-alpha.2.3 WORK07 competitive research
```

5. Push в `main`.

WORK07 — research/documentation package, а не новый application release.

Важно:
в конкурентных документах `NOT CONFIRMED` означает отсутствие подтверждения в просмотренном публичном материале, а не доказанное отсутствие функции.
