# Product Vision — Akronikl IT Nexus

Akronikl IT Nexus is an engineering IT learning platform whose core learning path is free to learners, combining a deep digital textbook, interactive labs, projects, Skill Graph and the contextual AI mentor Akronikl.

The platform teaches not only how to write code but how to think as an engineer: understand execution models, diagnose errors, connect disciplines, document decisions and complete working projects.

The primary focus is Russian-speaking learners, while the product is designed internationally: **Russian-first, not Russian-only**.

Core value: deep theory, internal-mechanism explanations, adjacent practice, contextual Akronikl, cross-discipline Skill Graph, project portfolio, offline/PWA-first design, multilingual UI/course/mentor architecture, free core learning and a rights model that protects code/content/brand from unauthorized commercial repackaging.

Positioning: **interactive textbook + engineering laboratory + mentor + development path + portfolio + knowledge assimilation system**.
