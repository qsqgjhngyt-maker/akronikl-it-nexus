# Первое создание репозитория akronikl-it-nexus

1. Создать новый пустой репозиторий `akronikl-it-nexus`.
2. Не добавлять автоматически шаблон README, если планируется загрузить этот starter-пакет целиком.
3. Распаковать содержимое данного пакета в корень локального клона или загрузить его в корень GitHub.
4. Первый коммит рекомендуется назвать: `docs: зафиксирован Foundation Akronikl IT Nexus`.
5. До Sprint 1 не переносить монолитный `cpp-course/index.html` в новый root.
6. Исходный C++ v7 хранить отдельным backup/baseline.
7. Любые секреты/API keys запрещено коммитить; `.env` исключён через `.gitignore`.
