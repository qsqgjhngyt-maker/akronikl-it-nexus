# Initial setup of the akronikl-it-nexus repository

1. Create a new empty repository named `akronikl-it-nexus`.
2. Do not auto-generate a README if this starter package will be uploaded as-is.
3. Extract this package into the repository root or upload its contents to the GitHub root.
4. Recommended first commit: `docs: establish Akronikl IT Nexus Foundation`.
5. Do not copy the monolithic `cpp-course/index.html` into the new root before Sprint 1.
6. Keep C++ v7 separately as an immutable backup/baseline.
7. Never commit secrets/API keys; `.env` is ignored by `.gitignore`.
