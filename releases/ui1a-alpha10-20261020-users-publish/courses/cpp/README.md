# C++ course package — v0.1.3-alpha.1

Первый reference-курс AKRONIKL IT NEXUS.

## Текущее состояние

- 40 тем C++ v7 перенесены в модульный course package со стабильными language-neutral ID.
- 6 практикумов и 7 итоговых проектов сохранены.
- `cpp.first-cpp-program` и `cpp.pointers-references-addresses` полностью переработаны по Benchmark Standard.
- Для двух benchmark-уроков существуют полноценные RU и EN тела.
- Для остальных 38 тем английский контент пока использует честный fallback на русский baseline.
- Benchmark 02 включает интерактивную символическую модель памяти: object → address → pointer → dereference → reference/alias → lifetime.
- Старый `cpp-course v7` остаётся immutable reference baseline.

## Benchmark-уроки

1. `cpp.first-cpp-program` — **complete RU/EN**
2. `cpp.pointers-references-addresses` — **complete RU/EN + interactive memory model**
3. `cpp.oop-principles` — next

Benchmark Standard включает: prerequisites, мотивацию, быстрое понимание, глубокую и полную теорию, внутреннюю модель, построчный разбор, управляемые эксперименты, ошибки «симптом → причина → исправление», самостоятельную практику, лабораторию, глубокую проверку, Skill Graph и чек-лист понимания.

Прогресс старого курса импортируется неразрушающе: legacy-ключ `cpp_programming_pdf_course_v1` не удаляется.
