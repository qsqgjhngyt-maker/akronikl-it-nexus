Nexus — серверный вход и обратная связь
Passkey: существующий аккаунт + одноразовое приглашение администратора; создание
ключа и вход подтверждает сам пользователь на своем устройстве. Имя не является
доказательством владения аккаунтом. WebAuthn UV/challenge/signature обязательны.
Модератор: только явно выбранный существующий account ID через trusted SQL.
Публичны лишь одобренные отзывы с актуальным согласием. API private/no-store.
Legacy Cloud Sync в worker/legacy-sync.js сохранен побайтово; маршрутизация новых
API добавлена отдельным entry.mjs. Секретов, приглашений и database backups в Git нет.
Локальный Docker не нужен: workflow собирает только image tar, без облачных ключей
и автоматического deployment. Публикацию выполняет доверенный оператор отдельно.
