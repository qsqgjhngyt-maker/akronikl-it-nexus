# Интеграционный кандидат UI-1A для ветки 05

Основание: решение MASTER 00 от 18.10.2026. Единственный целевой репозиторий:
`qsqgjhngyt-maker/akronikl-it-nexus`, `main`.

Кандидат объединяет проверенный локальный UI-1A, POLISH-01/02, Mobile Flight и IA-01
с main `18389da0737dc9cebb8ac5dbe54d7bfe2959dc9f`. Исторический ORIGINAL не изменён.
Инкрементальные архивные patches повторно к preview не применялись.

Новый PWA worker не включён: SEC-PWA-02C и независимая приёмка 02E найдены в
историческом архиве. Приёмка ограничена isolated/synthetic scope; реальная public
authority, RUNTIME-001 и browser lifecycle остаются открытыми. Прототип 02D не
переносился в Nexus. Исторические запреты на интеграцию не выдаются за разрешение
этого кандидата: основанием нового производного integration является прямое
поручение пользователя от 18.10.2026.
Прежний worker из main оставлен в истории исходников, но не входит в публичную
сборку и не регистрируется приложением. Account/Passkey и feedback transport
из локального кандидата выключены `core/ui1a-release-contracts.js` до согласования
владельцев 01/02/03. Существующие Identity, Cloud и runtime модули main сохранены.
Выключенные функции не считаются прошедшими функциональный release gate.

Это локальный кандидат с блокирующими gates, не разрешение на публикацию.
Историческая sealed ORIGINAL UI AFTER authority и непосредственное IA→TEST
происхождение внешнего теста остаются NOT VERIFIED по STEP 4B. Текущий проверенный
snapshot не переименовывается в ORIGINAL. Новая AFTER inventory относится только
к этому производному кандидату; она не закрывает исторические gaps задним числом.
Реальные Android/iPhone/Safari, HTTPS install/update/offline/rollback и подтверждение
контрактов проверяются отдельно. Изменять production, выполнять push, deploy или
release нельзя до успешного независимого Release Gate 05 и разрешения владельца.

Полный пакет содержит точные исходники, публичную сборку, Git bundle, changeset,
BEFORE/AFTER SHA256, тестовую матрицу, сырые evidence, дефекты и план отката.
Все новые мобильные браузерные evidence — Chrome emulation, не Safari.
