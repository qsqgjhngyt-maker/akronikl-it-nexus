# Release v0.1.2-alpha.2 — Benchmark 01 · Theory & Nexus Sandbox

## Цель

Довести первый эталонный урок до уровня, который можно использовать как стандарт для следующих benchmark-тем и будущих дисциплин Nexus.

## Что изменилось

Урок «Первая программа C++» стал полностью самодостаточным для начинающего: профессиональная структура, 16 разделов фундаментальной теории, 20 терминов/сокращений, подробная модель сборки/выполнения, диагностика, эксперименты, практика, лабораторная работа и RU/EN паритет.

Практика остаётся внутри платформы: Nexus Sandbox содержит редактор, `stdin`, запуск, `stdout`, self-test runtime, восстановление примера и сохранение пользовательского кода. Для базового сценария отдельная IDE не обязательна.

## Важная граница alpha

Текущий C++ runtime является браузерной учебной реализацией. Он не заявляется как полный industrial native toolchain. Архитектура Sandbox должна позволить в будущем подключить WebAssembly/local/secure backend provider без изменения учебного интерфейса.

## Provenance

Информация о происхождении исходного курса не показывается в пользовательском учебном интерфейсе. Внутренний provenance и права сохраняются в документации проекта.
