# Legal Action Checklist

## P0 — before the first major public release

- [ ] Keep root `LICENSE` absent until the initial rights audit is complete.
- [ ] Identify key authors and rights holders.
- [ ] Build a third-party notices/rights inventory.
- [ ] Audit the C++ baseline and source PDFs.
- [ ] Replace material with unclear rights.
- [ ] Define AI-draft and human-review policy.
- [ ] Run preliminary trademark clearance for `AKRONIKL`, `AKRONIKL IT NEXUS` and core logos.
- [ ] Obtain legal review of the selected mixed-license model.

## P1 — before license activation

- [ ] Finalize the software license.
- [ ] Define exactly which content is CC BY-NC-SA 4.0.
- [ ] Exclude brand assets from the general license.
- [ ] Add copyright notices and third-party notices.
- [ ] Approve contributor rights model.
- [ ] Verify dependency-license compatibility.

## P2 — evidence and brand protection

- [ ] Consider optional Russian software/database registration as an evidentiary measure.
- [ ] File trademark application after clearance when the project reaches stable public use.
- [ ] Preserve release archives, SHA-256 hashes, Git tags and changelogs.
- [ ] Track authorship of content and translations.

## P3 — international expansion

- [ ] Choose priority jurisdictions.
- [ ] Evaluate national filings and/or WIPO Madrid System.
- [ ] Review privacy, child-safety and consumer-law requirements as accounts, analytics and cloud AI expand.
