# AKRONIKL IT NEXUS v0.1.2-alpha.1 — Benchmark Lesson 01

## Назначение релиза

Зафиксировать первый эталон качества учебного контента до масштабирования остальных дисциплин и тем.

Рабочий Platform Shell `v0.1.1-alpha.3` используется как baseline. Архитектура прогресса, стабильные ID, C++ sandbox, практикумы и проекты не меняются по смыслу.

## Что добавлено

- Полностью переработан урок `cpp.first-cpp-program` / «Первая программа C++».
- Benchmark Standard 1.0:
  - prerequisites;
  - зачем тема нужна;
  - быстрое понимание;
  - полная теория;
  - toolchain/runtime model;
  - построчный разбор;
  - управляемые эксперименты;
  - ошибки «симптом → причина → исправление»;
  - самостоятельная практика;
  - лабораторная;
  - глубокая проверка понимания;
  - Skill Graph;
  - итоговый чек-лист.
- Полноценная английская версия этого же урока с тем же stable ID.
- Добавлен `courses/cpp/data/lessons.en.json` как partial localization package.
- Переключение языка курса выбирает EN-урок там, где он авторизован, и безопасно возвращается к RU baseline для остальных тем.
- UI benchmark-блоков адаптирован под desktop/mobile.
- Service Worker cache namespace обновлён до `v0.1.2-alpha.1`.

## Что намеренно не делается

- Не переписываются остальные 39 тем до утверждения эталона.
- Не подключается облачный AI.
- Не меняется legacy progress key.
- Не удаляется и не изменяется исходный `cpp-course v7`.
- Не устанавливается alpha.4 recovery patch: текущий рабочий baseline — alpha.3.
