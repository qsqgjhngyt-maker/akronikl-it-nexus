# AKRONIKL IT NEXUS v0.1.2-alpha.2

## Benchmark 01 · Theory & Nexus Sandbox

### Контент

- `cpp.first-cpp-program` переведён на Benchmark Standard 1.1.
- Фундаментальная теория расширена до 16 логических разделов.
- Добавлен отдельный словарь из 20 терминов, сокращений и обозначений с расшифровками и примерами.
- Усилено объяснение границ: язык C++ ≠ IDE ≠ compiler ≠ linker ≠ runtime ≠ OS.
- Добавлена явная модель `source → preprocess → compile → object code → link → runtime → main → exit code`.
- Удалены пользовательские отсылки к PDF; provenance остаётся во внутренней документации.

### Nexus Sandbox

- Кодовый блок оформлен как единая встроенная среда Nexus.
- Добавлена кнопка самопроверки runtime.
- Добавлены понятные статусы загрузки/готовности/ошибки.
- Добавлена очистка вывода без сброса кода.
- Сохранена работа `stdin → run → stdout` и сохранение изменённого кода в прогрессе.
- На мобильных устройствах отключены autocorrect/autocapitalize/autocomplete для редактора и stdin; размер шрифта повышается до 16 px для предотвращения нежелательного zoom на iOS.

### UI

- «ПОЛНАЯ ТЕОРИЯ / Прочитать спокойно» заменено на «ФУНДАМЕНТАЛЬНАЯ ТЕОРИЯ / Системный разбор темы».
- Унифицированы профессиональные названия блоков: ключевая модель, модель выполнения, разбор кода, диагностика, практика, лабораторная работа, контроль понимания.
- Из заголовка урока убраны номера страниц источника и пользовательский блок `Источник v7`.

### Совместимость

- Stable lesson ID и legacy progress mapping не изменены.
- Остальные 39 уроков сохраняют прежние ID и данные; из их learner-facing theory удалены только прямые фразы «в PDF».
