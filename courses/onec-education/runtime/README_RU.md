# Изолированное языковое исполнение — кандидат S2

IMPLEMENTED: локальный операторский provider OneScript, неизменяемый снимок одного файла `.os`/`.bsl`, отдельный контейнер каждой попытки, receipt по SHA256/ревизии, отказ без Docker. Браузер не получает Docker socket или HTTP bridge. Автоматический зачёт отсутствует. Это не официальная платформа 1С.

В Studio доступна выгрузка снимка самостоятельного `.os` текущего курса, до16384 байтов UTF-8. Выгружается открытая версия, включая несохранённый текст; база работ, Account и прогресс не меняются. Полный проект конфигурации экспортируется прежней командой. Платформенный модуль не преобразуется в OneScript автоматически.

## Подготовка оператором

В новый отдельный каталог скачать [официальный OneScript2.2.0 Linux x64](https://github.com/EvilBeaver/OneScript/releases/tag/v2.2.0), архив `OneScript-2.2.0-linux-x64.zip`. Проверить SHA256 `3b3b0a96e141d6758b74cbf492d5e5c11823bfd92318caff1aaa19bd500f1df7`, распаковать в `engine/`, скопировать этот Dockerfile. Собирать локальный образ без публикации в registry. Пакеты платформы1С в образ не включаются. Никакие чужие образы или рабочие конфигурации не используются.

```powershell
docker build --tag nexus-onec-oscript:s2-20261031 <новый-каталог>
$env:ONEC_OSCRIPT_IMAGE_ID = docker image inspect nexus-onec-oscript:s2-20261031 --format '{{.Id}}'
node tools/check-onec-isolated-run.mjs nexus-onec-language-snapshot.json receipt-new.json
```

Рецепт фиксирует базовый digest. Пакеты Debian устанавливаются из подписанных репозиториев; повторная сборка может иметь другой digest, поэтому приёмка привязана к фактически проверенному image ID. Для передачи образа требуется сохранить notices/лицензии всех входящих компонентов, включая MPL2.0 и исходники соответствующего OneScript tag. Сейчас образ локальный, binaries/образ не публикуются в Git/Release.

## Ограничения

`network=none`, root read-only, UID65532, capabilities=ALL drop, no-new-privileges, без host mounts/портов/devices,256MiB RAM+swap cap,0.5CPU,32 процесса,256 файловых дескрипторов,1MiB размер файла,16MiB временный раздел noexec/nosuid. До10 секунд обычный запуск, максимум30 в операторском API; stdout+stderr до128KiB. Удаление только своего контейнера после проверки UUID-label, включая timeout/overflow. Временно созданные файлы не возвращаются на host. Клиент не задаёт Docker args или образ.

Из-за воспроизведённого конфликта `docker-init` с RLIMIT_FSIZE процесс OneScript запускается непосредственно как PID1. Таймаут завершается принудительным удалением целого контейнера; лимит32 ограничивает потомков и зомби. Это решение и отказ с nofile64 сохранены в evidence. Значения проверяются через inspect до выполнения. Docker daemon остаётся привилегией доверенного локального оператора; данный CLI не является готовым общедоступным сервисом для множества учеников.

Receipt содержит настоящий stdout, exitCode и границы среды, но stdout является недоверенными данными: ученик может сам напечатать PASS. `automaticGrade=false`, `codeVerifiedServer=false`, `credentialEligible=false`. Результат не переписывает исходник и completion. Повторный запуск создаёт новый job/контейнер, существующий receipt не перезаписывается.

## Официальная 1С

PLANNED/BLOCKED для выполнения недоверенного ученического проекта: нужен отдельно подготовленный и лицензированный guest официальной платформы. Установленная Windows8.3.27.2214 не запускается Linux-контейнером; бинарники не копируются и Wine не подменяет проверку совместимости. Наличие host-лицензии не доказывает право на новый guest или общий учебный сервис.

Формы, СКД, регистры, роли/RLS, управляемые блокировки и клиент-серверное поведение проверяются официальной платформой отдельно. Прежний доверенный native эталон сохранён. [Официальные учебные версии](https://v8.1c.ru/podderzhka-i-obuchenie/uchebnye-versii/) и [лицензионные разъяснения](https://v8.1c.ru/priobretenie-i-vnedrenie/otvety-na-tipovye-voprosy-po-litsenzirovaniyu-1s-predpriyatiya-8/) не заменяют проверку точного соглашения выбранной поставки и способа размещения. Точное соглашение online.1c.ru `agreement.php?ID=16463663` пока недоступно для полной проверки. Общая пригодность многопользовательского runtime и права guest не объявляются доказанными.
