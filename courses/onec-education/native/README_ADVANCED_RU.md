# Расширенная «Учебная сервисная служба»

Собственная конфигурация `service-desk-advanced`,18 файлов, версия1.1.0-advanced-qa. Исходный `service-desk-full` и учебные работы не перезаписываются. Новый шаблон не подменяет существующие Topic ID/прогресс. Только синтетические клиенты/услуги/заявки; копии базы обязательны.

`advanced-spec.v1.json` связывает каждый файл с размером/SHA и точными case IDs. Реальный запуск на ПК: полная1С8.3.27.2214; изолированный стенд: официальная учебная8.3.27.1508. Результаты не переносятся на другие версии автоматически.

Проверены76 native cases:70 прежних + настоящая СКД12строк/440минут, сравнение отбора с независимым запросом, создание/контрол/открытие формы, изменение поля без сохранения исходного документа. Setup71 создаёт только двух синтетических пользователей без пароля/OS-auth в отдельной учебной базе. Читатель6 проверяет свою фактическую роль, разрешённое подмножество/RLS `Минуты<=30`, отказ запроса без `РАЗРЕШЕННЫЕ`, чтение разрешённого объекта и отказ записи. Администратор затем выполняет76 проверок без reseed; снимок должен остаться прежним.

Оператор собирает **собственный** verifier из корня репозитория:

```powershell
./tools/check-onec-advanced-build.ps1 -OutputDirectory ../advanced-build-new
```

Дистрибутив1С/ключ/модель в сборку не включаются. Verifier на host обязан отказать кодом101. Только в подготовленной личной Windows Sandbox с readonly `C:\NexusInput`, прежним проверенным AF-эталоном и законно установленной учебной1С оператор запускает `NexusAdvancedRunner.exe --trusted-advanced-qa`. Код0 означает точное совпадение всех четырёх наборов/снимков/исходников. Код100+phase — отказ; не снижайте ожидаемые числа, не выдавайте загрузку конфигурации за исполнение. Завершите только свою VM и проверьте её отсутствие.

Verifier не принимает ученический код/произвольный путь и не является публичным runner. Сессии последовательны. Job Object ограничивает процессы/ресурсы/время; сеть и host output mappings не требуются. Общий сервер, scheduling/background jobs, EDT и client-server concurrency не приняты. `УчебныеЗадания` подготовлен, выполнение фонового задания не доказано.

Доказательства: [приёмка ПК](../../../docs/ru/03-content/onec/pc-acceptance-20261101/REPORT_RU.md). Сохраняйте безопасные case IDs/хеши; базы, private logs, сведения активации и реальные данные не передаются. Самопроверка локальна: `codeVerifiedServer=false`, `credentialEligible=false`; отметки/progress не записываются автоматически.
