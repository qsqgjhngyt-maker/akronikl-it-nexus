# Локальное распознавание на Windows

Whisper small multilingual — настоящая ИИ-модель. Личный оператор может явно выбрать CPU-сборку whisper.cpp v1.9.5 на Windows, когда Docker недоступен. Браузерная подсветка/эмуляция не участвуют. Бесплатная локальная обработка; облачный провайдер не подключён. Пакет репозитория не содержит vendor EXE или весов.

Источники/модели/MIT и SHA закреплены в `asr-lock.json`. Собственная сборка из официального архива и портативного CMake3.31.1 требует уже установленного Visual Studio2022/MSVC. `tools/check-onec-asr-windows-build.ps1` принимает SourceArchive,CmakeExecutable,новый OutputDirectory, проверяет hashes, компилирует статический x64 CPU CLI с curl=OFF и создаёт `WINDOWS_ASR_BUILD.json`. Системная установка не выполняется; лицензии/NOTICE исходного проекта сохраняются при передаче сборки.

Оператор выбирает параметры в своём локальном окружении, без секретов:

```powershell
$env:NEXUS_ASR_ENGINE='windows'
$env:NEXUS_ASR_WINDOWS_BUILD='C:\my-asr-build'
$env:NEXUS_ASR_MODEL_DIRECTORY='C:\my-asr-models'
$env:NEXUS_ASR_ORIGIN='http://127.0.0.1:8080'
node tools/check-onec-asr-server.mjs
```

Замените пример origin на точный адрес своего локального preview. Порт18792 привязан только к127.0.0.1. В models должны находиться ровно два файла из lock; несовпадение SHA/размера/символическая ссылка запрещают запуск. Браузер не выбирает EXE,файловый путь или модель. Existing Origin/Host/token/CORS/cookie guards сохранены; внешний сайт не получает распознавание. Token хранится в памяти, по завершении отзывается.

В помощнике выберите «Whisper small · локальная ИИ-модель». Диктовка добавляет текст в поле, не отправляя сообщение. «Голосовой разговор» должен повторять цикл слушания/ответа/озвучки до остановки/закрытия; в отсутствие речи ждёт следующую реплику. Требуется разрешённый физический микрофон и локальный голос озвучки. Одновременно один job, до30секунд реплика,90секунд распознавание, ограниченный вывод. Аудио передаётся собственному CLI через stdin, расшифровка stdout без output-файлов. Отмена завершает собственный процесс, потоки микрофона останавливаются.

Ограничение: Windows-процесс доверенный/личный, без Docker hard-memory limit и network namespace. Это не общий сервер и не молчаливое переключение с Docker. Нельзя объявлять этот путь эквивалентным изоляции Docker. Проверены RU/EN QA,тишина,ошибочный WAV,отмена; настоящий USB capture/stop выполнен. Естественная речь/два полных цикла остаются NOT_RUN до соответствующей приёмки.

После явного разрешения физического микрофона оператор может запустить `$env:NEXUS_LIVE_MIC='1'`, затем `node tools/check-onec-mic-live.mjs <новый-каталог>` с теми же build/model параметрами и установленным Playwright. Проверка открывает отдельный локальный тестовый аккаунт, включает два15-секундных окна, не сохраняет звук/расшифровку и не использует реальный Account. Пустое распознавание фиксируется как PARTIAL.
