# Локальная ИИ-модель распознавания речи

Кандидат PR63, без изменения BFF/Identity/production. Модель — Whisper small multilingual; движок whisper.cpp v1.9.5; выделение речи — Silero VAD v6.2.0. Версии, источники, размеры и SHA256 закреплены в `asr-lock.json`. Обе модельные карточки и движок имеют MIT; при передаче нужно сохранять notices и лицензии. [Whisper](https://github.com/openai/whisper), [whisper.cpp](https://github.com/ggml-org/whisper.cpp/tree/v1.9.5), [веса](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1), [VAD](https://huggingface.co/ggml-org/whisper-vad/tree/9ffd54a1e1ee413ddf265af9913beaf518d1639b).

Это отдельная модель speech-to-text. Разговорная модель получает уже распознанный текст по существующим настройкам чата. Справка по курсу работает без разговорной модели. Выбор локального Whisper не включает платный API и не переключает звук в облако при ошибке.

## Режимы пользователя

Диктовка вставляет текст для исправления и ручной отправки. Непрерывный разговор после явного запуска повторяет цикл: захват → распознавание → ответ → полная озвучка → новый захват. Во время распознавания, ответа и озвучки микрофон не работает. Остановить можно кнопкой; закрытие, скрытие вкладки, смена аккаунта/ветки/модели, открытие настроек и ошибки прекращают сеанс. Возобновление — явным запуском. Прошлый отменённый ответ не может остановить новый сеанс или включить его микрофон.

Каждая реплика до30 секунд/1500 знаков. Для определения конца используется пауза; backend VAD отбрасывает отсутствие речи. Браузерная локальная модель и сервис браузера остаются отдельными явными вариантами; внешний сервис требует отдельного согласия. Это не скрытые fallback для Whisper.

## Операторский запуск кандидата

Подготовить исходный архив и два модельных файла по lock, проверить все SHA256. Распаковать исходники в `source/` рядом с Dockerfile и `run-asr.sh`, собрать отдельный локальный образ. Базовый Debian digest закреплён; пакеты берутся из подписанного репозитория. Сборка GGML_NATIVE предназначена для CPU компьютера сборки; переносимость произвольного готового образа не заявляется. В Git нет бинарников, весов или образа.

```powershell
docker build --tag nexus-whisper-asr:v1.9.5-s3 <каталог-сборки>
$env:NEXUS_ASR_IMAGE_ID = docker image inspect nexus-whisper-asr:v1.9.5-s3 --format '{{.Id}}'
$env:NEXUS_ASR_MODEL_DIRECTORY = '<отдельный-каталог-двух-bin-файлов>'
$env:NEXUS_ASR_ORIGIN = '<точный-origin-проверяемого-frontend>'
node tools/check-onec-asr-server.mjs
```

Модуль слушает только127.0.0.1:18792 и допускает только указанный Origin/Host, без cookies и credential forwarding. Короткий токен хранится в памяти окна и локального обработчика, привязан к разрешённому origin; при закрытии отзывается, при бездействии истекает. Он не является сессией Nexus и не даёт прав на Account/работы. Частота/сеансы ограничены, inference один. Модель и VAD перепроверяются при запуске по размеру/SHA. Неизвестная модель не получает микрофон.

PCM16 mono16k WAV до960044 байтов передаётся из памяти браузера в stdin отдельного процесса. Аудиофайл на host не создаётся; звук не входит в чат, progress, outbox, evidence или логи. Сохраняется только текст, отправленный пользователем согласно выбранному режиму. Контейнер без сети, UID65532, read-only root, cap-drop ALL/no-new-privileges;2GiB RAM+swap cap,4CPU,32 процесса,16MiB tmpfs. Единственный read-only bind содержит два публичных файла весов; пользовательские каталоги/микрофонные устройства не монтируются. Timeout/отмена/вывод ограничены; удаляется только UUID-label собственного job. Общедоступный multi-tenant сервис и независимая security приёмка не заявляются.

## Приёмка

Реальная модель RU/EN, тишина, неправильный WAV и отмена проверяются `tools/check-onec-asr-native.mjs` с публичными/синтетическими QA WAV. Реальные устройство и речь человека отмечаются отдельно. Контрольная синтетическая запись не называется естественной речью пользователя. Метрики и остаток находятся в отчёте03/05 соответствующего milestone.
