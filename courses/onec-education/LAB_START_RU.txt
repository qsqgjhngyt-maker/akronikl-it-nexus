Как выполнить лабораторную: от Studio до учебной 1С

Nexus и 1С — два отдельных окна. В Studio вы пишете и сохраняете исходники. В установленной программе 1С вы открываете учебную базу и проверяете результат. Инструкция ниже предназначена для Windows.

Два способа работы: установленная 1С и временная Windows

Восемь шагов ниже описывают ручную работу в установленной учебной 1С: вы открываете окна, вводите данные и смотрите результат. Отдельный изолированный стенд предназначен для проверки снимка кода во временной Windows Sandbox. Для проверенного комплекта нужны Windows 11 Pro/Enterprise/Education x64, включённая виртуализация и заранее подготовленный личный комплект. В Windows Home этот путь не проверен.

Чтобы включить компонент, в меню «Пуск» найдите «Включение или отключение компонентов Windows», отметьте «Песочница Windows» и нажмите «ОК». Перезагрузите ПК, если Windows попросит. Если компонент уже включён, повторять шаг не нужно. До запуска комплекта закройте другие окна Sandbox.

Для изолированной проверки изменяйте код в Studio, нажмите «Сохранить» и дождитесь «Сохранено на устройстве». В разделе «Проверки в официальной 1С» выберите вид проверки и нажмите «Подготовить запуск 1С». Скачается nexus-onec-official-snapshot.json.

Запрос выполняет заранее подготовленный личный Windows-комплект. Его запуск сейчас является отдельным действием по инструкции «Как выполнить запрос на компьютере» в Studio. Скачивание JSON ещё не открывает временную Windows; кнопки автоматического запуска в браузере пока нет.

Комплект создаёт временную Windows, устанавливает в неё официальную учебную 1С, проверяет копию исходников и останавливает созданную среду. Внутри неё не храните единственный экземпляр работы и не редактируйте код: изменения вносите в Studio до следующей проверки.

После завершения в папке попытки появляется NATIVE_RESULT.json. В Studio нажмите «Загрузить протокол запуска» и выберите этот файл. В журнале появится результат именно этого снимка. Он не отмечает лабораторную выполненной автоматически.

Сохранённая работа и прогресс остаются в Nexus. Временная база и гостевые файлы удаляются. Обратно передаётся ограниченный протокол проверки, а не произвольные файлы или база.

1. Подготовьте программу 1С

Если официальная платформа 1С уже установлена и вы можете использовать её для обучения, переходите к следующему шагу. Иначе откройте официальную страницу учебных версий по ссылке в конце инструкции и выберите версию для обучения программированию. Платформа не входит в файлы Nexus.

Следуйте инструкции выбранной поставки. Если установщик находится в ZIP: нажмите на архив правой кнопкой → «Извлечь всё» → «Извлечь». Запустите setup.exe из распакованной папки, если такой файл есть в комплекте, и пройдите мастер установки. Условия использования прочитайте и примите самостоятельно.

В меню «Пуск» есть программа запуска «1С:Предприятие» или «1С:Предприятие — учебная версия». Сам по себе вход в Nexus не устанавливает 1С.

2. Откройте свою рабочую копию в Studio

Откройте нужный урок в Академии. Нажмите «Лабораторная работа», затем «Открыть лабораторную в Studio». Войдите в Nexus, если ещё не вошли.

Проверьте выбранные курс и урок. Нажмите «Создать новую рабочую копию». Если работа уже есть, откройте её из списка. Для нового эксперимента нажмите «Новая отдельная копия»: прежняя работа останется на месте.

Открылся редактор со списком файлов. У работы есть своё название. Для первых модулей в шаблоне 9 файлов, для полного учебного шаблона — 12.

3. Измените код и дождитесь сохранения

Выберите файл, указанный в задании. Файлы .bsl содержат код модулей 1С; .os предназначены для отдельных языковых упражнений. XML описывает устройство конфигурации и в исходной копии защищён от изменения.

Внесите изменение по условию лабораторной. Нажмите «Сохранить» и дождитесь надписи «Сохранено на устройстве». Для проверки откройте эту работу заново через «Мои проекты» и убедитесь, что текст остался. При сообщении об ошибке сохранения оставьте редактор открытым и выгрузите исходники.

Ваш код виден после повторного открытия. Сохранение кода не запускает программу и не отмечает урок пройденным.

4. Скачайте файлы и распакуйте ZIP

Нажмите «Скачать файлы ZIP». Браузер сохранит nexus-onec-sources.zip, обычно в папку «Загрузки». В архив попадает текущий текст открытой работы.

Нажмите на ZIP правой кнопкой → «Извлечь всё». Укажите новую папку, например C:\NexusLabs\Lesson_01, и нажмите «Извлечь». Откройте её. Рядом с инструкцией должна быть папка src.

Внутри src должны быть Configuration.xml и папки Ext, Catalogs и другие файлы шаблона. Папка с исходниками и папка базы 1С — разные папки. Если Configuration.xml нет, вы выгрузили отдельные файлы, а не полную конфигурацию: выполняйте инструкции именно своего упражнения.

Вы видите настоящий файл src\Configuration.xml в распакованной папке, а не внутри открытого ZIP-архива. JSON-выгрузку распаковывать не нужно.

5. Создайте новую учебную базу

Запустите программу 1С из меню «Пуск». В окне со списком баз нажмите «Добавить» → «Создание новой информационной базы» → «Далее».

Выберите создание базы без конфигурации. Назовите её «Учебная служба — опыт 01». Выберите размещение на данном компьютере и укажите новый пустой каталог, например C:\NexusLabs\Base_01. Завершите мастер кнопкой «Готово».

В списке выделите именно новую учебную базу и нажмите «Конфигуратор». Для каждой независимой попытки или восстановления используйте отдельную базу и новый каталог.

Открылся Конфигуратор новой учебной базы. Каталог Base_01 выбран для базы, а Lesson_01\src остаётся каталогом исходников.

6. Загрузите конфигурацию из папки src

В Конфигураторе выберите «Конфигурация» → «Загрузить конфигурацию из файлов…». Укажите распакованную папку src, в которой лежит Configuration.xml.

Команда «Загрузить конфигурацию из файла…» предназначена для .cf; это другая команда. ZIP и JSON в неё не загружают. Если меню недоступно, сначала выберите «Конфигурация» → «Открыть конфигурацию».

После загрузки выберите «Конфигурация» → «Обновить конфигурацию базы данных» или нажмите F7 в окне Конфигуратора. В новой пустой учебной базе подтвердите добавление объектов, показанных в диалоге. Если появились ошибки, сохраните текст ошибки и вернитесь к указанному в ней файлу; урок ещё не отмечайте выполненным.

В дереве конфигурации появились учебные объекты. Обновление базы завершилось без ошибки. Исходники в Studio не были заменены.

7. Запустите 1С и выполните действия из урока

В Конфигураторе выберите «Отладка» → «Начать отладку» или нажмите F5 именно в окне Конфигуратора. Другой путь: закройте Конфигуратор, выделите эту базу в окне запуска и нажмите «1С:Предприятие».

Откроется отдельное окно 1С. Шаблон покажет сообщение об учебной сервисной службе. При обычном первом открытии автоматическое заполнение не выполняется, поэтому пустые списки допустимы. Это подтверждает открытие приложения, но ещё не успешное выполнение лабораторной.

Откройте раздел «Учебная сервисная служба» и нужный по заданию список, например «Клиенты» или «Услуги». Создавайте только учебные записи. Сравнивайте каждое действие с разделом «Ожидаемый результат» своего урока. Некоторым заданиям нужны дополнительные объекты или отдельная серверная среда — это указано в самом уроке.

Видно окно 1С и результат ваших действий. Вы можете объяснить, что получилось и совпало ли это с условием лабораторной.

8. Сохраните результат и отметьте выполненную работу

Сохраните исходники и результаты, перечисленные в лабораторной: например снимок экрана, текст вывода или таблицу проверки. Если вы меняли код в Конфигураторе, перенесите изменённый текст обратно в соответствующий файл Studio и нажмите «Сохранить».

Вернитесь в урок Nexus. Ответьте на вопросы и нажмите «Проверить понимание». После реального выполнения лабораторной подтвердите её галочкой и нажмите «Отметить выполненным по самоотчёту».

В этом курсе изменился счётчик прогресса. Прогресс другого курса не переносится. Отметка — ваш учебный самоотчёт, а не автоматический сертификат.

Как выполнить проверочную и итоговую работу

Для проверки одного урока откройте «Проверка понимания», ответьте на вопросы и нажмите «Проверить понимание». Разберите показанные пояснения. После настоящего выполнения лабораторной подтвердите её и нажмите «Отметить выполненным по самоотчёту».

Для итоговой работы вернитесь на страницу именно своего курса и нажмите «Итоговая работа» или «Открыть итоговую работу». Выберите вариант. В каждом из трёх вариантов — 24 вопроса. Ответьте на все и нажмите «Проверить и сохранить попытку». Проверьте результат и число попыток в истории.

Прочитайте четыре практические работы. В каждой раскройте «Критерии приёмки». Выполняйте задания в отдельных копиях по основному маршруту лабораторной. Сохраните ZIP исходников и результаты, перечисленные в задании: например снимки экрана и протокол проверки.

В разделе «Самостоятельный проект» выберите один из трёх проектов. Прочитайте состав работы, список результатов и рубрику оценки. В поле «Портфолио» опишите свою копию, выполненные проверки, фактические результаты и оставшиеся ограничения. Укажите требуемые заданием ссылки и идентификаторы. Это текстовое поле, а не загрузка файлов: сами архивы и снимки храните отдельно.

После выполнения заданий отметьте подтверждение и нажмите «Сохранить версию портфолио». Дождитесь подтверждения и проверьте число версий в истории. Новая версия не удаляет прежнюю. Для резервной копии нажмите «Экспорт итоговой истории этого курса».

Ответы теста проверяются локально. Портфолио фиксирует ваш самоотчёт; загрузка протокола 1С не выставляет оценку проекта автоматически. Результаты двух курсов независимы. Сертификат, преподавательская или серверная аттестация здесь не выдаются.

Где ввести первую проверочную строку кода

В своей копии выберите Ext/ManagedApplicationModule.bsl. Найдите «Процедура ПриНачалеРаботыСистемы()». Сразу после этой строки, до условий и команды Возврат, добавьте строку ниже. Она должна находиться внутри процедуры.

Сообщить("Моя проверка запуска");

Сохраните работу, скачайте новый ZIP, загрузите его src в свою учебную базу, обновите конфигурацию базы и запустите 1С. Должно появиться сообщение «Моя проверка запуска». Для заданий без программирования этот шаг необязателен.

Как сделать резервную копию базы

Закройте окно 1С:Предприятия и откройте эту учебную базу в Конфигураторе. Выберите «Администрирование» → «Выгрузить информационную базу…». Сохраните отдельный файл .dt.

Для проверки восстановления создайте ещё одну новую пустую базу в другом каталоге. В её Конфигураторе выберите «Администрирование» → «Загрузить информационную базу…» и укажите .dt. Открывайте восстановленную копию и сравнивайте данные. В исходную базу ничего загружать не нужно.

Какой файл для чего нужен

ZIP с исходниками: Распаковать. В Конфигураторе загрузить папку src через команду «из файлов».

nexus-onec-sources.json: Перенос работы обратно в Nexus через «Импорт исходников 1С». Это не архив и не база 1С.

nexus-onec-official-snapshot.json: Запрос для заранее подготовленного личного проверочного комплекта. Сам по себе 1С не запускает.

.dt: Резервная копия базы. Восстанавливается средствами 1С в новую отдельную базу. Не импортируется в Studio как исходники.

Если что-то не получилось

Нажал «Подготовить запуск 1С», а скачался JSON
Так и должно быть: эта кнопка создаёт запрос для внешнего личного проверочного комплекта. Если комплект ещё не подготовлен, используйте ручной путь с ZIP и Конфигуратором выше. Браузер не исполняет BSL.

1С просит файл .cf
Выбрана команда «из файла». Вернитесь в меню и выберите «Загрузить конфигурацию из файлов…», затем папку src.

Код изменил, а результат старый
Скачайте ZIP после последнего сохранения, загрузите его заново, обновите конфигурацию базы данных и перезапустите 1С. Проверьте имя открытой базы.

Редактор не даёт изменять файл
XML защищён в исходной копии. Для изменения метаданных создайте новую копию с соответствующим разрешением. Если работу уже редактируют в другой вкладке, закройте тот редактор и нажмите «Начать редактирование».

Работаю с телефона или без установленной 1С
Можно читать уроки и работать с текстом. Для настоящей проверки платформы нужен ПК с указанной в лабораторной средой. Автономный пакет курса не содержит установщик 1С.
